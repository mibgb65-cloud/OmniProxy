# ADR-011: StepFun 默认计费顺序与模型目录去重

## Status

Accepted — 2026-10-16

失败重试条款局部由 [ADR-015](ADR-015-account-failover.md) 取代（Partially superseded）；原跨计费／地区及共享额度限制保持。

## Context

用户要求 StepFun 沿用 MiMo 的默认通道顺序与模型列表去重，替代此前多平台／计费池并存时要求显式通道的默认行为。

## Decision

- 迁移 027 独立保存 `stepfun_settings.preferred_billing_mode`，仅允许 `step_plan`／`payg`，初始 Step Plan 优先；缺失／损坏明确报错。MiMo 设置及默认值保持独立。
- 共享 MiMo／StepFun 的合格计费方式筛选和前端保存交互；每个服务商内优先首选通道，无合格账号才使用另一方式，然后沿用服务商优先级与账号创建时间／ID 顺序。国内／海外按账号已有地区配置转发，不探测账号权限，不在请求失败后跨通道重试。
- 公开目录仅发布原模型及用户显式别名，旧四类通道和旧 Claude 上下文／编码 ID 仍能兼容解析。模型协议、地区能力和版本校验不放宽，Router 继续仅国内 Step Plan 可用。
- Wails 设置绑定保存后复用受管目录刷新；不读取凭据、不新增依赖、不改变已选定目标的在途请求。

## Alternatives Considered

只隐藏通道副本仍会留下裸模型歧义；请求失败后跨通道重试扩大计费和副作用；复制整套 MiMo 界面与筛选逻辑容易使两处保存及兼容行为不一致，因此采用已有策略与有限复用。

## Consequences

同名模型统一展示，偏好可在阶跃星辰账号设置中即时保存。用户仍可用固定账号／显式通道指定平台及计费；官方额度未知不视为满额或耗尽，外部客户端可能需要重载目录。
