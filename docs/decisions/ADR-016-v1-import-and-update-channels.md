# ADR-016: v1 只读导入和预发布更新渠道

## Status

Accepted

## Context

v1 与 Wails v3 版的目录、账号模型和 DPAPI 参数不同；Codex 登录还改用官方组件隔离凭据。原版本比较丢弃预发布信息，更新端点不能发现 Beta，仓库及应用版本尚未定稿。

## Decision

以用户主动预览／确认方式读取旧格式，在现有账号创建事务内保存明确可映射的 API Key 及账号级设置。使用源文件快照防止预览后变化，确定性身份和目标 Key 检查避免重复；逐账号报告失败，支持保留成功项后的重试。旧数据始终只读，订阅和未知计费／端点身份明确提示重新登录或手工处理，不推断权限或改写客户端。

更新沿用只读检查与发布页安装，持久化正式／Beta 选择；默认根据应用是否预发布解析。Beta 用有界分页，选择有效最高 SemVer，正式优先于同基础版本预发布。应用使用已确认的 `2.0.0-beta.1`，Windows 数字资源独立映射，默认接入原正式发布仓库。

## Alternatives Considered

- 直接搬移旧目录：密文、模型和登录生命周期不兼容，且削弱回退能力。
- 一次性全库转换：历史统计、路由和客户端备份语义尚不一致，不能承诺无损兼容。
- 所有账号共同事务：文件凭据与 SQLite 无共同事务；复用成熟的单账号创建和清理边界，配合逐项结果更容易可靠重试。
- 将 Beta 后缀剥离后比较：无法识别 Beta 序号及正式版提升。

## Consequences

无需新增依赖或数据库迁移。导入不是全库无损迁移，也不代替官方订阅登录；自动更新安装仍未实现。源文件和目标凭据只在后端短期使用，UI 只有元数据。发布前还需执行实际安装／升级／卸载验收。
