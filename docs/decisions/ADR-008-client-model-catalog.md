# ADR 008: 统一模型目录与客户端格式适配

Status: Accepted

Date: 2026-10-10

## 背景

一键接入原先要求用户选择单个模型，Codex 与 Claude Desktop 的目录格式也不同。普通 OpenAI `data/id` 列表不能直接作为 Codex ModelsResponse；API Key 自定义 Provider 的远程目录还需要版本适用的发现开关和完整目录 URL。客户端身份保护仍遵循 ADR 005。

## 决策

- `core/modelcatalog` 定义与数据库、Wails 和 React 无关的目录、元数据校验及格式适配。模型可用性由现有路由服务统一解析；别名按实际选中账号继承目标元数据。
- 迁移 011 保存官方明确返回的描述、默认标记、推理档位，以及可选上下文／模态／工具能力。未知值保持空，不套用其他模型的能力。旧快照默认为空元数据，重同步后补齐。
- `/v1/models` 保留普通 `data/id` 协议并增加公开名称／描述及有界分页；`/v1/codex-models` 输出 Codex `models` 元数据。目录端点各自接受白名单参数，推理端点继续拒绝查询字符串。两者均使用现有本地接入鉴权。
- Codex 内置 `openai` 使用应用管理的本地目录，以保留原提供商和会话身份。已安装核心版本支持显式目录 URL 的自定义 Provider 使用远程目录；旧版使用本地兼容方式，不自动升级客户端。
- Codex 兼容目录提供通用编码说明和当前网关的文本协议配置，不复制官方模型专属指令、人格或审批元数据。已存在的用户指令文件／安全设置保留；不宣称未确认的上下文、搜索、图片或推理摘要能力。
- Claude Desktop 生成完整 `inferenceModels`，避免其自动发现对 Claude ID 的过滤；不改 `appliedId`、工作空间或官方配置。CLI 自动设定可用默认模型，可用 ID 通过 `/model <ID>` 切换，菜单展示依客户端版本。
- 默认选择优先保留仍可用的现有模型；否则按官方默认标记及模型 ID 稳定排序。预览修订包含模型目录、默认模型、目录方式与端口，应用拒绝过期预览。
- 本地目录与主配置均核对文件版本并加密备份；文件写入成功后事务保存两个版本，版本提交失败时回滚两份文件。外部修改或未受管同名目录阻止覆盖与恢复。
- 同步模型、路由／资源变更及读取受管客户端时尝试更新已接管目录。目录刷新失败保留可恢复状态并记录安全错误；未接管的客户端不被自动写入。客户端重启后加载更新，不强制结束现有会话。

## 验证与限制

单测覆盖模型排序、元数据边界、路由目标继承、两种协议及参数边界、自动默认、完整列表、目录修订、双文件回滚、更新和恢复。显式隔离验收使用本机 Codex 0.155.1 实际读取生成目录；不借用默认登录或真实上游密钥。

远程目录策略需与目标客户端核心版本一致；CLI 与 Desktop 使用不同核心时，应按实际版本核对。未知模型能力仍需后续官方同步补齐，目录显示不代表所有上游扩展能力均可转发。
