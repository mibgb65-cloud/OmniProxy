# ADR 007: 仪表盘统计与请求明细分离

Status: Accepted

Date: 2026-10-09

## 背景

仪表盘需要按本地今日／7 天／30 天展示请求、结果、耗时与 Token。请求明细有保留上限，既有日桶没有结果与耗时，不能用最近列表计算完整指标。

## 决策

- 追加独立 UTC 15 分钟桶，覆盖现代整点、半小时和 45 分钟时区边界，前端提交有限的本地小时／日期 UTC 边界，后端校验时间跨度与排序。
- Begin、Token 差值、结束结果及崩溃恢复与既有记账事务原子更新；完成事件幂等，取消单列，成功率与平均完整请求耗时按成功＋失败请求计算。明细淘汰不减少桶。
- 迁移仅回填现存明细；曾淘汰明细则保守标记升级前的统计可能不完整，不从 Token 汇总推算未知结果或耗时。
- 只读接口返回同一快照的指标、趋势、最近请求与历史覆盖信息。Token 继续使用十进制字符串，空样本的比率／耗时返回 null。
- 变更通过有界合并的 activity:updated 信号通知读取，不在事件中携带账号或请求内容，不新增依赖或 Core 对 Wails 的依赖。

## 后果

每个活跃时间片增加一个小聚合行，首页轻量读取即可更新。旧缺失历史无法恢复；用户本地日期和服务端时区不必一致。资源概况另外复用已有缓存，查询官方额度只由用户主动触发。
