# OmniProxy v2.0.0-beta.40

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 修复

- **刷新额度时反复出现「额度查询失败，请稍后刷新。」**。此前每次查询都为每个订阅账号启动一次
  本机 `codex` 官方子进程（实测约 5.5–5.9 秒，其中初始化 3.5–3.8 秒），任何一次启动、握手或
  上游读取失败都会变成同一句错误；即使上一次查询成功、界面上还留着百分比，红色提示也会覆盖它。
  - 额度改为优先调用官方 HTTP 额度接口 `GET https://chatgpt.com/backend-api/wham/usage`，
    只使用本地已核对的隔离授权材料，单次查询不再启动子进程。官方明确拒绝授权（401／403）时
    直接提示重新登录；网络、限流、5xx、响应形状变化或需要续期时才回退原有官方组件链路，
    续期行为不变。
  - 额度显示改为保留最近一次成功结果：瞬时失败（网络、超时、5xx、429、上游 `request_failed`）
    在最近成功后 10 分钟内继续显示上次百分比与重置时间，并标注「已保留上次获取的信息」；
    超过窗口或确定性失败（未授权、身份变化、凭据不可用）仍然立即显示错误，不用旧数据掩盖。
  - 本地额度快照写入失败不再把一次成功的读取变成失败，只记录一条告警。

## 升级说明

- 覆盖安装即可，无新增数据库迁移。
- 已有的路由、别名、账号、客户端配置与额度留存快照保持不变。
- 若之前读写额度异常缓慢，升级后可观察到刷新明显变快（一次 HTTPS 取代一次子进程启动）。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 官方 HTTP 额度接口是官方客户端的订阅端点，不是公开文档化 API；形状变化时回退原有链路，
  不会阻断额度显示，也不会改变账号授权状态。
- 重置卡数量与兑换仍走原有官方组件链路，本次未改。
- 真实账号上的额度接口返回形状需要用户在本机验收。
