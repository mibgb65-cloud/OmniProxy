# v1.2.9-beta.5 - Reset-credit-aware quota estimates / 刷新卡感知额度预估

This beta prevents Codex weekly quota cost estimates from mixing local Token usage recorded before a rate-limit reset with the provider percentage reported after the reset.

本次 beta 防止 Codex 周额度费用预估将限额刷新前记录的本地 Token 用量与刷新后的上游百分比混合计算。

## Bug Fixes / 问题修复

- **Weekly reset detection**: After a reset credit is consumed, OmniProxy compares the weekly percentage and reset time before and after the refresh. A new estimate baseline is recorded only when the weekly window actually changes.
  - **周窗口重置检测**：使用刷新卡后，OmniProxy 会比较刷新前后的周额度百分比和重置时间；只有周窗口真正变化时才记录新的预估基线。
- **Post-reset Token deltas**: Weekly cost estimates now subtract the persisted pre-reset input, output, and cache Token totals instead of reusing the entire local weekly aggregate.
  - **刷新后 Token 增量**：周费用预估现在会扣除持久化的刷新前输入、输出和缓存 Token 总量，不再复用整个本地周汇总。
- **Five-hour resets stay isolated**: If a reset credit changes only the five-hour window, the existing weekly estimate remains unchanged. A naturally expired weekly window is not treated as a reset-credit event.
  - **5 小时窗口保持独立**：如果刷新卡只改变 5 小时窗口，现有周额度预估保持不变；自然到期的周窗口也不会被误判为刷新卡事件。
- **Clear estimate scope**: Adjusted estimates identify that they are based on local proxy usage recorded after the latest reset credit.
  - **明确预估口径**：经过校正的预估会明确说明，结果基于最近一次刷新卡之后的本地代理用量。
- **Regression coverage**: Added backend and frontend tests for weekly-window changes, five-hour-only resets, natural weekly rollover, baseline persistence, and post-reset estimate calculation.
  - **回归测试覆盖**：补充周窗口变化、仅 5 小时重置、周窗口自然轮换、基线持久化和刷新后预估计算的前后端测试。

## Upgrade Guidance / 升级说明

- Reset credits consumed after installing this beta can establish an exact local Token baseline when the weekly window changes.
  - 安装本 beta 后使用的刷新卡，在周窗口变化时可建立精确的本地 Token 基线。
- A reset credit consumed by an older version has no historical baseline and is not reconstructed heuristically. Normal estimation resumes with the next weekly window.
  - 旧版本已经使用的刷新卡没有历史基线，本版本不会通过启发式规则反向推测；下一个周窗口将恢复常规预估。
- No account-pool or local-data migration is required.
  - 无需迁移账号池或本地数据。
