# OmniProxy v2.0.0-beta.9（本地生产安装版）

本版修复 Codex Desktop 原生文件变更摘要与上下文压缩链路，包含 Beta.8 及此前已完成的修复。本地使用 production 标签构建 Windows amd64 NSIS 安装包，不发布 GitHub，由用户自行安装测试。

## 文件变更摘要

- 原生 OpenAI Responses 受管模型目录显式启用补丁工具能力，让 Codex 核心能够为新增、修改和删除文件产生结构化变更事件。
- 第三方模型不推断此能力；通过终端、脚本或外部工具写文件，不保证出现同样的原生变更摘要，也不会补生成旧会话的历史摘要。
- 安装后需要通过已有接入流程刷新受管模型目录，再重新加载 Codex。若配置或目录存在外部改动，应先预览并按正常保护流程处理，不直接覆盖原配置。

## 上下文压缩

- 修复 Compaction V2 功能标记与回合元数据在网关中丢失，HTTP 与 WebSocket 均有明确校验和传递边界，后续回合不沿用旧回合元数据。
- 补齐旧核心使用的独立压缩端点，仅原生订阅固定端点支持；保留不透明压缩内容和用量，不把普通回答或第三方转换结果伪装为压缩成功。
- 不修改用户现有上下文窗口或自动压缩阈值。CLI／Desktop 内核离线契约已验证文件操作及手动压缩链路，真实长会话自动压缩与 Desktop 界面仍需安装后验收。

## 安装与测试边界

沿用现有覆盖安装与数据保留流程，无新增数据库迁移或业务依赖。本轮不自动安装、不重启生产实例、不切换账号、不修改真实客户端配置。

本地安装包未签名，Windows 可能提示未知发布者；机器级安装需要管理员确认。只有新版本实际安装并刷新受管目录后，才能验证当前客户端中的行为。离线契约与打包成功不等于真实订阅上游或 GUI 验收完成。
