# OmniProxy v2.1.1-beta.3 - 更新完成后提示本版新功能 / Post-update whats-new notice

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对公开正式版 `v2.1.0`，本次用户可见改动是升级结束后的反馈；同时包含本地 `v2.1.1-beta.1`、`v2.1.1-beta.2` 的发布说明排版改动，取代这两个本地版本。

## 新特性 / Features

- **更新完成浮窗**：安装结束并以新版本重新打开后，自动弹出「更新完成」，说明「升级前版本 → 当前版本」，正文列出本版新增内容，不再出现升级后毫无反馈的空档。
  - **Update-complete dialog**: after the installer finishes and the app reopens, a one-time dialog shows the previous version, the current version and what changed in this release.
- **本版说明走同一套排版**：正文取构建内置的 `docs/releases/v<运行版本>.md`，与升级浮窗、设置页「当前版本更新日志」共用 Markdown 渲染与链接白名单；提示本身不联网。
  - **Same renderer everywhere**: the body reuses the bundled release note for the running version and the shared Markdown renderer, with no extra network request.
- **只提示一次**：确认、关闭按钮、Esc 或点击遮罩都算已读，回执写入 `updates/status.json`；写入失败时下次启动再提示，不假装已读。
  - **Shown once**: confirming, closing with the button, Esc or the overlay records the acknowledgement in `updates/status.json`; a failed write shows the notice again next launch instead of silently pretending it was read.
- **「查看完整更新日志」**：先回执再打开设置页的关于分区，不在浮窗之上再叠一层弹窗。
  - **"Open release notes"** acknowledges first, then opens the About tab instead of stacking a second modal.

## 修复 / Fixes

- 升级浮窗与设置页的说明正文此前可能显示 `##`、`**`、反引号等原始记号，现在统一按 Markdown 排版（标题、段落、粗体／斜体、行内代码、链接、有序／无序及嵌套列表、引用、代码块、分隔线）。
- 升级浮窗改为「固定标题栏 + 可滚动正文 + 固定操作区」，版本摘要按「当前版本 → 可升级版本」分区，附发布时间、包大小与发布页入口。

## 安全边界 / Safety boundary

- 说明正文中的 HTML 标签只作为文本显示，不执行脚本，也不加载远端图片（仅保留替代文字）。
- 只有 `http(s)` 链接与以 `/` 开头的站内路径生成可点击入口，并带 `rel="noreferrer"`；`javascript:` 等其余协议保持纯文本。
- 「更新完成」提示的版本来源与回执全部来自本地记录，不接受前端传入的版本、路径或 URL。

## 升级说明 / Upgrade notes

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- Windows 数字版本为 `2.1.1.0`；完整版本递增至 `2.1.1-beta.3`，高于公开的 `2.1.0` 与本地 `2.1.1-beta.1`、`2.1.1-beta.2`。
- 安装身份、安装目录与数据目录沿用既有设置；无新增数据库迁移、无新增依赖。
- 不修改已有账号、路由、用量留存或本地客户端配置；建议更新前正常退出应用并保留数据备份。

## 已知边界 / Known limits

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 本次为本地构建，不会出现在远端自动更新渠道。
- 「更新完成」浮窗的前端排版已通过隔离 Chromium 截图核对，原生 WebView2 窗口与 140% 字号观感需在本地更新后确认。
