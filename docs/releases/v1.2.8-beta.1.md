# v1.2.8-beta.1 - Claude browser login / Claude 浏览器登录

This beta adds a first-class Claude browser login flow to Account Management. It uses PKCE and a loopback-only callback to import Claude OAuth credentials automatically, while preserving the existing manual OAuth JSON workflow.

本次 beta 为账号管理新增完整的 Claude 浏览器登录流程，通过 PKCE 和仅本机可访问的回调自动导入 Claude OAuth 凭据，同时保留原有的手动 OAuth JSON 导入方式。

## Features / 新特性

- **Claude browser login**: The Anthropic account page now provides **Log in to Claude**, with a copyable authorization link, explicit browser opening, automatic callback detection, and in-dialog status feedback.
  - **Claude 浏览器登录**：Anthropic 账号页新增「登录 Claude」，支持复制授权链接、明确打开浏览器、自动检测回调和弹窗内状态反馈。
- **Automatic account import**: Successful authorization stores a Claude Code-compatible OAuth JSON credential and adds or updates the matching account by account UUID or email.
  - **自动导入账号**：授权成功后按 Claude Code 兼容的 OAuth JSON 结构保存凭据，并根据账号 UUID 或邮箱新增或更新对应账号。
- **Refreshable login session**: An expired or unwanted Claude login link can be replaced directly from the login dialog.
  - **可刷新的登录会话**：过期或不再需要的 Claude 登录链接可以直接在登录弹窗内重新生成。

## Bug Fixes / 问题修复

- **Claude manual token refresh**: Claude OAuth accounts now expose the same manual refresh action as Codex accounts.
  - **Claude 手动刷新令牌**：Claude OAuth 账号现在和 Codex 账号一样提供手动刷新操作。
- **Current Anthropic OAuth endpoint**: Claude authorization-code exchange and refresh now use the current `platform.claude.com` token endpoint.
  - **当前 Anthropic OAuth 端点**：Claude 授权码交换和令牌刷新改用当前的 `platform.claude.com` 令牌端点。

## Security / 安全

- The temporary callback listener binds only to loopback, uses an OS-assigned port, validates OAuth state, and expires after five minutes.
  - 临时回调监听器只绑定本机回环地址，使用系统分配端口，校验 OAuth state，并在五分钟后失效。
- OAuth access and refresh tokens remain in the protected local account store and are never written to application logs.
  - OAuth access token 和 refresh token 继续保存在受保护的本机账号存储中，不会写入应用日志。
