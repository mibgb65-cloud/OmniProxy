# v1.3.0-beta.2 - Immediate and manual Codex activation / Codex 即时与手动激活

This beta improves the opt-in Codex quota-window activation introduced in `v1.3.0-beta.1`. It starts scanning immediately when the setting is enabled, supports expired windows, adds a per-account manual action, and makes activation activity visible in persistent request history.

本次 Beta 改进 `v1.3.0-beta.1` 引入的可选 Codex 额度窗口自动激活：开启设置后立即扫描、支持已过期窗口、增加单账号手动操作，并将激活过程持久化到请求历史。

## Features / 新特性

- **Immediate scan after opt-in**: Saving Global Settings with Codex auto-activation changing from off to on immediately scans every enabled Codex account instead of waiting for a later health check.
  - **开启后立即扫描**：在「全局设置」中把 Codex 自动激活从关闭改为开启并保存后，会立即扫描所有启用的 Codex 账号，无需等待后续健康检查。
- **Manual per-account activation**: Each Codex account card on the OpenAI Quota page now provides `检测并激活`. The action works independently of the global switch, but always queries current usage first and sends no message when the windows are already active.
  - **单账号手动激活**：OpenAI 额度页的每个 Codex 账号卡新增「检测并激活」。该操作不依赖全局开关，但始终先查询当前额度；窗口已经启动时不会发送消息。
- **Expired-window handling**: A missing or expired five-hour / weekly reset is now eligible for activation. A displayed `0%` usage value is never used as the trigger, preventing duplicate requests for active low-usage windows.
  - **过期窗口处理**：五小时或周重置时间缺失、已经到期时均可触发激活；显示为 `0%` 的使用率不会作为触发条件，避免对已启动的低用量窗口重复请求。
- **Persistent activation history**: Activation start, completion, skip, and failure states are written to Request History with before / after reset timestamps and without credential values.
  - **持久化激活历史**：激活开始、完成、跳过和失败状态会写入请求历史，包含激活前后的重置时间，但不包含凭据内容。
- **Clear interaction feedback**: The manual action exposes an in-progress state, prevents duplicate clicks, updates the account card after completion, and reports whether activation occurred or was unnecessary.
  - **明确交互反馈**：手动操作提供执行中状态、防止重复点击，完成后更新账号卡，并明确提示已激活或无需激活。

## Upgrade Guidance / 升级说明

- Existing `v1.3.0-beta.1` installations can upgrade directly. The existing auto-activation switch value is preserved.
  - 现有 `v1.3.0-beta.1` 可直接升级，自动激活开关状态会保留。
- If the switch is already enabled during upgrade, normal startup quota refresh scans Codex accounts with the new expired-window rules. Turning the switch off and on is not required.
  - 升级时开关已经开启的情况下，正常启动额度刷新会按新的过期窗口规则扫描 Codex 账号，无需重新关闭再开启。
- The manual action may consume a very small amount of Codex quota only when the live usage response shows a missing or expired expected window.
  - 只有实时额度响应显示预期窗口缺失或已过期时，手动操作才可能消耗极少量 Codex 额度。
- No account-pool or local-data migration is required.
  - 无需迁移账号池或本地数据。
