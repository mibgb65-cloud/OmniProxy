# v1.3.1 - Astra, Atria, and managed model catalog / Astra、Atria 与托管模型目录

This stable release consolidates the validated `v1.3.1` beta line. It adds GPT-6 Astra and Atria support, exposes OmniProxy-managed models in the ChatGPT desktop app, and restores usage accounting for compressed streaming responses.

本正式版汇总已验证的 `v1.3.1` Beta 版本线：新增 GPT-6 Astra 与 Atria 支持，让 ChatGPT 桌面应用显示 OmniProxy 托管模型，并恢复压缩流式响应的 token 用量统计。

## Features / 新特性

- **GPT-6 Astra**: Added `gpt-6-astra` to gateway presets, Codex model selection, generated OpenCode and Pi configurations, context-window settings, and billing estimates.
  - **GPT-6 Astra**：在网关预设、Codex 模型选择、生成的 OpenCode 与 Pi 配置、上下文窗口设置和费用估算中加入 `gpt-6-astra`。
- **Atria provider**: Added Atria as a first-class provider with OpenAI- and Anthropic-compatible routes, `atr_` key validation, multi-account rotation, retry support, and gateway presets.
  - **Atria 服务商**：将 Atria 接入为一等公民服务商，支持 OpenAI 与 Anthropic 兼容路由、`atr_` Key 校验、多账号轮换、失败重试和网关预设。
- **Atria one-click configuration**: Added `Atria-Dawn-Preview` to Claude Code and Codex one-click configuration and model-route presets, including its documented context window.
  - **Atria 一键配置**：在 Claude Code、Codex 一键配置及模型路由预设中加入 `Atria-Dawn-Preview`，并写入其文档定义的上下文窗口。
- **Managed model catalog**: Models selected in OmniProxy Codex profiles are appended to the catalog returned to the ChatGPT desktop app, so routed models such as Atria, DeepSeek, and MiMo appear in its model picker.
  - **托管模型目录**：OmniProxy Codex 配置中选择的模型会追加到返回给 ChatGPT 桌面应用的模型目录，使 Atria、DeepSeek、MiMo 等路由模型出现在模型选择器中。

## Bug Fixes / 问题修复

- **Compressed stream usage**: Decode the internal response copy for gzip, deflate, and brotli streams before extracting usage, model, and error summaries, while preserving the original bytes sent to clients.
  - **压缩流用量**：提取用量、模型和错误摘要前，对内部响应副本解码 gzip、deflate 与 brotli 流，同时保持发送给客户端的原始字节不变。
- **Usage history**: Fixed successful compressed streaming requests being recorded as zero tokens in per-request history and token statistics.
  - **用量历史**：修复成功的压缩流式请求在单次请求历史与令牌统计中被记录为 0 token 的问题。

## Upgrade Guidance / 升级说明

- Existing account pools, routes, local configuration, request history, billing summaries, and theme state remain compatible. No local-data migration is required.
  - 现有账号池、路由、本地配置、请求历史、费用汇总和主题状态保持兼容，无需迁移本地数据。
- Re-run one-click client configuration to add newly supported models to existing OpenCode, Pi, Claude Code, or Codex profiles.
  - 如需把新支持的模型加入现有 OpenCode、Pi、Claude Code 或 Codex 配置，请重新执行一键客户端配置。
- Fully quit and reopen the ChatGPT desktop app after upgrading so it refetches the managed model catalog.
  - 升级后请完全退出并重新打开 ChatGPT 桌面应用，使其重新拉取托管模型目录。
- Token usage recorded as zero by earlier betas is not backfilled; corrected totals accumulate from new requests onward.
  - 早期 Beta 中已经记为 0 的 token 用量不会回填，修正后的统计从新请求开始累计。
- Atria does not expose a documented balance or quota endpoint, so OmniProxy reports connectivity and observed usage rather than a remaining balance percentage.
  - Atria 未提供公开的余额或配额接口，因此 OmniProxy 显示连通性和已观察用量，而不是剩余余额百分比。
- Beta users can upgrade directly to `v1.3.1`; the stable version compares newer than every `v1.3.1-beta.*` tag.
  - Beta 用户可直接升级到 `v1.3.1`；正式版版本顺序高于所有 `v1.3.1-beta.*` 标签。
- The Windows installer is currently unsigned; verify its SHA256 file before installation. The macOS universal DMG remains unsigned and not notarized.
  - Windows 安装包目前未签名，安装前请核对其 SHA256 文件；macOS Universal DMG 仍未签名且未公证。

## Breaking Changes / 不兼容更新

- None / 无

## Refactor & Performance / 重构与优化

- **Catalog compatibility**: Upstream models are never duplicated or hidden, and an unparseable upstream catalog is passed through unchanged.
  - **目录兼容性**：不会重复或隐藏上游模型；无法解析的上游模型目录会保持原样透传。
- **Response accounting**: Compression decoding is limited to the bounded internal capture used for accounting and diagnostics, without changing proxy delivery behavior.
  - **响应统计**：压缩解码仅作用于统计与诊断使用的受限内部副本，不改变代理转发行为。
