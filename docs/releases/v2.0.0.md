# OmniProxy v2.0.0

OmniProxy 2.0 是面向 Windows 的本地 AI 接入与账号管理桌面应用。
本版本提供 Windows 10／11 amd64 全量安装器，需要 WebView2 运行时。

## 主要功能

- 统一管理提供商、API Key 与已接入的订阅账号，配置模型、路由及账号使用顺序。
- 通过本机网关连接 Codex、Claude 等受支持客户端，提供流式转发、工具调用与账号故障切换。
- 展示请求结果、Token 用量、仪表盘，以及已支持提供商的官方额度或余额；
  本机统计、估算和官方余额保持不同语义，不把未知信息当作零或已确认能力。
- 一键应用和恢复受支持客户端的配置，提供独立接入设置及模型选择。
- 按提供商选择直连、走代理或跟随全局，支持 HTTP／SOCKS／mixed 端口识别与故障提示。
- 提供中英文界面、深浅主题、系统托盘、自启动设置及应用内更新。

## 正式版收尾修复

- 安装器从明确的原安装目录读取历史 `data-dir.txt`，避免临时辅助程序错误地使用默认位置。
- 旧位置仍含数据库时拒绝改选空目录；数据迁移继续由应用内操作完成。
- 保持历史数据位置时，将旧标记安全保存为用户配置，改变程序安装目录不再丢失数据指针。
- 安装向导通过明确的 Unicode 结果协议读取数据位置，避免中文目录在系统代码页转换中乱码。
- 数据位置读写使用实际使用者的 Windows 身份与目录权限，不使用提权管理员继承的
  `APPDATA` 或 `OMNIPROXY_*` 环境。无法确认身份／位置时明确报错，不猜测默认目录。
- 配置与目录写入验证使用唯一临时文件，避免覆盖已有同名文件；损坏的配置和历史标记有读取边界。

## 升级与数据

- 从已有 v2 Beta 覆盖升级，无新增数据库迁移；保留账号、配置与请求记录。
- 升级前建议备份数据主目录。需要搬迁时，先完成升级，再使用应用内
  「设置 → 数据存储 → 数据主目录」；不要用安装器代替数据迁移。
- v1 数据布局按已有独立导入／隔离迁移流程处理；不支持把 v2 数据库直接交给 v1 使用。
- 卸载保留用户数据；完整版本及更新渠道按正式版规则识别，已有显式渠道偏好继续保留。

## 已知边界

- 安装器未签名，Windows 可能提示未知发布者或 SmartScreen 警告；SHA256 校验不是数字签名。
- 仅承诺 Windows amd64，不提供 macOS／Linux 桌面发布资产。
- 外部客户端、模型、订阅权限及官方接口可能变化；本机配置不能扩展上游模型的真实能力。
- 部分提供商没有官方额度／余额接口，不能提供跨设备的完整消费记录。
- 长会话压缩时机仍受客户端与上游影响，不承诺修复所有客户端的提前压缩现象。
- Control API 当前提供健康检查，不是完整的远程管理 API；网关仍只监听本机回环地址。
