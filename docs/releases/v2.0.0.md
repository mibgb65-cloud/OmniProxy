# v2.0.0 - Windows local AI gateway / Windows 本地 AI 网关正式版

The first stable v2 release brings the Go/Wails 3 and React desktop gateway to Windows 10/11 amd64.
The incremental changelog below compares the last public v2 beta, `v2.0.0-beta.5`, with this release.

v2 首个正式版本面向 Windows 10／11 amd64，采用 Go／Wails 3 与 React 桌面架构，需要 WebView2。
下方增量日志对比上一个公开 v2 测试版 `v2.0.0-beta.5`，不是尚未发布的本地 Beta 编号。

## Features / 新特性

- **Accounts and models**: Manage provider keys and supported subscription accounts, model catalogs, routing and account rotation.
  - **账号与模型**：统一管理提供商 Key 与已接入的订阅账号、模型目录、路由及账号轮换。
- **Client integration**: Apply and restore supported Codex/Claude and other client configurations with explicit model selection.
  - **客户端接入**：为受支持的 Codex／Claude 等客户端应用或恢复配置，并明确选择接入模型。
- **Usage visibility**: Request history, Token aggregates, dashboards and supported official quota/balance queries distinguish local estimates from provider data.
  - **用量观测**：提供请求历史、Token 聚合、仪表盘与已接通的官方额度／余额查询，区分本机估算和服务商数据。
- **Outbound proxy**: Choose direct, proxy or global settings per provider, with HTTP/SOCKS/mixed-port detection and actionable errors.
  - **出站代理**：按提供商选择直连、走代理或跟随全局，支持 HTTP／SOCKS／mixed 端口识别和故障提示。
- **Desktop experience**: Chinese/English UI, light/dark themes, tray controls, autostart settings and in-app updates.
  - **桌面体验**：中英文、深浅主题、系统托盘、自启动设置及应用内更新。

## Bug Fixes / 问题修复

- **Installer data safety**: Resolve legacy markers from the original installation, reject abandoning existing databases and retain the data pointer when moving the program.
  - **安装数据保护**：从原安装目录读取旧标记，拒绝遗留已有数据库，修改程序安装目录时保留数据指针。
- **Windows identity and Unicode**: Use the actual user's token and permissions for data settings; preserve Chinese paths through an explicit UTF-16LE installer protocol.
  - **Windows 身份与中文**：按实际使用者的令牌和权限读写数据设置，通过 UTF-16LE 安装器协议完整传递中文路径。
- **Configuration and release safety**: Bound file reads, use unique temporary files and atomic replacement, and stop packaging when the quality gate fails.
  - **配置与发布安全**：限制文件读取，使用唯一临时文件与原子替换，质量门失败后立即停止打包。

## ⚠️ Breaking Changes / 不兼容更新

- **Platform**: v2 currently publishes Windows amd64 only. Existing v1 macOS releases remain available; this is not a macOS/Linux v2 update.
  - **平台**：v2 当前仅发布 Windows amd64。已有 v1 macOS 资产继续保留，本版不是 macOS／Linux 的 v2 更新。
- **Data**: Back up the data directory consistently, including SQLite WAL, before upgrading. Public Beta.5 and earlier installations apply existing migrations through 044; only the local Beta.44 has no additional migration.
  - **数据**：升级前请做包含 SQLite WAL 的一致性备份。公开 Beta.5 及更早版本会按需执行截至 044 的既有迁移；仅相对本地 Beta.44 没有额外迁移。
- **v1 import and rollback**: Use the v1 import preview for supported keys; OAuth accounts need a new login. Historical statistics/settings are not a full-database import. Do not let an older app write the migrated v2 database.
  - **v1 导入与回退**：通过 v1 导入预览迁入受支持的 Key，OAuth 账号需重新登录；历史统计与设置不属于整库导入。不要让旧程序继续写入迁移后的 v2 数据库。
- **Relocation**: Move existing data from the application's storage settings after upgrading, not from the installer. Uninstalling preserves user data.
  - **搬迁**：升级后使用应用内数据存储设置迁移已有数据，不要用安装器替代迁移；卸载保留用户数据。

## Refactor & Performance / 重构与优化

- **Architecture**: Keep desktop bindings separate from the Go core and reuse bounded gateway, credential and update components.
  - **架构**：保持桌面绑定与 Go Core 分离，复用有界的网关、凭据与更新组件。
- **Compatibility**: Preserve explicit update-channel preferences; external models, quota APIs and long-session compaction remain subject to client/provider capabilities.
  - **兼容性**：保留显式更新渠道偏好；外部模型、额度接口与长会话压缩仍受客户端／上游能力限制，不承诺修复所有提前压缩现象。

## Release verification and limits / 发布校验与边界

- Public assets must be built by GitHub Actions, approved and signed through SignPath, then have their signature and regenerated SHA256 checked before publication. Check the embedded signature; local verification packages are unsigned and are not Release assets.
  - 公开资产必须经 GitHub Actions 构建、SignPath 人工审批签名，再校验签名并重新生成 SHA256 后发布。签名以产物内嵌信息为准；本地验证包未签名，不属于公开 Release 资产。
- The gateway binds to loopback. The Control API currently provides health checks, not a complete remote management API.
  - 网关仅监听本机回环地址，Control API 当前提供健康检查，不是完整远程管理 API。
