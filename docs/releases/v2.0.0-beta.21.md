# OmniProxy v2.0.0-beta.21

本版为 Windows amd64 production 本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

## Claude 推理强度：一个模型 + 独立强度选择

- 修正 Claude Code CLI／Desktop 模型菜单把推理强度当成不同模型的问题。此前每个档位会派生一个模型条目（如 `模型 · 高强度推理`、`模型[1m] · 最高强度推理`），同一模型在菜单里出现多行。
- 现在每个模型只保留一行（普通 + 可选 `[1m]`），推理强度改回客户端原生的 effort 选择：`/effort` 或 `/model` 中的强度滑杆。
- 菜单标签和请求中的模型 ID 仍是真实模型名，不伪装厂商身份、不改变计费归属。只有已在能力目录中确认档位枚举和默认档位的模型才显示强度选择；未知型号保持未知，不推测枚举。
- 强度选择会按该模型真实支持的档位封顶，不会显示或发送该模型实际不支持的档位；非法值返回明确错误，不静默降级。
- 此前版本写入的档位选项仍可被识别并还原为原模型与原档位，已保存的旧会话不会失效；这些条目不再出现在菜单中。

## 兼容与已知边界

- 继承 Beta.20 的推理档位、压缩专用时限与独立记账及此前各版功能。
- 不新增数据库迁移，不改变安装身份、凭据格式、账号启用状态、路由选择或客户端登录。
- 强度选择依赖 Claude Code 2.1.257 或更高版本；更旧版本不显示强度控件，按模型默认档位调用。
- Codex 在约 500k 用量时提前压缩的现象本版**仍未定位根因**，不宣称已修复，也不修改用户的 1.05M／900k 设置。
- Google 上游 `429 / RESOURCE_EXHAUSTED` 仍是独立调查项，本版不宣称解除限流。
- 构建与回归在隔离环境执行，不以本地测试替代真实上游调用、真实覆盖安装或客户端界面验收。

## 升级后需要做的一步

本机 `~/.claude/settings.json` 里仍保留 Beta.20 写入的旧档位选项。升级后请在应用中对该 Claude 客户端**重新应用一次一键配置或刷新目录**，然后**完全退出并重启** Claude，菜单才会换成「单模型 + 强度滑杆」。客户端可能缓存旧菜单，仅重启进程而不完全退出可能仍显示旧条目。

## 安装与数据保留

先从托盘完全退出旧版，再为整个数据目录保留一致性备份，随后运行本安装包覆盖原安装目录，无需先卸载旧版或删除账号数据。安装后在“设置与关于”核对版本为 2.0.0-beta.21。

本版沿用现有安装目录、账号、数据库、设置、请求历史与累计统计，不主动清空数据，不自动重启 Claude／Codex Desktop；不要同时启动新旧版本写入同一数据目录。

本地安装包未签名，Windows 可能提示未知发布者，机器级安装需要管理员确认。构建过程不自动安装、停止或替换生产应用，不上传公开发布；真实覆盖安装与数据保留由用户本地验收。
