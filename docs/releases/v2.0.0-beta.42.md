# OmniProxy v2.0.0-beta.42

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 自动激活：真正后台运行并自动刷新

此前「自动激活 Codex 额度窗口」实际上只在软件运行且在后台循环里才会检测，而默认关闭窗口会退出应用，
关闭设置面板后又看不到任何结果，因此体感上是「必须打开软件并点进设置才会激活」。本版：

- **关闭主窗口不再结束检测**。开启自动激活后，关闭窗口会最小化到托盘，进程继续按 5 分钟周期检测；
  托盘菜单的「退出」仍是真正退出，之后可在 设置 › 通用 › 桌面行为 里显式改回「直接退出」。
  重启应用后若开关仍为开启，启动时会再次校正。
- **启动或唤醒后不必再等满 5 分钟**。官方对未开始的窗口常返回「5 小时 1 分钟后重置」这类随查询
  后移的滑动目标，判定需要两次独立观测。现在出现这类候选时，后台约 35 秒后再补一次观测
  （连续补检最多 3 次），启动、唤醒机器或额度读取唤醒后都能更快给出结论。
- **结果自动刷新，不必打开设置**。每轮检测结束由后端推送脱敏状态（只有账号数、发送数、
  确认数与稳定错误码），任意页面都会自动刷新并弹出一次提示；同一结果不重复弹出，没有可检查账号的
  空轮次不提示。额度卡片仍通过既有事件刷新。

窗口判定条件、发送前的额度与身份复核、按周期至多一次的持久去重均未改变；仍不会自动重发、
不会自动使用重置卡。

## 提供商：卡片直接进入账号页面

- 提供商页的每张卡片（内置与自定义）都可以点击进入该提供商自己的账号页面。
- 卡片标题同时是键盘入口（Tab 聚焦、Enter 进入），悬停有下划线，卡片有悬停边框与焦点环。
- 卡片内的启用开关、测试、模型预览、编辑和删除仍只执行自身操作，不会被整卡点击带起来。
- 内置但未配置的预设卡片保持不可点击。

## 升级说明

- 覆盖安装即可，无新增数据库迁移，无新增依赖。
- 已有的路由、别名、账号、客户端配置、用量与额度留存快照保持不变。
- 若此前把「关闭窗口时」设为退出，开启自动激活后该项会变为「最小化到托盘」；不再需要后台检测时
  可以改回退出。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 后台检测只在进程存活时运行：未开启「开机启动」时，重启电脑后仍需手动打开一次软件。
- 账号页面的「返回」仍回到账号列表，而不是回到提供商页。
- 真实账号的后台自动激活效果、托盘常驻的长周期行为、浅色主题与 80%／140% 字号下的卡片交互
  仍需安装后在本机验收。
