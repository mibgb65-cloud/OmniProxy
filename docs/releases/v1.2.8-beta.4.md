# v1.2.8-beta.4 - Settings visual consistency / 设置页视觉统一

This beta aligns the global settings page with OmniProxy's current interface language, with a clearer Claude quota risk prompt and a more compact outbound-provider selector.

本次 beta 统一全局设置页与 OmniProxy 当前界面的视觉语言，重新整理 Claude 额度风险提示，并压缩出站厂商选择区的信息密度。

## Improvements / 体验优化

- **Claude quota confirmation now follows the application theme**: The prompt now uses the same surfaces, 28px container radius, theme colors and button treatment as the rest of OmniProxy. Its explanation, risk list and unaffected behavior are separated into clear reading levels instead of one dense block.
  - **Claude 额度确认框与应用主题统一**：提示框现在使用与 OmniProxy 其他界面一致的表面色、28px 容器圆角、主题颜色和按钮样式，并将功能说明、风险列表与不受影响的行为拆分成清晰层级，不再挤在一个文本块中。
- **Outbound-provider cards are more compact**: Provider choices use less vertical space and smaller nested radii, while selected routes gain a restrained side accent and clearer state badge.
  - **出站厂商卡片更加紧凑**：厂商选项减少纵向占用和嵌套圆角，已选路由增加克制的侧边强调与更清楚的状态标签。
- **Settings controls match the rest of the desktop console**: URL fields and the save action now use the application's regular control radius instead of full pill shapes.
  - **设置控件与桌面控制台一致**：URL 输入框和保存操作改用应用常规控件圆角，不再使用完整胶囊造型。
- **Interaction semantics are clearer**: Expand controls expose their expanded state, and preset/provider choices expose their pressed state to assistive technology.
  - **交互语义更加清楚**：展开按钮会暴露当前展开状态，端口预设与厂商选项会向辅助技术暴露当前选中状态。
