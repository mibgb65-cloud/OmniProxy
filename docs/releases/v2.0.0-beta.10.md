# OmniProxy v2.0.0-beta.10（本地生产安装版）

本版优化 Codex 额度查询超时和请求互相阻塞的问题，包含 Beta.9 及此前已完成的修复。使用 production 标签构建 Windows amd64 NSIS 安装包，仅供本地覆盖更新测试，不发布远端或自动安装。

## 额度查询超时修复

- 取消每次查额度前多余的强制令牌刷新，先核验当前托管身份，再正常读取官方额度，避免额外认证请求先耗尽查询预算。官方授权管理、账号手动刷新及网关取令牌前续期保持不变。
- 凭据准备完成后释放全局锁，再消费模型响应。长响应不再持续占用其他账号额度查询、后续请求和自动激活取令牌所需的准备锁。
- 排队支持取消和超时，30 秒查询总预算包含排队；排队超时显示账号操作繁忙，不再一律提示检查网络。失败仍保留最后成功的额度快照，不注销账号。

## 自动激活与安全边界

- 自动激活沿用原有窗口判断、发送前复查及持久去重，不增加自动重试或重复发送。
- 保留成员邮箱、工作区及凭据版本校验；取令牌回调只使用本次短期副本，结束后清零，不增加令牌缓存或输出敏感信息。
- 并发、取消、身份隔离和不强制刷新等离线回归已覆盖。真实过期授权、上游网络及自动激活效果仍需安装后验收，不承诺消除全部网络超时。

## 安装与测试边界

沿用现有覆盖安装与数据保留流程，无新增数据库迁移、业务依赖或客户端配置迁移。由用户自行退出旧版并运行安装包，安装后在关于页确认版本为 2.0.0-beta.10。

建议在 Codex 持续输出时刷新额度，确认查询不再被整段模型响应阻塞，再按原设置检查自动激活；真实网络故障仍会明确提示。构建过程不停止生产程序，不切换账号或修改真实客户端配置。

本地安装包未签名，Windows 可能提示未知发布者；机器级安装需要管理员确认。构建与离线验证通过不等于已完成真实覆盖升级或 GUI 验收。
