# OmniProxy v2.0.0-beta.17

本版为 Windows amd64 production 构建的本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

## Gemini 工具调用兼容性修复

- 修复 Claude Code CLI／Desktop 自带工具的完整 JSON Schema 被放入 Google 受限 `parameters` 字段，导致 Gemini 上游返回 `400 / invalid_request` 的问题。
- Gemini 函数工具改用 `parametersJsonSchema`，完整保留 `$schema`、`exclusiveMinimum`、`additionalProperties` 等定义与参数约束，不通过删除约束规避错误。
- Chat Completions、Responses、Messages 三种入口及 JSON／SSE 输出均有回归覆盖；Google 订阅内 Claude／GPT-OSS 通道保持原 Schema 字段，不扩展未经验证的能力。
- 沿用 Beta.16 的错误分类：无效请求返回 400，真实认证失败、权限拒绝及限流分别保留 401／403／429；不新增重试或跨通道回退。

## 能力与验证边界

- 使用 Claude Code 2.1.299 内核的默认工具定义进行真实合成对照：旧 Schema 字段返回 400，仅改用 JSON Schema 字段后返回 200。
- 进一步使用 Desktop 内核的默认请求验证时遇到 `429 / rate_limited`，本版不宣称解除 Google 限流、补充额度或完成真实桌面会话验收。遇到 429 请暂停连续重试，刷新对应模型分组额度并参考实际重置时间；不能仅凭 429 区分短时限流与额度耗尽。
- 旧现场未保存完整请求，Schema 修复不能等同于解决全部历史 400。工具签名缓存失效、多模态和其他高级选项继续遵守现有支持边界。
- 不引入新依赖或数据库迁移，不改变安装身份。构建和打包过程不发送真实推理，安装后的实际 Gemini 调用由用户验收。

## 安装与数据保留

更新前建议保留包含 SQLite WAL 的一致性数据备份。从托盘完全退出旧版后，运行本安装包覆盖更新，安装后在“设置与关于”确认版本为 2.0.0-beta.17。

本版沿用现有数据与安装目录，不主动清空已有账号、请求历史或累计统计，不改写客户端登录或自动重启 Claude／Codex Desktop。不建议让旧版本继续写入升级后的同一数据库。

本地安装包未签名，Windows 可能提示未知发布者，机器级安装需要管理员确认。构建过程不自动安装、停止或替换生产应用，不上传发布；真实覆盖安装及数据保留由用户本地验收。
