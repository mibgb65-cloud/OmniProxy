# v1.2.9-beta.2 - DeepSeek native Codex Responses compatibility / DeepSeek 原生 Codex Responses 兼容

This beta aligns OmniProxy's Codex configuration and gateway routing with DeepSeek's native Responses API support for DeepSeek V4 Pro and Flash.

本次 beta 使 OmniProxy 的 Codex 配置与网关路由适配 DeepSeek 原生 Responses API，覆盖 DeepSeek V4 Pro 与 Flash。

## Features / 新特性

- **DeepSeek V4 Flash is available on the Codex gateway**: The Codex route and DeepSeek platform preset now expose both V4 Pro and V4 Flash.
  - **Codex 网关现已支持 DeepSeek V4 Flash**：Codex 路由和 DeepSeek 平台预设现在同时提供 V4 Pro 与 V4 Flash。
- **Dedicated DeepSeek Codex provider profile**: DeepSeek models use a Responses provider that explicitly disables WebSocket transport and keeps HTTP/SSE streaming.
  - **独立的 DeepSeek Codex provider profile**：DeepSeek 模型使用专门的 Responses provider，明确关闭 WebSocket，并保留 HTTP/SSE 流式传输。
- **Model-specific Codex settings**: DeepSeek profiles use a 1,048,576-token context window, a 95% automatic compaction threshold, and `high` reasoning effort.
  - **按模型配置 Codex 参数**：DeepSeek profile 使用 1,048,576 token 上下文、95% 自动压缩阈值和 `high` 推理档位。

## Compatibility / 兼容性

- **Mixed GPT and DeepSeek profiles remain available**: OmniProxy keeps Codex's built-in OpenAI provider for GPT profiles instead of replacing the global model catalog.
  - **继续支持 GPT 与 DeepSeek 混合 profile**：OmniProxy 为 GPT profile 保留 Codex 内置 OpenAI provider，不替换全局模型目录。
- **Official DeepSeek direct configuration is migrated safely**: One-click configuration removes an active DeepSeek-only `model_catalog_json` reference and direct provider section from the generated config. The original configuration remains in the existing OmniProxy backup.
  - **安全迁移 DeepSeek 官方直连配置**：一键配置会从生成后的配置中移除仅含 DeepSeek 的 `model_catalog_json` 引用和直连 provider；原配置仍保存在既有 OmniProxy 备份中。
- **ChatGPT and API login modes remain supported**: The DeepSeek provider reuses Codex authentication only for the loopback OmniProxy connection; upstream DeepSeek credentials continue to come from the OmniProxy account pool.
  - **继续支持 ChatGPT 与 API 登录模式**：DeepSeek provider 仅复用 Codex 认证连接本机 OmniProxy；上游 DeepSeek 凭据仍由 OmniProxy 账号池提供。

## Regression Coverage / 回归测试

- Added an end-to-end test for `/codex/v1/responses` routing to DeepSeek `/v1/responses`.
  - 新增 `/codex/v1/responses` 到 DeepSeek `/v1/responses` 的端到端路由测试。
- The test covers API-key injection, request-body passthrough, SSE events, apply-patch tools, and token/cache usage recording.
  - 测试覆盖 API Key 注入、请求体透传、SSE 事件、apply-patch 工具以及 token/缓存用量记录。
- Frontend regression coverage verifies that DeepSeek V4 Flash is selectable for Codex.
  - 前端回归测试确认 Codex 可选择 DeepSeek V4 Flash。

## Upgrade Guidance / 升级说明

- After installing this beta, run Codex one-click configuration again to write the new provider profiles.
  - 安装本 beta 后，请重新执行一次 Codex 一键配置，以写入新的 provider profiles。
- Restart Codex CLI, the IDE extension, or the desktop client after reconfiguration.
  - 重新配置后，请重启 Codex CLI、IDE 扩展或桌面客户端。
- No OmniProxy account-pool or request-history migration is required.
  - 无需迁移 OmniProxy 账号池或请求历史。
