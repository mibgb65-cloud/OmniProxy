# v1.3.1-beta.2 - Atria provider support / Atria 服务商接入

This beta adds Atria (`https://api.atria-asi.ai`) as a first-class provider. Multiple accounts, failure retry across keys, and automatic rotation work through the existing token pool, and Atria is available in the gateway route presets.

本次 Beta 将 Atria（`https://api.atria-asi.ai`）接入为一等公民服务商，复用现有令牌池实现多账号、失败重试与自动轮换，并可在网关路由预设中选择。

## Features And Fixes / 新增与修复

- Added a dedicated `atria` provider with its own base URL setting (defaults to `https://api.atria-asi.ai`) that is persisted to the local config file.
  - 新增 `atria` 服务商，拥有独立的 Base URL 设置（默认 `https://api.atria-asi.ai`）并持久化到本地配置文件。
- Atria API keys must start with `atr_`; the token editor shows a matching placeholder and rejects other prefixes.
  - Atria API Key 必须以 `atr_` 开头，令牌编辑器提供对应输入提示并拒绝其他前缀。
- Both protocols are supported on the same base URL: OpenAI-compatible requests at `/atria/v1` (Bearer auth) and Anthropic-compatible requests at `/atria/anthropic/v1` (`x-api-key` plus `anthropic-version: 2023-06-01`).
  - 同一 Base URL 同时支持两种协议：OpenAI 兼容请求走 `/atria/v1`（Bearer 鉴权），Anthropic 兼容请求走 `/atria/anthropic/v1`（`x-api-key` 加 `anthropic-version: 2023-06-01`）。
- Token validation uses `GET /v1/models`, so the account list reports connectivity and the model list for each key.
  - 令牌校验通过 `GET /v1/models` 完成，账号列表可显示连通性与模型列表。
- Atria is included in the codex, OpenAI, Claude, and model-route gateway provider sets, in the platform and strategy presets, and in outbound proxy and client tool mappings.
  - Atria 已加入 codex、OpenAI、Claude 与模型路由的网关 provider 集合、平台及策略预设，以及出站代理与客户端工具映射。

## Upgrade Guidance / 升级说明

- Add Atria accounts under the Atria provider in the token list, then select Atria in the gateway route presets or a custom route. No data migration is required.
  - 在令牌列表的 Atria 服务商下添加账号，然后在网关路由预设或自定义路由中选择 Atria；无需数据迁移。
- Atria has no documented balance or quota endpoint, so the quota view can only show connectivity plus cumulative token usage from response `usage` fields, not a remaining balance percentage.
  - Atria 文档未提供余额或配额查询接口，额度视图只能显示连通性与响应 `usage` 字段累计的 token 用量，无法显示剩余余额百分比。
- Live upstream requests and installer upgrade checks have not been performed locally for this beta; only the documented endpoints and key prefix were verified.
  - 本次 Beta 尚未在本地完成真实上游请求与安装包升级验证，仅核对了文档所列端点与 Key 前缀。
