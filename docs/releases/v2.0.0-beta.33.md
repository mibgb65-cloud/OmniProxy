# OmniProxy v2.0.0-beta.33

本版为 Windows amd64 production 本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

相对 Beta.32 只有两处改动：安装时可以自己选数据放哪，通用设置里的两个开关终于长得一样了。无新增数据库迁移，`app.json` 结构未变。

## 1. 安装时可选数据存储位置

安装向导在「选择安装目录」之后多了「数据存储位置」一页：

- **留空 = 保持现状**，仍然使用当前 Windows 用户的应用数据目录（`%APPDATA%\OmniProxy`）。
- 选择其他目录后，安装目录下写入 `data-dir.txt`；程序首次启动即在所选目录建库。
- 覆盖安装会预填既有选择，留空不会把已选的位置重置；静默升级（自动更新）不显示该页，也不改写这个文件。
- 卸载删除 `data-dir.txt`，账号与数据库始终保留。

数据目录的解析顺序变为：

```text
OMNIPROXY_DATA_DIR  >  app.json 的 dataDir  >  安装目录的 data-dir.txt  >  %APPDATA%\OmniProxy
```

因此**安装时的选择只是建议值**：你在应用内「数据存储 → 数据主目录」改过的位置永远优先，重装或自动更新都不会把你搬走的数据目录打回系统盘。

已知边界：

- 安装包是机器级的（`Program Files` + UAC 提权），数据目录是每用户的，所以安装时的选择对「尚未自行选择过的 Windows 用户」生效；多用户共享同一台机器时，每个人都可以在应用内改回自己的位置。
- 目标目录由程序首次启动时按当前用户身份创建，不在安装阶段创建（避免出现管理员属主的目录）。目录不可创建时回落到默认位置，并在日志中记录原因。
- 已经在应用内设置过数据位置的用户（`app.json` 里有 `dataDir`），安装页的选择不会生效——要挪位置请用应用内的搬家流程，它会在退出时搬迁现有数据。

## 2. 通用设置的桌面行为开关统一

「开机自启动」原来是自己手写的一套开关（深色下开启态是近白色、尺寸 44×24），「启动软件时自动启动网关」用的是共享组件（蓝色、36×20），同一张卡片里两个开关颜色和尺寸都不一样。

现在两者都由共享 `Switch` 组件渲染：颜色、尺寸、滑块、圆角、聚焦环完全一致，行为不变（整行可点击、保存失败回滚、开发环境禁用并说明原因）。同时加了回归测试，两个开关的类名必须相同。

## 兼容与已知边界

- 无数据库迁移；沿用 Beta.32 的 Codex v1 透明转发与网关托管登录。
- 安装器未签名、未自动安装、未打标签、未推送。

## 安装与数据保留

先从托盘完全退出旧版，备份数据目录后覆盖安装。安装后在「设置与关于」核对版本为 2.0.0-beta.33。
