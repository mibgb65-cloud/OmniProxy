# OmniProxy v2.2.1-beta.3 - 重置卡按钮可用性修正 / Reset-credit buttons actually usable

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对本地 `v2.2.1-beta.2`，本次修正「重置卡」面板里「使用这张卡」按钮变灰、点不动的问题。

## 修复 / Fixes

- **「使用这张卡」不再无故变灰**：卡片的「可使用」徽标此前只看官方状态，按钮却还要求
  `reset_type` 等于字面量 `codexRateLimits`。官方对该字段的写法（大小写、下划线）不一致时，
  就出现「写着可使用、按钮是灰的」。现在徽标与按钮共用同一判定，类型只做写法归一。
  - **Usable cards are clickable**: the badge looked at the official status while the button also
    required an exact `reset_type` literal. Both now share one predicate that normalizes spelling.
- **后端同步放宽**：兑换前的可用性检查同样按归一后的类型判断，避免界面放行后被后端以
  「这张卡当前不可使用」拒绝；过期、已使用、明显属于其他权益的卡仍然拒绝。
  - **Backend matches**: the pre-consume check normalizes the type the same way; expired,
    redeemed and clearly foreign credits are still rejected.
- **刷新按钮不再长时间变灰**：之前只要额度查询在途就被禁用（官方读取可能要十几秒），
  期间没有任何反馈。现在刷新始终可用（仅兑换进行中禁用），读取中图标旋转。
  - **Refresh stays available**: it is no longer disabled while a quota read is in flight;
    the icon spins instead.
- **核对记录时给出说明**：读取「最近一次使用记录」期间显示「正在核对最近一次使用记录…」，
  不再只是把按钮变灰。
  - **Explained waiting state**: a short line appears while the latest redemption is checked.

## 升级说明 / Upgrade notes

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- Windows 数字版本仍为 `2.2.1.0`；完整版本递增至 `2.2.1-beta.3`。
- 无新增数据库迁移、无新增依赖，安装身份与数据目录沿用既有设置。
