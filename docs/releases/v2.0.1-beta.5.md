# OmniProxy v2.0.1-beta.5

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 界面：账号概览页改为 Bento 原位展开 + 底部切换 Dock

账号概览不再「点卡片跳到另一个页面」，改成在同一页里展开：

- 点击任意提供商卡片（标题或卡片空白处），该卡片在网格顶部横向撑满，就地展开完整的账号／额度
  详情：账号卡片（含余额、订阅额度、重置卡等既有内容）、提供商设置入口、卡片／列表切换、
  添加账号按钮都在面板内，行为与原来的详情页一致。
- 其余提供商以 600ms `cubic-bezier(0.22, 1, 0.36, 1)` 的 FLIP 过渡压缩重排到页面底部，
  变成一排紧凑的迷你切换卡片（Dock），只保留品牌图标、名称与账号数。
- 点击 Dock 任意迷你卡即在上方面板切换查看该提供商：被点中的迷你卡放大成面板，
  原来的面板同帧压缩回 Dock，全程 600ms 连续过渡，没有淡出淡入的空白帧。
- 面板内的「返回账号」收起回卡片墙，收起同样走这段 600ms 过渡（面板缩回卡片、Dock 卡片长回网格）。
- 过渡期间卡片内容会短暂淡化再呈现，避免大尺寸缩放把文字压扁；系统要求「减少动画」时直接切换布局。
- 地址栏在展开／切换／收起时都不变；直接打开 `/accounts/<providerId>` 深链接仍进入原来的独立详情页。

## 其他

- 卡片标题由链接改为按钮（不再有跳转），整卡可点击；卡片内的「添加账号」「启停」「删除」「编辑」
  等控件不会误触发展开。
- 展开后焦点移到面板、收起后回到该提供商卡片，键盘操作不会丢失位置。
- 文档与任务记录归档；无新增依赖（FLIP 用浏览器原生 `getBoundingClientRect` + `Element.animate`）。

## 升级说明

- 覆盖安装即可，无新增数据库迁移、无新增依赖、无后端接口变化。
- 数字版本仍是 `2.0.1.0`（同一 patch 的 beta 递增不改数字版本），安装身份、安装目录与数据目录
  沿用原设置；路由、别名、账号、客户端配置、用量、额度留存快照与重置操作记录保持不变。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 展开／压缩／切换的实际观感（600ms 节奏、宽窗多列与窄窗单列、140% 字号）只在单元与集成测试、
  构建产物层面核对，**尚未在真实窗口人工验收**；节奏不合适时只需调整
  `use-flip-reflow.ts` 的默认时长一个常量。
- 同一时刻只有一个提供商展开；不含拖拽排序或多选展开。
- 概览页仍按容器宽度自适应列数（宽窗多列），展开面板与 Dock 始终横跨整行。
