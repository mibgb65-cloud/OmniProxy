# v1.2.7-beta.3 - Automatic Codex browser authorization / Codex 浏览器授权自动完成

This beta streamlines Codex browser login by detecting the local OAuth callback automatically, importing the authorized account without an extra confirmation step, and allowing an expired or unwanted login link to be refreshed in place.

本次 beta 优化 Codex 浏览器登录流程：自动检测本地 OAuth 回调，无需额外确认即可导入已授权账号，并可直接在弹窗内刷新过期或不再需要的登录链接。

## Features / 新特性

- **Automatic authorization detection**: OmniProxy checks the active Codex login session in the background and automatically exchanges and imports credentials as soon as the browser callback arrives.
  - **自动识别授权结果**：OmniProxy 会在后台检查当前 Codex 登录会话，浏览器回调到达后立即自动交换并导入凭据。
- **Refresh login link in place**: The login dialog now provides a refresh button that invalidates the previous OAuth session and generates a new PKCE login link without closing and reopening the dialog.
  - **弹窗内刷新登录链接**：登录弹窗新增刷新按钮，会废弃旧 OAuth 会话并生成新的 PKCE 登录链接，无需关闭后重新打开弹窗。

## Bug Fixes / 问题修复

- **Non-blocking manual check**: The manual fallback checks callback readiness before completing the login, so clicking it before browser authorization no longer leaves the interface waiting for the full session timeout.
  - **非阻塞手动检查**：手动兜底操作会先检查回调是否到达，未完成浏览器授权时不再让界面一直等待到会话超时。
- **Real session replacement**: Regenerating a login link now closes and invalidates the previous callback session instead of returning the same still-active URL.
  - **真正替换登录会话**：重新生成链接时会关闭并废弃原回调会话，不再返回同一个仍处于活动状态的旧链接。
- **Clear authorization feedback**: Dialog and browser callback messages now explain that OmniProxy is detecting and importing the account automatically, while preserving a manual check as a fallback.
  - **清晰的授权反馈**：弹窗与浏览器回调页面会明确提示 OmniProxy 正在自动识别并导入账号，同时保留手动检查作为兜底。

## Refactor & Performance / 重构与优化

  - 补充刷新登录链接、回调检测、自动导入凭据和过期会话处理的回归测试。
