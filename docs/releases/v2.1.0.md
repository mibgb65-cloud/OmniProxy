# v2.1.0 - Gateway port management and account experience / 网关端口管理与账号体验升级

This stable release for Windows 10/11 amd64 compares against the previous public stable release, `v2.0.0`, and includes the changes tested in local `2.0.1-beta.1` through `beta.7` builds.

本次 Windows 10／11 amd64 正式版以此前公开正式版 `v2.0.0` 为比较基线，汇总本地 `2.0.1-beta.1` 至 `beta.7` 的变更，需要 WebView2。

## Features / 新特性

- **Gateway port management**: Configure, save or restore the local gateway port from Settings. Port conflicts use a bounded search for an available alternative, including gateway autostart, and persist the selected port.
  - **网关端口管理**：在设置页修改、保存或恢复本地网关默认端口；端口冲突时有界查找可用替代端口并保存，支持启动自动启动时避让。
- **Managed client integration**: Port changes update managed client configurations only when their contents still match the application's recorded revision. Externally modified configurations are preserved and reported for manual action. `OMNIPROXY_PROXY_PORT` remains authoritative and makes the setting read-only.
  - **受管客户端联动**：换端口时仅同步内容仍与应用登记版本一致的受管客户端配置；外部修改的配置保持原样并提示手动处理。`OMNIPROXY_PROXY_PORT` 仍优先，生效时界面只读。
- **Accounts workspace**: Expand provider cards in place with the Bento layout and switch providers through a horizontally scrollable bottom Dock, preserving direct detail links, keyboard navigation and reduced-motion preferences.
  - **账号工作区**：提供商卡片采用 Bento 原位展开，通过可横向滚动的底部 Dock 切换提供商，保留详情深链接、键盘导航与减少动画偏好。
- **Model catalogs**: Refresh the OpenAI featured-model presets and add River `Qwen/Qwen3.8-27B-FP8` and `moonshotai/Kimi-K3`, including their model identities, limits and supported reasoning controls.
  - **模型目录**：更新 OpenAI 推荐模型预设，River 新增 `Qwen/Qwen3.8-27B-FP8` 与 `moonshotai/Kimi-K3`，补齐模型身份、容量及已支持的推理档位。

## Bug Fixes / 问题修复

- **Token accounting**: Fix missing usage records in transparent HTTP forwarding, with regression coverage for JSON, streaming responses and accounting failures.
  - **Token 记账**：修复 HTTP 透明转发的用量漏记，增加 JSON、流式响应与记账失败的回归覆盖。
- **Reset-credit display**: Read reset-credit counts and details from the official HTTP summary when displaying or refreshing quota. A reset-credit failure does not discard otherwise available quota windows; background quota reads do not add this request.
  - **重置卡显示**：显示或刷新额度时从官方 HTTP 汇总读取重置卡数量与明细；重置卡读取失败不影响已获取的额度窗口，后台额度读取不额外请求该接口。
- **Account animations and Dock layering**: Fix Bento expansion flicker, animation copies crossing into the sidebar or title bar after horizontal scrolling, and overlapping account text and provider icons.
  - **账号动画与 Dock 分层**：修复 Bento 展开闪动、横向滚动后动画副本侵入侧栏或标题栏，以及账号文字与提供商图标重叠。
- **Quota observation tests**: Replace a timing-dependent test assumption with an explicit publication-completion barrier.
  - **额度观察测试**：通过明确的发布完成屏障消除测试中的时序依赖。

## Breaking Changes / 不兼容更新

None / 无。Relative to v2.0.0, this release adds no database migrations or dependencies and preserves installation identity and data locations.

相对 v2.0.0，本版无新增数据库迁移或依赖，沿用安装身份及数据位置。

## Refactor & Performance / 重构与优化

- **Theme and navigation**: Add a click-origin circular theme transition and a sliding sidebar selection indicator, with reduced-motion fallback.
  - **主题与导航**：主题切换采用基于点击位置的圆形扩散过渡，侧栏选中态使用滑动背景，并兼容减少动画偏好。
- **Request history**: Keep scrolling inside the request table and use the shared thin horizontal scrollbar.
  - **请求历史**：滚动限制在请求表格内部，横向滚动条统一为细滑块。
- **Interruptible layout transitions**: Reuse native browser animation APIs for account transitions and bound animation copies to their owning viewport without adding animation dependencies.
  - **可打断布局过渡**：复用浏览器原生动画 API，将账号动画副本约束在所属视口内，不新增动画依赖。

## Upgrade notes / 升级说明

- Exit the app normally and make a consistent data-directory backup, including SQLite WAL, before upgrading. No account re-import or data-directory relocation is required when upgrading from v2.0.0.
  - 升级前正常退出应用，做包含 SQLite WAL 的一致性数据备份。从 v2.0.0 升级无需重新导入账号或搬迁数据目录。
- Saving a different port restarts a running gateway and cancels in-flight requests. Check the actual selected port after conflict avoidance and follow any manual client-reconfiguration prompts.
  - 保存不同端口会重启正在运行的网关并取消在途请求；自动避让后请确认实际端口，按提示处理需手动重新配置的客户端。
- Application and installer version: `2.1.0`; Windows numeric resource version: `2.1.0.0`. This stable version supersedes the local `2.0.1-beta.*` builds.
  - 应用与安装器版本为 `2.1.0`，Windows 数字资源为 `2.1.0.0`；本正式版高于此前本地 `2.0.1-beta.*`。

## Release verification and limits / 发布校验与边界

- Public assets are built by GitHub Actions. The installer is self-signed with the pinned project certificate; signature, certificate pin, tamper rejection and final SHA256 are checked before publication. Local unsigned validation packages are not uploaded as public release assets.
  - 公开资产由 GitHub Actions 构建，安装器使用固定项目证书自签；公开前校验签名、证书 pin、篡改拒绝和最终 SHA256。本地未签名验证包不作为公开发布资产。
- Self-signing is not publicly trusted CA signing and may still trigger SmartScreen or unknown-publisher warnings. The application executable is not separately signed, and the installer does not import the public certificate into the user's trust stores.
  - 自签不等同于公开受信任 CA 签名，仍可能触发 SmartScreen／未知发布者提示；应用本体暂不单独签名，安装器不会向用户信任库导入公开证书。
- Automated tests and isolated browser checks do not establish acceptance of real in-place upgrades, final native-window visuals, live client port switching or the official reset-credit endpoint with real accounts. These remain separate manual checks.
  - 自动测试和隔离浏览器检查不能替代真实覆盖安装、原生窗口最终观感、真实客户端换端口及真实账号官方重置卡接口验收；这些仍需独立人工确认。
