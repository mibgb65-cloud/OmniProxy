# OmniProxy v2.2.1-beta.2 - 账号页切换提供商栏真正固定 / Provider dock pinned on the accounts page

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对本地 `v2.2.1-beta.1`，本次修正账号页展开态的滚动归属：底部「切换提供商」栏不再随页面滚动向上移动。

## 修复 / Fixes

- **「切换提供商」栏不再上移**：展开某个提供商后，页面本身被锁定为不可滚动，只有中间的详情区域可以滚动；停靠栏始终贴在内容区底部。
  - **Dock stays put**: expanding a provider locks the page scroller, so only the detail region between the header and the dock scrolls.
- **展开时从头开始**：之前在折叠网格里滚动过再展开，会沿用旧的滚动偏移；现在展开第一屏总是回到顶部。
  - **Expanded view starts at the top**: a previously scrolled provider grid no longer carries its offset into the expanded layout.
- **不再依赖 `:has()` 推断结构**：Dock 是否存在由组件显式声明（`data-has-dock`），两行网格的分配不随选择器支持情况变化。
  - **No structural inference**: the dock row is declared by the component instead of being inferred with `:has()`.

## 实现要点 / Implementation notes

- 展开时给外层滚动区打 `data-locked`，其视口改为 `overflow-y: clip`：`clip` 连程序化 `scrollTop` 也不允许，
  因此即便滚动内容里残留了别的元素，也无法把整页（连同停靠栏）带走。
- 覆盖层自身 `overflow: clip`，任何遗留溢出都不会变成页面滚动范围。
- 详情区仍是独立的 `ScrollRegion`，内部滚动与既有的滚动位置恢复互不影响。

## 升级说明 / Upgrade notes

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- Windows 数字版本仍为 `2.2.1.0`；完整版本递增至 `2.2.1-beta.2`，高于公开的 `2.2.0` 与本地 `2.2.1-beta.1`。
- 安装身份、安装目录与数据目录沿用既有设置；无新增数据库迁移、无新增依赖。
