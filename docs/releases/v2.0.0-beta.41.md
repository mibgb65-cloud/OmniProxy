# OmniProxy v2.0.0-beta.41

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 界面

- **左侧边栏通顶，全窗口只保留一个品牌标识**。此前标题栏横跨全屏、左侧还带一个小 Logo，
  与侧栏顶部的品牌重复。现在：
  - 侧栏占满窗口 100% 高度，品牌（图标 + `OmniProxy`）只在左上角出现一次；
  - 折叠按钮移到品牌栏右侧；收起后整行品牌栏就是「展开」按钮，悬停或键盘聚焦时切换为展开图标；
  - 标题栏只覆盖内容区，双击最大化与拖动行为不变。
- **River 账号卡片不再闪烁提示行**。请求进行中时，卡片底部的「包含进行中或用量未完整返回的
  请求，当前数值仅为已记录用量。」会随每次用量刷新反复出现／消失，卡片高度跟着跳动。现在：
  - API Key 与「已启用」徽标之间固定一个 16px 槽位，有请求正在进行时显示旋转圆环，其余时间留空，
    徽标位置不移动，卡片高度恒定；
  - 鼠标悬浮（或键盘聚焦）圆环时提示「该 API Key 正在使用中」；
  - 判断依据改为「此刻仍在进行中的请求」（新增 `pendingRequests`），历史未完整记录不再被当成
    「正在使用」；圆环在请求之间保留 1.2 秒，连续请求不会闪断；
  - 表格视图的状态列同步显示同一圆环；Token 数值与 `≥` 前缀规则未变。

## 升级说明

- 覆盖安装即可，无新增数据库迁移。
- 已有的路由、别名、账号、客户端配置、用量与额度留存快照保持不变。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 流式响应结束前记录一直处于「进行中」，因此圆环会覆盖整个流式过程。
- 若进程异常退出留下陈旧的「进行中」记录，仍由启动时的恢复逻辑（10 分钟）收口。
- 浅色主题与 80%／140% 字号下的圆环与提示框位置待本机视觉验收。
