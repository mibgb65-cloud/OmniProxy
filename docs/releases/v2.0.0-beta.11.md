# OmniProxy v2.0.0-beta.11（本地生产安装版）

本版修复 Codex 长会话中断后反复出现 `invalid_request` 的问题，同时包含 Beta.10 之后已完成的授权进度、账号删除和 OpenAI 轮换设置优化。使用 production 标签构建 Windows amd64 NSIS 安装包，仅供本地覆盖更新测试，不发布远端或自动安装。

## Codex 长会话恢复

- Responses 与上下文压缩请求不再套用 512 条消息限制；推理、工具调用及结果可随完整历史一起转发，不删减或截断上下文。仍保留 16 MiB 请求、JSON 深度、并发与流容量保护，其他协议的消息数量限制不变。
- 流中断后允许客户端重新连接并显式回放完整历史；保留连接内增量续写和未知 response ID 校验，不增加后台模型请求、隐式账号重试或自动重放生成。
- WebSocket 保留具体校验错误码，并在重编码前检查原始帧，拒绝重复 JSON 字段。读流失败、事件超大和客户端写入失败分别分类，不再把这些问题误报成凭据不可用；日志不记录正文或凭据。
- 已覆盖部分输出后回放 516 项历史及继续对话的隔离回归。最初历史断流的底层诱因无法从旧日志还原，真实长会话与上游网络仍需安装后验收，不承诺网络永不中断。

## 授权进度与账号管理

- 登录弹窗展示真实授权处理阶段，提供复制登录链接和轮询恢复，避免网页授权完成后仍一直显示等待。
- ChatGPT 账号删除仅清理本地托管授权，不启动官方组件或调用远端退出；显式退出登录仍为独立操作。

## OpenAI 账号轮换设置

- 提供持久保存的队列／平衡模式，默认队列保持兼容；平衡模式优先使用新鲜、可比较的额度观察，否则等权分配。
- 保留固定账号、额度耗尽和开始生成后不重放的保护；不因切换模式增加额度探测或模型调用。
- 精简设置补充说明，检测摘要使用去重的全局提示。数据库迁移 035 保存轮换设置，安装后按既有流程升级，不清空账号数据。

## 安装与验收边界

由用户自行退出旧版并运行安装包，沿用已有安装身份、目录和数据保留流程；安装后在关于页确认版本为 2.0.0-beta.11。让 Codex 重新连接更新后的网关，再在原聊天尝试继续，确认不再因历史超过 512 项被本地拒绝。

本版未包含额度与重置时间跨重启快照持久化，该独立任务仍未实现。无新增业务依赖，不修改真实客户端配置或默认登录。真实 OAuth、覆盖升级、账号轮换效果和原生界面仍由用户本地验收，离线回归不替代这些验证。

本地安装包未签名，Windows 可能提示未知发布者；机器级安装需要管理员确认。构建过程不停止或替换生产程序，不自动运行安装器。
