# OmniProxy v2.0.0-beta.1

Wails v3 与 React 桌面版的首个 Windows Beta。

**覆盖升级已知问题：**部分机器的旧统计库与新版同名 `request_records` 表冲突，可能导致安装后无法启动；桌面图标也可能沿用旧缓存。不要删除数据库或 WAL。修复已在 [v2.0.0-beta.2](https://github.com/mibgb65-cloud/OmniProxy/releases/tag/v2.0.0-beta.2) 发布，请升级新版。受影响用户需先做一致性备份，再按 [升级说明](https://github.com/mibgb65-cloud/OmniProxy/blob/main/docs/product/UPGRADE.md) 处理独立目录和主动账号导入。已公开的 Beta.1 标签及资产保持原样。

- 新版账号管理、提供商、模型路由、本地网关、用量与额度界面。
- 可预览、去重并重试的 v1 兼容 API Key 导入；旧数据始终保留。
- 正式／Beta 渠道、侧栏升级标记、版本浮窗、安装器下载进度、SHA256 校验和重启静默更新。
- 覆盖安装复用旧安装目录，正常关闭目标应用并保留本地数据；卸载保留账号、配置、历史及未知文件。

当前发布目标为 Windows amd64。订阅账号需重新登录，部分旧计费／自定义地址需手工确认；历史统计、路由和客户端备份不做整库迁移。各提供商与客户端的实测范围见产品文档。

请将安装器与同名 `.sha256` 一起下载并校验。签名状态以产物数字签名为准，本流程尚未接入代码签名。

已知问题：本版选择「仅正式版」时检查更新可能返回查询失败，原因是请求路径编码；修复已包含在 Beta.2。Beta.1 请保留默认的「正式版与 Beta 测试版」渠道并升级到 Beta.2，该渠道及安装包下载已完成公开源验证。
