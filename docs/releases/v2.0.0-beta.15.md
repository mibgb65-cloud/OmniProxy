# OmniProxy v2.0.0-beta.15

本版为 Windows amd64 production 构建的本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

## Claude 长会话修复

- 修复 Claude Messages 转为 River Chat 后，工具结果和提醒展开成更多消息、触发旧 512 条限制的本地误拒绝。
- Messages 入口与共享 Chat 校验采用 100,000 条安全上限，仍保留请求体、JSON 深度、重复字段、角色及工具字段校验。
- 可信 Messages 转换沿用 16 MiB 容量，不再误用普通 Chat 的 2 MiB／单条 1 MiB 限制；普通外部 Chat 保护不放宽，客户端不能伪造内部转换标记。
- 不截断、不丢弃工具结果、不自动压缩或重放真实历史。合成回归验证了源消息少于 512、转换后 513 条的场景；原失败请求未保存，不宣称现场精确条数或真实会话续接已验收。
- 保留原有图片及未知工具类型边界，上游实际 Token 上下文限制仍然有效；本版不保证无限长会话，也不自动执行截图中其他项目的命令。

## 额度展示与 Token 用量

- Codex 5h／一周美元估算改为左右同行、单值显示，移除原折叠说明。
- 历史缓存明细未知时不计缓存折扣；这是 API 等值参考估算，不是官方美元余额或套餐承诺。
- 下方增加输入／输出／缓存 Token 三列，使用紧凑单位并可查看完整整数。统计仅覆盖当前身份的本机留存代理记录，不代表所有客户端或账号全生命周期用量。
- 缓存已包含在输入中，不重复相加；未知缓存显示 `—`，部分缺失时显示已知下界，不伪造为零。

## Google 额度留存

- Google／Antigravity 公开额度分组、百分比与绝对重置时间写入本机数据库；更新后成功读取一次，即可在切页或重启后先恢复，再联网刷新。
- 刷新失败不清空旧显示，留存值标为待刷新，不计作已确认的当前额度，也不参与调度或权限判断。
- 按账号身份与授权版本隔离，普通令牌轮换在事务内保留；退出登录隐藏，重新授权不复用旧版本，账号删除级联清理。
- 不保存真实令牌或原始上游响应；本地恢复不等待可能联网的刷新锁。区分“已保留数据”和“已到官方重置时间”，避免错误提示。

## River 使用方式与失败切换

- River 账号页新增设置按钮，支持自动持久保存“队列使用／均衡使用”，默认队列，对后续请求立即生效。
- 均衡方式在同池健康 Key 间轮流分配新请求，均衡请求数而非保证 Token 消耗完全相等。
- 明确认证失败、余额不足及限流沿用安全切换；一分钟内连续两次网络／5xx 失败后，暂时冷却该账号／版本／模型 30 秒，后续请求使用其他可用 Key。
- 沿用网关“账号故障切换”总开关，固定账号不切换，不跨服务商或模型回退；结果不确定或已开始输出的当前请求不盲目重放。

## 安装与数据保留

更新前建议保留包含 SQLite WAL 的一致性数据备份。从托盘完全退出旧版后，运行本安装包覆盖更新，安装后在“设置与关于”确认版本为 2.0.0-beta.15。

本版继承 Beta.14 的数据和安装身份，启动时执行数据库迁移 038／039，新增 Google 公开额度快照和 River 非敏感设置，不清空已有账号、请求历史或累计统计。不建议让旧版本继续写入升级后的同一数据库。

本版不自动运行本地 Codex 登录同步试验工具，不改写真实客户端登录或重启 Claude／Codex Desktop；客户端发送前的独立额度门禁仍须单独验收。

本地安装包未签名，Windows 可能提示未知发布者，机器级安装需要管理员确认。构建过程不自动安装或停止生产应用，不上传发布；真实覆盖安装、账号数据保留及原聊天续接仍由用户本地验收。
