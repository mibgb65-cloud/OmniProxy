# OmniProxy v2.0.0-beta.19

本版为 Windows amd64 production 本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

## Codex Fast 模式入口修复

- 修复新版统一模型目录遗漏官方服务档位信息，导致 GPT 模型旁 Fast 闪电入口消失的问题。
- 同步并保留官方确认的服务档位、名称及说明；路由别名按实际目标账号继承能力，不给第三方模型或未知账号伪造 Fast 支持。
- 不自动开启 Fast，不改变现有服务档位选择；原生 Responses 转发保留用户选择的档位，实际速度、可用性与额度消耗仍由上游决定。
- 更新后在路由页为 OpenAI 账号执行「同步官方模型」，成功后刷新已接入且未被外部修改的受管目录；运行中的 Codex 需要重新加载模型菜单，必要时由用户重新打开客户端。旧快照缺少能力字段时不会凭空声明 Fast。

## 项目与协议正式入口

- 关于页接通官网、开源仓库、免责声明、使用协议和隐私政策五项固定 HTTPS 入口，在系统默认浏览器打开，不在应用内加载协议正文。
- 增加等待期间防重复操作、可重试的安全错误提示，支持中英文与键盘操作，不暴露浏览器底层启动详情。
- 官网已发布三份独立静态协议，补齐页脚导航，修正旧技术栈及安全模型链接；已核验独立标题和正文，避免把 HTTP 200 首页回退当作协议上线。
- 五个入口已完成深浅主题及紧凑原生窗口检查。协议说明依据当前实现编写，不指定未确认的软件许可证或运营主体，也不替代专业法律审核。

## 兼容与已知边界

- 继承 Beta.18 的 Codex 授权解密缓存、独立周额度估算及卡片精简；冷解密或缓存失效时仍可能短暂需要约 1 GiB，美元估算不是官方余额。
- 不新增数据库迁移，不改变安装身份、已有凭据格式、账号启用状态、路由选择或客户端登录。
- Google 上游 `429 / RESOURCE_EXHAUSTED` 仍是独立调查项，本版不宣称解除限流；Codex 旧聊天兼容及真实模型调用也仍需在实际客户端中验收。
- 构建、专项回归及原生检查使用隔离环境，不以本地测试代替真实覆盖安装、上游授权或模型加速效果。

## 安装与数据保留

先从托盘完全退出旧版，再为整个数据目录保留一致性备份，随后运行本安装包覆盖原安装目录，无需先卸载旧版或删除账号数据。安装后在“设置与关于”核对版本为 2.0.0-beta.19。

本版沿用现有安装目录、账号、数据库、设置、请求历史与累计统计，不主动清空数据，不自动重启 Claude／Codex Desktop；不要同时启动新旧版本写入同一数据目录。

本地安装包未签名，Windows 可能提示未知发布者，机器级安装需要管理员确认。构建过程不自动安装、停止或替换生产应用，不上传公开发布；真实覆盖安装与数据保留由用户本地验收。
