# OmniProxy v2.0.1-beta.4

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 界面：侧栏导航选中态改为滑动背景

侧栏九个导航项（仪表盘／账号／提供商／网关／路由／配额／用量／请求／日志）的选中背景不再
就地消失和出现，而是一块独立的圆角背景块在条目之间滑动：

- 点击切换时背景块以 450ms、`cubic-bezier(0.22, 1, 0.36, 1)` 的阻尼缓动纵向滑动到新条目；
  相邻切换与「仪表盘」→「日志」这类跨项点击都是同一段平滑位移，不淡出淡入。
- 背景块位于图标与文字之下（`z-index: 0`）且不拦截点击；未选中项悬停只提亮文字与图标，
  不再整块变色，也不会盖住滑动中的背景。
- 位置与高度取自选中条目本身的真实布局，因此侧栏收展、全局字号缩放后会自动重新测量；
  首次挂载时先落位再启用过渡，不会出现从顶部滑下来的误触发动画。
- 选中判定沿用路由自身的结果（观察链接上的 `data-active`），嵌套路由（如账号详情页仍高亮
  「账号」）行为不变；系统要求「减少动画」时不做位移动画，直接到位。

## 其他

- 导航链接去掉自带悬停／选中底色，改为文字提亮 + 颜色过渡；行高、图标位置、收起态提示
  与键盘／无障碍名称均未变化。
- 文档与任务记录归档；产品行为无其它变化。

## 升级说明

- 覆盖安装即可，无新增数据库迁移、无新增依赖（未引入 Framer Motion 等动画库）。
- 数字版本仍是 `2.0.1.0`（同一 patch 的 beta 递增不改数字版本），安装身份、安装目录与数据目录
  沿用原设置；路由、别名、账号、客户端配置、用量、额度留存快照与重置操作记录保持不变。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 滑动背景的观感（相邻／跨项、键盘 Tab 切换、140% 字号、收起态）只在单元与集成测试、
  构建产物层面核对，**尚未在真实窗口人工验收**；若节奏不合适，只需调整
  `app-sidebar.css` 的 `--sidebar-indicator-duration`。
- 背景块随导航列表内容滚动，列表出现纵向滚动时同样适用，但滚动容器本身的行为未改。
