# v1.2.9-beta.4 - Team account identity fix / Team 账号身份修复

This beta prevents Codex OAuth logins from replacing another email account when both accounts belong to the same Team workspace and share a ChatGPT `account_id`.

本次 beta 修复 Codex OAuth 登录覆盖问题：当两个邮箱账号属于同一个 Team 工作区并共享 ChatGPT `account_id` 时，OmniProxy 现在会分别保留这两个账号。

## Bug Fixes / 问题修复

- **Different emails are retained separately**: Codex OAuth identity matching now checks the email before using `account_id`, so a shared Team workspace ID no longer causes one email account to overwrite another.
  - **不同邮箱会分别保留**：Codex OAuth 身份匹配现在会先核对邮箱，再使用 `account_id`；共享的 Team 工作区 ID 不会再导致一个邮箱账号覆盖另一个。
- **Existing account refresh behavior is preserved**: Logging in again with the same email and `account_id` still updates the stored credentials instead of creating a duplicate.
  - **保留现有账号刷新行为**：使用相同邮箱和 `account_id` 再次登录时，仍会更新已保存的凭证，不会创建重复账号。
- **Legacy data remains compatible**: If an older stored credential lacks an email, OmniProxy can still match it by `account_id` during refresh.
  - **兼容旧数据**：如果旧版保存的凭证缺少邮箱，OmniProxy 在刷新时仍可通过 `account_id` 匹配。
- **Regression coverage**: Added a test proving that two email accounts sharing one Team `account_id` remain stored independently and the first account is not modified.
  - **回归测试覆盖**：新增测试，确认共享同一 Team `account_id` 的两个邮箱会独立保存，且第一个账号不会被修改。

## Upgrade Guidance / 升级说明

- Accounts already overwritten by an older version cannot be restored automatically. After installing this beta, sign in again or import the missing email account once.
  - 旧版本已经覆盖的账号无法自动恢复。安装本 beta 后，请重新登录或导入一次缺失的邮箱账号。
- No account-pool or local-data migration is required.
  - 无需迁移账号池或本地数据。
