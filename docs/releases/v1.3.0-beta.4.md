# v1.3.0-beta.4 - Codex activation request compatibility hotfix / Codex 激活请求兼容性热修复

This beta fixes the activation failure reported after `v1.3.0-beta.3`. The ChatGPT Codex responses endpoint rejected the minimal activation request with `400 Unsupported parameter: max_output_tokens`.

本次 Beta 修复 `v1.3.0-beta.3` 发布后反馈的激活失败：ChatGPT Codex responses 上游会以 `400 Unsupported parameter: max_output_tokens` 拒绝最小激活请求。

## Fix / 修复

- Removed `max_output_tokens` from the dedicated Codex quota activation request while retaining the minimal prompt, low reasoning effort, streaming response, and disabled response storage.
  - 从专用 Codex 额度激活请求中移除 `max_output_tokens`，保留最小提示、低推理强度、流式响应和禁用响应存储。
- Added a regression assertion that the activation payload never sends this unsupported parameter.
  - 新增回归断言，确保激活请求不会再次发送该不兼容参数。

## Upgrade Guidance / 升级说明

- `v1.3.0-beta.3` users should upgrade to this build before retrying `立即激活` or automatic activation.
  - `v1.3.0-beta.3` 用户应升级到本版本后，再重试「立即激活」或自动激活。
- Existing accounts, quota data, and the automatic activation setting are preserved.
  - 现有账号、额度数据和自动激活设置均会保留。
- No account-pool or local-data migration is required.
  - 无需迁移账号池或本地数据。
