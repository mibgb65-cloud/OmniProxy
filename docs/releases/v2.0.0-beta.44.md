# OmniProxy v2.0.0-beta.44

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 改进：重做「网络代理」弹窗布局

Beta.43 的网络代理弹窗是一条 560px 宽的单列长表单：内容约 900px 高，标题和「保存」都会滚出
视野；13 行提供商分流挤在一条窄列里，行高只有 26px，三态按钮随提供商名长度左右浮动。

本版把它改成 **880px 两栏 + 固定头部 + 固定页脚**：

- **左栏「代理服务器」**：启用开关、协议、地址＋端口、用户名、密码、不走代理的地址，
  以及「探测本机代理」「测试」与结果，一屏可见。
- **右栏「使用代理的提供商」**：标题行右侧常驻「全部走代理／全部直连」；新增**按名称筛选**，
  列表自身独立滚动，行更宽松，三态控件固定右对齐成一列，不再随名字长度漂移。
- 列表下方常驻**计数摘要**：`共 N 个提供商 · 走代理 a · 直连 b · 跟随全局 c`；
  筛选时显示 `显示 x / N 个提供商`。
- **「保存／取消」固定在页脚**，滚到任何位置都能直接保存；保存失败的提示也随页脚常驻。
- 「清除密码」并入密码标签行，少占一行；字段标签降为更轻的说明文字，主输入框保持原高度。
- 窗口变窄时两栏自动堆叠成单栏，弹窗宽度随视口收敛。

## 行为与安全

- 接口、字段语义、三态取值（跟随全局／直连／走代理）与批量设置语义**完全不变**。
- 密码仍只存 Windows 凭据库（DPAPI），界面只显示「已保存」；错误文本继续脱敏。
- 端口范围校验、探测、测试结果分类、保存成功即关闭 / 失败留在弹窗内的行为均未改变。

## 升级说明

- 覆盖安装即可。**本版没有数据库迁移**，升级到 Beta.44 不会再动数据库结构。
- 回退到 Beta.43 安全，只是弹窗会退回旧的单栏布局。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 代理软件需自行保持运行；应用不管理它的进程与订阅。
- 实机代理端口（mixed／纯 SOCKS／纯 HTTP）下的弹窗交互仍需安装后本机验收。
