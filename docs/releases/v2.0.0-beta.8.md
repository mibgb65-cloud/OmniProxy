# OmniProxy v2.0.0-beta.8（本地生产安装版）

本版补齐额度查询前的官方授权续期并细分查询失败原因，包含更新页面与可选自动下载改进，保留 Beta.7 的混合订阅登录和 GUI 日志修复。本地使用 production 标签构建 NSIS 安装包，不发布 GitHub。

## 额度查询与授权续期

- 额度查询前先请求官方组件刷新授权并核验账号成员，再读取额度，避免额度链路缺少显式续期。
- 官方组件启动、续期和查询共用的预算由 10 秒调整为最多 30 秒，仍受接口总超时限制，不增加自动重试或独立定时续期任务。
- 区分查询超时、授权刷新失败和额度接口失败；日志仅包含固定阶段和稳定错误码，不记录账号身份、Token 或原始官方响应。
- 查询失败不注销账号或覆盖最后成功快照，网络错误不直接认定为 Token 永久失效。真实历史失败本次未复现，不将防护改进等同于所有官方网络问题均已修复。

## 更新页面

- 更新页面重新组织当前版本、候选更新与更新设置，当前版本日志随安装包提供，离线也可查看。
- 自动下载作为独立可选设置，默认关闭；正式安装环境主动开启后才下载和校验，安装仍需确认。
- “已是最新版本”使用短暂悬浮提示，避免占用页面空间；保留并发检查与渠道切换保护。

## 安装与边界

沿用现有覆盖安装与数据保留流程，无新增数据库迁移或业务依赖。账号的“刷新状态”执行授权刷新并更新元数据，额度区域的刷新重新查询额度且查询前同样请求续期；网关继续按需刷新授权。

本轮仅生成和校验本地安装包，不自动安装、不重启真实生产实例，不修改现有账号、系统登录或客户端配置。真实过期令牌、故障复现及管理员安装流程需在用户选择更新后验证。
