# OmniProxy v2.0.0-beta.34

本版为 Windows amd64 production 本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

本版重做安装向导：**先选语言**，**再选安装目录**，**再选数据目录**，并且数据目录页显示的是你**当前正在用**的位置——改动前会明确警告不会迁移已有数据。

## 1. 安装向导：语言 → 安装目录 → 数据目录

- 启动安装包先弹出语言选择（中文 / English），选择记在 `HKCU\Software\OmniProxy\InstallerLanguage`，卸载器沿用同一语言；静默升级不显示。
- 安装器全部文案（页面、确认框、完成页、卸载提示）都随语言切换，自定义页面集中在新加的 `strings.nsh`。
- 之后依次是欢迎页、安装目录、数据存储位置、安装、完成。

## 2. 数据目录页显示真正在用的位置

上一版这一页只写了个「建议文件」，对已经装过的用户等于没作用，这一版改成：

- 打开页面时，安装器调用程序自身的辅助模式（`--omniproxy-installer-data-dir-read`）读出**当前用户正在使用**的数据目录，来源是 C 盘上的指针文件 `%APPDATA%\OmniProxy\app.json`。升级安装看到的就是你当初设置的位置，而不是默认值。
- 你改动它时先弹警告：原目录里的账号、凭据和请求记录会留在原处，程序将从新目录重新开始；要保留并搬迁数据，请在安装完成后用应用内「设置 → 数据存储 → 数据主目录」。选「否」就留在本页。
- 确认后由辅助程序写入（`--omniproxy-installer-data-dir-write`）：路径必须绝对、可写、不与当前位置互相包含；**当前目录仍含数据库时直接拒绝**（提示装完后在应用内搬迁），因为安装器不做数据迁移——真正的搬迁只能由应用在退出时完成，它带校验和回滚。

## 3. 数据都在数据目录，C 盘只留指针

数据目录里是全部内容：SQLite 数据库（含 WAL）、DPAPI 凭据、日志、更新缓存。C 盘只剩一个约 200 字节的 `%APPDATA%\OmniProxy\app.json` 指向它，`OMNIPROXY_DATA_DIR` 之类的环境变量仍可覆盖。

解析顺序：`OMNIPROXY_DATA_DIR` > `app.json` 的 `dataDir` > Beta.33 写下的 `data-dir.txt`（兼容读取）> `%APPDATA%\OmniProxy`。

## 兼容与已知边界

- 无数据库迁移；沿用 Beta.33 的代码（桌面行为开关统一、数据目录解析）。
- 安装器是机器级（`Program Files` + UAC），数据目录是每用户的：安装时选的位置写进**执行安装那个 Windows 用户**的 `app.json`；同一台机器上的其他用户仍各用各的默认位置，可在应用内改。
- 静默升级（应用内「重启更新」）不显示向导，也不改动任何数据位置设置。
- Codex 约 500k 提前压缩、Google `429 / RESOURCE_EXHAUSTED` 两项仍是独立调查项。
- 安装器未签名、未自动安装、未打标签、未推送。

## 安装与数据保留

从托盘完全退出旧版（托盘菜单「退出」，不是关窗口），备份数据目录后覆盖安装。安装后在「设置与关于」核对版本为 2.0.0-beta.34。

## 校验

- 安装器位于 `release-assets/v2.0.0-beta.34/`，同名 `.sha256` 一并生成。
- 完整质量门、Windows 版本资源与发布资产校验均通过。
