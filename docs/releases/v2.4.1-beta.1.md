# OmniProxy v2.4.1-beta.1

## New Features / 新功能

- Optional request-body recording. A new switch in Settings → Requests and logs ("Record request content") is off by default. When enabled, the gateway stores each inference request's client body in the local database: the protocol entry saves the normalized body before routing rewrites, Codex transparent HTTP saves the forwarded body, and each Responses WebSocket round (including the transparent WebSocket) saves the body or frame actually sent. The request detail dialog shows the content as formatted JSON with a copy button, sizes and a truncation notice; requests without saved content say so explicitly. / 可选的请求正文记录：设置 → 请求与日志新增「记录请求正文」开关，默认关闭。开启后网关把每次推理请求的客户端正文存入本机数据库——协议入口保存规整后、路由改写前的正文，Codex 透明 HTTP 保存实际转发的正文，Responses WebSocket（含透明 WebSocket）按每一轮保存实际发送的正文／帧。请求详情弹窗以格式化 JSON 展示正文，附复制按钮、大小与截断提示；未保存正文的请求会明确说明。
- XLSX export of request records. The Requests page now has an "Export XLSX" button that exports every record matching the current search and outcome filters (up to 100,000 rows), including time, actual model, input model, reasoning effort, provider, account, tokens, usage state, HTTP status, error code, latency, first token, estimated cost and the stored request body. / 请求记录支持 XLSX 导出：请求页新增「导出 XLSX」，按当前搜索与结果筛选导出全部匹配记录（最多 100000 行），包含时间、实际模型、输入模型、推理档位、服务商、账号、Token、用量状态、HTTP 状态、错误代码、耗时、首字、估算成本与已保存的请求正文。

## Notes / 说明

- The feature is conservative by design: at most 256 KiB per request, cut on a UTF-8 boundary and marked truncated while keeping the original byte count; long Base64 inline data (images/audio) is folded into a placeholder; compressed or non-UTF-8 transparent bodies are not stored. Response bodies, raw headers, User-Agent, access keys and credentials are never stored, and content never enters the runtime logs. / 该功能按保守口径实现：每条最多 256 KiB，按 UTF-8 边界截断并标记，同时保留原始字节数；长 Base64 内联数据（图片／音频）折叠为占位文本；压缩或非 UTF-8 的透明转发正文不保存。响应正文、原始头部、User-Agent、接入 Key 与凭据始终不保存，正文也不会进入运行日志。
- Saving content is separate from usage accounting: a failed write only records the stable `content_unavailable` / `content_setting_unavailable` codes and the `request_content_failed` end-log field, and never changes the request result. Content is evicted together with its request record; turning the switch off only stops new captures, and "Clear saved content" removes stored bodies without touching request history or totals. / 正文写入与用量记账分离：写入失败只记录稳定错误码 `content_unavailable`／`content_setting_unavailable` 与结束日志字段 `request_content_failed`，不改变请求结果。正文随请求明细一起淘汰；关闭开关只停止新增采集，「清除已保存的正文」只删除正文，不影响请求历史与累计用量。
- XLSX cells are capped at Excel's 32,767-character limit and marked by the "Content truncated" column. The workbook is written by a standard-library OOXML writer, so no third-party spreadsheet dependency was added. / XLSX 单元格按 Excel 的 32767 字符上限截断，并由「正文截断」列标记。工作簿由标准库 OOXML 写入器生成，没有引入第三方表格依赖。

## Breaking Changes / 不兼容变更

None / 无。Migration 053 only adds the default-off setting column and the `request_contents` table; existing accounts, routing, request history and statistics are preserved, and no API or managed-client configuration changes. / 无。迁移 053 只追加默认关闭的设置列与 `request_contents` 表；既有账号、路由、请求历史与统计保持不变，也没有 API 或受管客户端配置变化。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release and not signed. Fully exit OmniProxy from the system tray, back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布、未签名。请先从托盘完全退出 OmniProxy，备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.4.1-beta.1`; Windows numeric resources: `2.4.1.0`; NSIS installer base version: `2.4.1`. / 应用／前端版本为 `2.4.1-beta.1`，Windows 数字资源版本为 `2.4.1.0`，NSIS 安装器基础版本为 `2.4.1`。
- First start runs migration 053 automatically. Content recording stays off until you enable it; turning it on affects new requests only, and history is not backfilled. / 首次启动自动执行迁移 053。正文记录保持关闭，直到你主动开启；开启后只影响新请求，不会补录历史。
- Export writes the selected file through the native save dialog; review the file before sharing it because it can contain prompts, code and secrets from the saved request bodies. / 导出通过原生保存对话框写入你选择的文件；文件可能包含已保存正文里的提示词、代码与密钥，分享前请自行检查。
