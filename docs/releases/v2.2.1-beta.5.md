# OmniProxy v2.2.1-beta.5 - 账号 Token 用量改为终身累计 / Account token usage is now lifetime

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对本地 `v2.2.1-beta.4`，本次修正账号卡片上的 Token 数值会随请求明细淘汰而变小的问题。

## 修复 / Fixes

- **Token 用量变成账号的终身累计**：账号卡片与配额页此前把「最近留存的 1 万条请求」当成累计值，
  明细一被淘汰数字就往下掉，同一账号还会比「用量」页少一大截
  （本机实测 `rv_1jfif` 卡片 749,404,763 对用量页 1,798,841,626）。现在改读按记账身份索引的
  终身累计表，请求明细淘汰、账号或提供商删除、应用重启都不会让它变小，只有新的代理请求会增加。
  - **Lifetime totals**: the account card and quota page used to sum only the retained request details,
    so the number fell as soon as history was evicted and disagreed with the Usage page by 1.5–2.4×
    (`rv_1jfif`: 749,404,763 vs 1,798,841,626 here). Both now read a per-identity lifetime total that
    survives detail eviction, account or provider deletion and restarts, and only grows with new traffic.
- **升级即回填历史**：迁移 045 建表时从每日桶回填 Token、请求数与完整用量数，卡片打开就是历史累计；
  缓存明细只能回填仍在保留期内的部分，更早的显示为下界（`≥`），不伪造完整值。
  - **Backfilled on upgrade**: migration 045 seeds the table from the daily buckets, so the card shows
    the historical total immediately. Cached-input detail is only recovered where request details are
    still retained; older parts stay a lower bound (`≥`) instead of a fabricated number.
- **同一身份两处口径一致**：身份索引与「用量」页、仪表盘、提供商／模型汇总同源同事务，
  订阅身份为「提供商类型 + 邮箱 + 工作区」，API Key 身份为「提供商类型 + 账号 ID」，
  删除后重新添加同一账号继续合并历史。
  - **One identity everywhere**: the same identity index now backs the card, Usage page, dashboard and
    provider/model totals; re-adding the same account continues its history instead of restarting at 0.
- **缓存明细不再重复计入或被降级**：后续快照缺少缓存字段时不再把已知缓存改写为未知，
  同一份缓存重复上报也不会被累加两次。
  - **No duplicate or downgraded cache**: a later snapshot without cache fields no longer wipes a known
    value, and the same cache figure reported twice is counted once.

## 升级说明 / Upgrade notes

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- 首次启动自动执行数据库迁移 045（新增 `usage_accounts` 累计表并从每日桶回填），只读历史、不改动已有明细。
- Windows 数字版本仍为 `2.2.1.0`；完整版本递增至 `2.2.1-beta.5`。
- 无新增依赖，安装身份与数据目录沿用既有设置。

## 已知边界 / Known limits

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 本次为本地构建，不会出现在远端自动更新渠道。
- 「请求明细上限」不再影响卡片数字，只决定请求页能翻到多少条历史；升级前已被淘汰明细的缓存部分只能显示下界。
