# OmniProxy v2.0.0-beta.12（本地生产安装版）

本版基于 Beta.11，加入订阅账号刷新误报修复、额度快照跨重启留存，以及 River 模型和请求分页优化。使用 production 标签构建 Windows amd64 NSIS 安装包，仅供用户本地覆盖更新，不自动安装或对外发布。

## 订阅账号刷新体验

- 普通“刷新状态”读取官方组件托管的身份，不再每次强制进行 OAuth 续期；已有 account_id 不重复请求附加用量信息。正常授权续期仍由官方组件管理，网关使用 Token 前和授权完成后的核验保持不变。
- 超时不再误报为“授权操作已取消”；排队繁忙、读取超时与真正取消分别处理。临时失败保留原授权状态和已显示额度，不把网络问题直接判为账号失效。
- 临时刷新失败采用可关闭、5 秒后自动消失的非阻断提示，重试成功或重新登录后不继承旧操作红字。真实缺失授权、身份不匹配、组件缺失和本地保存失败仍明确显示，不伪装成成功。

## 额度与重置时间留存

- 已成功获取的公开订阅额度和重置时间写入本地快照，换页或重启后先恢复已有显示，再按原策略刷新。
- 网络失败或官方暂缺部分窗口时保留最近成功显示，不推算剩余额度、不把过期快照恢复成 100%。历史上从未落盘的数据不能凭空恢复。
- 数据库迁移 036 追加快照存储，遵守账号成员、工作区、授权版本以及删除／重新登录边界。留存显示不作为实时账号调度、自动激活或实际调用权限的依据。

## River 模型与请求分页

- River 显示并区分 `DeepSeek-V4.1-Flash` 和独立的 `DeepSeek-V4.1-Flash-1017`，预设增至四款；NVIDIA 和 GLM 的显示及映射不变。
- 原版保留 `deepseek-flash` 路由及既有优先级，1017 不合并或回退到原版。已同步过目录的账号需再次点击“同步官方模型”获取新型号；未公布的 1017 推理档位不额外推断。
- 请求页底部改为“第 N 页 / 共 M 页”，按每页 50 条和实际筛选记录数计算总页数，左侧继续独立显示记录数及上限。例如 1017 条为 21 页，不再把记录数当作页数。

## 安装与验收边界

由用户自行退出旧版并运行安装包，沿用既有安装身份、安装目录和数据保留流程；安装后在关于页确认版本为 2.0.0-beta.12。Beta.11 的长会话恢复、授权进度、账号删除和轮换设置优化继续保留。

本版完成离线回归和完整质量门，但真实 OAuth、网络故障恢复、原生交互、覆盖升级以及安装版重启仍需用户本地验收，不承诺所有网络问题消失。无新增业务依赖，不改写真实客户端配置或默认 Codex 登录。

本地安装包未签名，Windows 可能提示未知发布者；机器级安装需要管理员确认。构建过程不停止或替换现有生产程序，不自动运行安装器。
