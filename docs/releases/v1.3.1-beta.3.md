# v1.3.1-beta.3 - Atria model in one-click configuration / Atria 模型加入一键配置

Following the Atria provider integration in v1.3.1-beta.2, `Atria-Dawn-Preview` can now be selected directly in the one-click configuration for Claude Code and Codex, and in the gateway route model presets. Requests are routed to Atria automatically based on the model name.

继 v1.3.1-beta.2 接入 Atria 服务商之后，`Atria-Dawn-Preview` 现在可以直接在 Claude Code 与 Codex 的一键配置以及网关路由模型预设中选择，请求会按模型名称自动路由到 Atria。

## Features And Fixes / 新增与修复

- Added `Atria-Dawn-Preview` to the Claude Code one-click model picker, so the configuration writer accepts it instead of rejecting it as an unsupported model.
  - Claude Code 一键配置的模型选择列表新增 `Atria-Dawn-Preview`，配置写入不再以"不支持的模型"拒绝。
- Added `Atria-Dawn-Preview` to the Codex one-click model picker, and mapped its documented context window (256,000 tokens, 65,536 max output) so Codex writes `model_context_window = 256000` instead of falling back to 1M.
  - Codex 一键配置的模型选择列表新增 `Atria-Dawn-Preview`，并按文档写入 256,000 上下文窗口（最大输出 65,536），不再回退到 1M。
- Added the model to the codex, Claude, and OpenAI-compatible gateway route model presets.
  - 网关路由的 codex、Claude、OpenAI 兼容预设均加入该模型。
- Routing needs no new code: the model name lowercases to `atria-dawn-preview`, which already matched the Atria prefix inference added in v1.3.1-beta.2.
  - 路由无需新增代码：模型名小写后为 `atria-dawn-preview`，命中 v1.3.1-beta.2 已有的 Atria 前缀推断。

## Upgrade Guidance / 升级说明

- Add an Atria account (API key starting with `atr_`) under the Atria provider in the token list first, then re-run one-click configuration and pick Atria Dawn Preview.
  - 先在令牌列表的 Atria 服务商下添加账号（`atr_` 开头的 API Key），再重新执行一键配置并选择 Atria Dawn Preview。
- Codex sends `model_reasoning_effort = "xhigh"` for Atria like it does for other non-DeepSeek models; Atria is text-only per its documentation.
  - Codex 对 Atria 与其他非 DeepSeek 模型一样发送 `model_reasoning_effort = "xhigh"`；按文档 Atria 仅支持文本。
- As with v1.3.1-beta.2, live upstream requests for this beta were not performed locally; the configuration output is covered by unit tests instead.
  - 与 v1.3.1-beta.2 相同，本次 Beta 尚未在本地完成真实上游请求验证，配置输出由单元测试覆盖。
