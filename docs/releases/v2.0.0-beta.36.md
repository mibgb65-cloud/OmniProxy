# OmniProxy v2.0.0-beta.36

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 新增

- **内置服务商 Oxion AI**（第 12 个内置服务商）。使用官方 OpenAI 兼容接口
  `https://oxionai.com/v1`，认证为 `cc_` 前缀的 Bearer API Key。
  - 添加账号后可「同步官方模型」：网关调用 `GET /v1/models`，只收录官方 `type=chat` 的模型，
    上下文窗口与 `vision`／`tools` 能力按目录声明；目录按账号发放，因此**没有内置预设模型**，
    未同步前该服务商不提供任何可用模型。
  - Chat Completions 请求原生透传；Responses／Messages 请求由网关转换成 Chat 后转发，
    并按调用方原协议编码回包。
  - 官方文档未声明 `reasoning_effort`，因此不发布推理档位选择；不注入 `stream_options` 等
    未声明参数。
  - 未接入：Embeddings、`web_search`、余额／额度面板。
- 服务商页新增 Oxion AI 名称、品牌图标与中英文案。

## 变更

- 新增迁移 043，仅追加 `builtin_oxionai` 预设；既有服务商启停、账号与凭证引用不受影响。
- 服务商目录新增 `discoveryOnly` 标记，用于区分「目录按账号同步」与「有内置预设」。

## 升级说明

- 覆盖安装后首次启动会自动执行迁移 043，无需手工操作。
- Oxion AI 默认启用但不含模型；需要先添加 API Key 账号并同步官方模型才可路由。
- 已在网关配置过其他服务商的用户：路由、别名与客户端目录保持不变。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 转换路径（Responses／Messages → Chat）的 Token 用量保持未知，不推测数值。
- 真实 Oxion AI Key 的端到端调用与原生窗口视觉由用户验收。
