# OmniProxy v2.2.3-beta.7

## Features / 新功能

None / 无。

## Bug Fixes / 问题修复

- Only one OmniProxy process runs per environment. Launching the app again after it was started at login no longer opens a second window or a second tray icon, and the duplicate launch no longer opens the database, rewrites `app.json`, applies migrations or competes for the gateway and control ports.
  - 同一运行环境只运行一个 OmniProxy 进程。开机自启后再次手动启动，不再出现第二个窗口或第二个托盘图标；重复启动也不再打开数据库、改写 `app.json`、执行迁移或抢占网关与控制端口。
- A later launch now brings the existing window to the front. A window hidden to the tray or minimised is restored and focused, then the duplicate process exits with code 0.
  - 重复启动只把已有窗口带到前台：托盘隐藏或最小化的窗口会恢复并聚焦，重复进程随即以退出码 0 结束。
- The single-instance guard is applied per runtime profile, so the production, development and test environments still run side by side; a development build never blocks the production app.
  - 单实例守卫按运行环境隔离，生产／开发／测试仍可并行运行，开发版不会阻挡生产版启动。

## Breaking Changes / 不兼容变更

None / 无。No new database migration or public API change / 无新增数据库迁移或公共 API 变更。

## Refactor & Performance / 重构与性能

- Added `internal/platform/singleinstance` (Windows named mutex plus a named activation event, no-op on other platforms) and wired it into startup before any shared state is touched. No new dependency.
  - 新增 `internal/platform/singleinstance`（Windows 命名互斥量与命名激活事件，其他平台为空实现），并在触碰任何共享状态之前接入启动流程。No new dependency / 无新增依赖。

## Local update / 本地更新

- This is a local Windows amd64 Beta production installer, not a public release. Fully exit OmniProxy from the system tray, back up the current data directory, then run the installer over the existing installation.
  - 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布。请先从托盘完全退出 OmniProxy，备份当前数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.7`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`.
  - 应用／前端版本为 `2.2.3-beta.7`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
- Existing accounts, routes, statistics and client configuration are preserved; this release has no database migration.
  - 保留现有账号、路由、统计与客户端配置；本版本没有数据库迁移。

## Verification and limits / 校验与边界

- The implementation task passed `task verify` (format, lint, type check, 53 Go test packages, 146 frontend files / 893 tests, and the Windows production build).
  - 实现任务已通过 `task verify`（格式、lint、类型检查、53 个 Go 测试包、前端 146 文件／893 项与 Windows 生产构建）。
- A process-level check confirmed that a duplicate launch exits with code 0 in about 0.26 s without creating a data directory or log file, and that the running instance receives the activation request.
  - 进程级验证确认重复启动约 0.26 秒内以退出码 0 结束，未创建数据目录或日志文件，且运行中的实例收到激活请求。
- Native window activation (foreground focus) was not verified automatically: WebView2 could not create a controller in the automation session (`800700aa`). Please confirm the second launch focuses the existing window on the real desktop.
  - 原生窗口置前未能自动验证：自动化会话中 WebView2 无法创建窗口控制器（`800700aa`）。请在实机确认第二次启动会把已有窗口带到前台。
- This packaging task does not rerun tests or `task verify`. Production compilation and installer metadata/SHA256 checks are build acceptance only, not a new full test pass.
  - 本次打包不重跑测试或 `task verify`；生产编译及安装器元数据／SHA256 核对仅代表构建验收，不代表重新通过完整测试。
- The local installer is unsigned and may trigger an unknown-publisher or SmartScreen warning. Building does not install or launch the application.
  - 本地安装器未签名，可能触发未知发布者或 SmartScreen 提示；构建不安装、不启动应用。
