# OmniProxy v2.0.0-beta.14（本地生产安装版）

本版在 Beta.13 基础上加入 Codex 额度美元参考估算、Claude Code 图片工具历史兼容性提示和启动网关偏好。使用 production 标签构建 Windows amd64 NSIS 全量安装包，仅供用户本地覆盖更新，不自动安装或对外发布。

## 额度美元参考估算

- 在 Codex 账号的一周额度进度条下，分别显示 5 小时／一周的预计总额和预计剩余；不适用的 5 小时窗口不显示。
- 沿用旧版公式：当前窗口内保留的本机 Token 基础等值成本 ÷ 官方已用比例，至少已用 5% 才估算。按实际模型分别匹配美元基础参考价，不再全部套用固定 GPT 价格；价格未知或用量不完整时不编造金额。
- 缓存读取不重复计入普通输入。历史记录缺少缓存明细时显示区间，新请求保存上游可获得的缓存读取计数。
- 只使用同一账号、成员、工作区和窗口实际观察时刻的记录，不用累计总 Token 回填。提前重置分别保存 5 小时／周窗口基线，避免混用重置前消费与重置后百分比。
- 这是本机样本的 API 等值粗估，不是官方美元余额。参考价非实时，不含长上下文、加速和工具附加费；其他客户端消费、清理历史及调价可能使结果偏低或失真，两个窗口不能相加。

## 图片工具兼容性提示

- Claude Code 通过 River／DeepSeek 文本通道发送图片，或工具结果及历史中携带图片时，继续明确返回 `400 / unsupported_content`，同时给出固定安全说明。
- 提示切换支持图片的模型及通道，或新建纯文本会话并避免截图／图片工具。请求详情对已有同类错误也显示兼容性说明。
- 本版没有为文本通道新增视觉能力，不删除图片、不回显图片内容／地址、不静默换账号或重放请求来伪装成功。

## 启动网关偏好

- 通用设置增加“启动软件时自动启动网关”，默认关闭，与 Windows 开机自启动相互独立。
- 设置只影响下次软件启动。端口占用等失败不会终止桌面应用，仍可查看状态并手动重试。
- 保留 Beta.13 的 Google 订阅模型自动同步及配置保护。本地 Codex 登录同步试验工具不会由本安装包自动运行，不自动改写客户端登录或重启 Codex Desktop。

## 安装与数据保留

先退出旧版，再运行本安装包覆盖更新，安装后在关于页确认版本为 2.0.0-beta.14。沿用既有安装身份和数据保留流程。

启动时应用数据库迁移 037，增加可空缓存读取计数及额度估算重置基线，不清空账号、请求历史或累计统计。更新前建议保留一致性数据备份；不建议让旧版本继续写入升级后的同一数据库。

本版完成关键回归、完整质量门及合成账号原生界面验收；真实安装覆盖、真实账号估算和安装后重启由用户本地验收。本地安装包未签名，Windows 可能提示未知发布者，机器级安装需要管理员确认。构建过程不停止或替换当前生产程序，不自动运行安装器，也不推送代码或发布版本。
