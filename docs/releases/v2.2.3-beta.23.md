# OmniProxy v2.2.3-beta.23

## Changes / 本版内容

- The usage page structure row is now a two-column layout on wide screens (≥1280px viewport). “Token composition” sits above “Provider share” in the left column, while “Model share” spans both rows on the right, so the three cards form one clean rectangle instead of leaving large blank areas under the two shorter cards. Card bodies now stretch vertically, the donut is centred in the spare height, and model rows spread evenly; nothing is hidden and no extra in-card scrollbar was added (the provider card keeps its existing scroll). On narrow screens the cards stack in the order composition → provider → model, matching the wide-screen reading order. / 用量页结构区在宽屏（≥1280px 视口）改为两栏：左栏「Token 构成」在上、「提供商用量占比」在下，右栏「模型用量占比」跨两行，三张卡拼成一个整齐矩形，不再因为三列等高而在两张较矮的卡片下方留下大片空白。卡片内容区改为可纵向伸展，环形图在富余高度中居中，模型条目均匀铺开；不隐藏内容，也没有新增卡片内滚动条（提供商卡保留原有滚动）。窄屏按构成 → 提供商 → 模型单列堆叠，与宽屏阅读顺序一致。
- Also inherited, since beta.22 was never installed: the full usage analytics view (six KPIs, switchable daily trend, composition donut, model/provider/account shares, top-6 model daily stack, 24-hour distribution, 30-day request quality) and the local proxy detection fix that stopped writing `auto://127.0.0.1` into the address field, plus the beta.19–beta.21 content: compact Google account card, Antigravity inline images, Google account rotation settings (migration 047), variant reasoning levels taken from the model name, and in-progress requests pinned with a “Finished” divider. / 同时包含 beta.22 未安装的内容：完整用量分析视图（6 个 KPI、可切换的每日趋势、构成环形图、模型／提供商／账号占比、Top 6 模型每日堆叠、24 小时时段分布、近 30 天请求质量）与「探测本机代理」不再把 `auto://127.0.0.1` 写进地址字段的修复；以及 beta.19–beta.21 的 Google 账号卡片瘦身、Antigravity 内联图片、Google 订阅账号轮换设置（迁移 047）、以变体型号为准的推理等级、请求页进行中记录置顶并带「已结束」分隔行。

## Breaking Changes / 不兼容变更

- None. The layout change only reorders the same three cards on wide screens and keeps every value, label and accessible name. / 无不兼容变更：布局改动只在宽屏重排同样三张卡片，数值、文案与可访问名称全部不变。
- No new database migration. Migration 047 only runs if the installed build predates beta.17. / 无新增数据库迁移；仅当安装版本早于 beta.17 时执行迁移 047。
- No public API change. / 无公共 API 变更。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release. Fully exit OmniProxy from the system tray, back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布。请先从托盘完全退出 OmniProxy，备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.23`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`. / 应用／前端版本为 `2.2.3-beta.23`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
