# OmniProxy v2.0.0-beta.6（本地测试版）

本版仅在本机生成 Windows amd64 安装包供用户更新测试；未发布 GitHub、未创建远端标签，也不会自动替换正在运行的生产实例。

## Codex Desktop 转发兼容

- Responses 首事件推断及 HTTP／WebSocket 单事件容量统一为有界 2 MiB，修复带较多工具定义的合法首事件被旧 512 KiB 推断上限误拒绝的问题。保留缺失 Content-Type 的协议校验，不接受任意 200 回包。
- 增加固定安全诊断，区分前缀超限、空／截断／读取失败、非 SSE JSON／HTML、事件及 JSON 校验失败和执行前额度拒绝，不记录提示词、回复正文或凭据。
- 固定订阅端点若以 HTTP 200 包装首个明确 `usage_limit_reached` 错误，按执行前额度拒绝处理，避免掩盖为普通 502。生成已经开始后的错误或断流仍不重放。

## 5h／一周额度耗尽后轮换

- 使用经过身份校验的账号额度快照，5h 或一周任一窗口耗尽且尚未重置时跳过该账号，尝试仍可用的同池账号；共享窗口对不同模型一致生效。
- 两个窗口同时耗尽时以较晚重置时间为准；重置、读取到新的可用额度及重置卡刷新后重新允许参与。缓存按账号配置版本隔离，缺失窗口或陈旧快照不假装恢复。
- 新登录但尚未同步模型目录的订阅账号可以参与已知模型的备用尝试，权限以官方响应为准；明确不支持模型的账号仍被排除。
- 保留固定账号、故障切换开关、最多三次尝试、同提供商／认证／计费／地区及不确定执行不重放的边界。一次客户端请求只计一次，尝试记录保留上游实际 HTTP 状态和已报告用量。

## 验证与使用

已覆盖 HTTP／WebSocket 的耗尽切换、周窗口重置、缓存版本与过期保护、未同步备用账号、开始生成后不重放，以及大首事件。实际安装的 Codex CLI 0.163.0 和 Desktop 内核 0.163.0-alpha.10.2 均通过独立 HOME、随机回环端口、模拟额度拒绝和 600 KiB 首事件的契约验收；未读取真实客户端登录或发送真实用户对话。

原生产 Desktop 失败的首事件未保存，不能宣称历史原因已唯一确定；请安装本地包后通过 ChatGPT.exe 的全新会话验收，若仍失败可根据新的安全分类继续定位。

更新后启动网关，确认「账号故障切换」开启，且该模型路由没有显式固定到耗尽账号。本版无数据库迁移，沿用覆盖安装及数据保留流程；不会静默修改共享 Codex 配置或登录。
