# OmniProxy v2.0.0-beta.2

修复 Beta.1 从历史安装覆盖升级后无法打开及桌面图标仍旧的问题。

- 启动前只读识别不兼容的历史统计库，为新版使用独立数据目录；保留旧库和已有正常 v2 数据，不会自动转换旧统计或覆盖账号。
- 启动失败时显示 Windows 原生提示，并在退出前将诊断写入日志。
- 安装器为桌面和开始菜单快捷方式指定独立图标文件，覆盖升级后显示新版图标；用户已移除的桌面入口继续保留该选择。
- 修复选择「仅正式版」时检查更新的请求路径编码问题；Beta 渠道可从 Beta.1 发现 Beta.2。

Windows amd64 测试版。请同时下载安装器和同名 `.sha256` 校验文件。支持安装覆盖及应用内下载、校验、重启静默更新；卸载保留本地数据。

已通过人工设置独立数据目录恢复的 Beta.1 用户会继续使用现有 v2 目录。旧版 API Key 仍需在「设置与关于 → 数据存储」主动预览和导入；订阅需重新登录，旧统计、路由和客户端备份不做整库迁移。若检测到混合账号／异常结构，会保留原库并明确提示人工处理。

本版尚未接入代码签名。功能与历史数据兼容边界见 [升级说明](https://github.com/mibgb65-cloud/OmniProxy/blob/main/docs/product/UPGRADE.md)。
