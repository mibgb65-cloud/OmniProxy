# OmniProxy v2.2.3-beta.12

## Bug Fixes / 问题修复

- The Antigravity entry on the gateway page is now a normal card in the client grid instead of a full-width banner. It uses the same layout as the other clients: brand icon, group title, description, one client row with status and install state, and a full-width action button under a divider. / 网关页的 Antigravity 入口改为客户端网格中的普通卡片，不再独占整行。版式与其它客户端一致：品牌图标、分组标题、描述、带状态与安装状态的客户端条目，以及分隔线下的整宽操作按钮。
- Its status badge now describes Antigravity itself — "Connected to the local gateway", "Configuration needs attention" or "Not configured" — instead of reusing the access-key wording. / 状态徽标改为描述 Antigravity 自身：「已连接本地网关」「配置需要检查」「尚未配置」，不再复用接入 Key 的措辞。
- The hint, Google sign-in note and settings path were shortened to fit the narrower column; the duplicate model summary that stretched the card was dropped. / 提示文案、Google 登录说明与设置文件路径已精简以适配更窄的列宽；拉长卡片的重复模型摘要不再显示。

## Breaking Changes / 不兼容变更

None / 无。No database migration, backend or public API change: this release only changes the layout and copy of the Antigravity card on the gateway page / 无新增数据库迁移、后端或公共 API 变更；本版本只改变网关页 Antigravity 卡片的版式与文案。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release. Fully exit OmniProxy from the system tray (the running instance is beta.11), back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布。请先从托盘完全退出 OmniProxy（当前运行的是 beta.11），备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.12`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`. / 应用／前端版本为 `2.2.3-beta.12`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
- Existing accounts, routes, statistics, client configuration and the Antigravity connection written by beta.11 are preserved; this release has no database migration. / 保留现有账号、路由、统计、客户端配置，以及 beta.11 写入的 Antigravity 连接；本版本没有数据库迁移。
- Antigravity behaviour is unchanged: connect from the card, pick a default model, then quit and restart the app. While connected there is no Google sign-in. / Antigravity 行为不变：在卡片上连接、选择默认模型，然后完全退出并重启桌面端；连接期间不使用 Google 登录。

## Verification and limits / 校验与边界

- `task verify` passed: format check, lint, typecheck, Go test packages, frontend suite (147 files / 898 tests, two of them new for this card) and the Windows production build. / `task verify` 通过：格式检查、lint、类型检查、Go 测试包、前端测试（147 文件／898 项，其中 2 项为本卡片新增）与 Windows 生产构建。
- The card is asserted in tests to sit inside the client grid, to keep the `h4` title, and to expose connect, apply and disconnect in the right states; its width follows the grid's `auto-fit` columns. Native WebView2 appearance still needs your eyes after installing. / 测试断言卡片位于客户端网格内、保留 `h4` 标题，并在对应状态下提供连接、应用与断开；卡片宽度随网格 `auto-fit` 列变化。原生 WebView2 观感仍需安装后确认。
- The local installer is unsigned and may trigger an unknown-publisher or SmartScreen warning. Building does not install or launch the application. / 本地安装器未签名，可能触发未知发布者或 SmartScreen 提示；构建不安装、不启动应用。
