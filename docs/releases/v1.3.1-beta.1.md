# v1.3.1-beta.1 - GPT-6 Astra support / GPT-6 Astra 模型适配

This beta adds `gpt-6-astra` to OmniProxy's model selection, client configuration, and pricing rules. Existing default models remain unchanged.

本次 Beta 为 OmniProxy 增加 `gpt-6-astra` 模型选择、客户端配置和费用估算规则，现有默认模型保持不变。

## Features And Fixes / 新增与修复

- Added GPT-6 Astra to the Codex and OpenAI-compatible gateway presets, the Codex model picker, and generated OpenCode and Pi model lists.
  - 在 Codex 与 OpenAI 兼容网关预设、Codex 模型选择，以及生成的 OpenCode、Pi 模型列表中加入 GPT-6 Astra。
- Codex configuration and model profiles now use a 1,050,000-token context window and a 900,000-token auto-compaction threshold for Astra, with the existing `xhigh` reasoning setting.
  - Codex 配置及模型配置文件使用 1,050,000 token 上下文窗口和 900,000 token 自动压缩阈值，沿用 `xhigh` 推理档位。
- Fixed Astra model-name normalization when converting Chat Completions to Codex Responses, including prefixed names and display-style capitalization. Regression tests cover preservation of `low`, `medium`, `high`, `xhigh`, and `max` reasoning effort.
  - 修复 Chat Completions 转 Codex Responses 时 Astra 模型名的规范化，支持前缀名称与展示形式的大小写，并验证五种推理档位均能保留。
- Added Astra standard token prices and cache/long-context pricing metadata to the existing estimation rules.
  - 在现有费用估算规则中加入 Astra 标准 token 单价及缓存、长上下文定价参数。

## Upgrade Guidance / 升级说明

- Select GPT-6 Astra in the gateway or Codex model configuration. Run the client configuration action again to add it to an existing OpenCode or Pi configuration.
  - 请在网关或 Codex 模型配置中选择 GPT-6 Astra；已有 OpenCode、Pi 配置需重新执行客户端配置操作以添加该模型。
- Existing model defaults, account pools, and local data formats are preserved. No data migration is required.
  - 保留现有默认模型、账号池及本地数据格式，无需数据迁移。
- Upstream access still depends on model availability for the selected account. Astra does not support reasoning effort `none`.
  - 实际调用取决于所选账号是否已开放该模型；Astra 不支持 `none` 推理档位。
- Model parameters were checked against the [official OpenAI documentation](https://developers.openai.com/api/docs/models/gpt-6-astra). Live upstream requests and installer upgrade checks have not been performed locally for this beta.
  - 模型参数已核对 OpenAI 官方文档；本次 Beta 尚未在本地完成真实上游请求与安装包升级验证。
