# OmniProxy v2.0.0-beta.16

本版为 Windows amd64 production 构建的本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

## Google 订阅错误提示修复

- 修复 Google／Antigravity 普通推理与控制端点返回 HTTP 400 时，被误报为 HTTP 401、导致客户端提示 “API key was rejected” 的错误分类。
- 普通请求错误现在返回 `400 / invalid_request`；真实上游 HTTP 401、OAuth 令牌端点 HTTP 400 仍返回 `401 / reauth_required`，权限拒绝和限流仍保留 403／429。
- Chat Completions、Responses、Messages 三种入口保持一致，并正确记录请求结果；不暴露原始上游错误正文，不新增重试或切换普通 API Key 通道。
- 客户端的 API Key 提示不能单独证明 Google 密钥失效：订阅登录使用独立 OAuth。持续认证失败时刷新授权或使用同一身份重新登录；429 时暂停连续重试，刷新对应模型分组额度并参考实际重置时间。

## 能力与验证边界

- 本版修复的是已证实的错误映射缺陷，不会恢复失效授权、补充额度或自动修复不兼容的请求／工具上下文。
- 旧请求记录未保留原始上游状态，无法反推历史 401 是否一定为误报；429 也不能单独区分短时限流与额度耗尽。
- 延续 Beta.15 的额度留存、River 轮换及 Claude 长会话修复；不引入依赖或数据库迁移，不改变安装身份。
- 真实 Google 推理恢复和原聊天续接仍需用户安装后验收，构建过程不发送真实推理。

## 安装与数据保留

更新前建议保留包含 SQLite WAL 的一致性数据备份。从托盘完全退出旧版后，运行本安装包覆盖更新，安装后在“设置与关于”确认版本为 2.0.0-beta.16。

本版沿用现有数据与安装目录，不主动清空已有账号、请求历史或累计统计，不改写客户端登录或自动重启 Claude／Codex Desktop。不建议让旧版本继续写入升级后的同一数据库。

本地安装包未签名，Windows 可能提示未知发布者，机器级安装需要管理员确认。构建过程不自动安装、停止或替换生产应用，不上传发布；真实覆盖安装及数据保留由用户本地验收。
