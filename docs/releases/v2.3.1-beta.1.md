# OmniProxy v2.3.1-beta.1

## Bug Fixes / 问题修复

- Streaming responses now send the HTTP response headers before the first visible token. When the upstream stays silent for more than 3 seconds the gateway commits `200` with `text/event-stream` and keeps the connection alive with an SSE comment (`: keep-alive`) every 10 seconds, so a reasoning model that thinks for a minute is no longer reported as "cancelled". / 流式响应现在会在首个可见 token 之前下发响应头：上游静默超过 3 秒就提交 `200` 与 `text/event-stream`，之后每 10 秒发一条 SSE 注释保活。思考超过一分钟的推理模型不会再被记成「已取消」。
- This fixes the Antigravity desktop failure chain where one task showed up as six "cancelled / usage not reported" rows: the desktop client has a 60-second response-header timeout, and the gateway previously wrote nothing until the first token. / 修复 Antigravity 桌面端的一次任务变成 6 条「已取消／未报告」：桌面端有 60 秒响应头超时，而网关此前在首个 token 前不写任何字节。
- Keep-alive comments are skipped while an SSE event is still being assembled, so a heartbeat cannot cut an event in half. / 正在拼装 SSE 事件时不做心跳，避免注释行的空行把事件截断。

## Features / 新功能

- DuMate models (`model-text`, `dm-auto-model/text.L0`) now declare `text` + `image` input in the model catalog and in managed client configurations. The gateway already forwarded `image_url` parts and converted images for Responses/Messages requests; only the capability declaration was missing. / DuMate 模型（`model-text`、`dm-auto-model/text.L0`）在模型目录与受管客户端配置里声明 `text` + `image` 输入。网关本来就转发 `image_url` 并为 Responses／Messages 转换图片，缺的只是能力声明。
- Context and output capacity are still not published for DuMate, because the upstream limits have not been verified with a real request. / DuMate 的上下文与输出容量仍未公布，因为尚未用真实请求验证上游上限。

## Breaking Changes / 不兼容变更

None / 无。No database migration, no public API change. / 无数据库迁移、无公共 API 变更。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release and not signed. Fully exit OmniProxy from the system tray (the running instance is an older build), back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布、未签名。请先从托盘完全退出 OmniProxy（当前运行的是更早的构建），备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.3.1-beta.1`; Windows numeric resources: `2.3.1.0`; NSIS installer base version: `2.3.1`. / 应用／前端版本为 `2.3.1-beta.1`，Windows 数字资源版本为 `2.3.1.0`，NSIS 安装器基础版本为 `2.3.1`。
- Existing accounts, routes, statistics and client configuration are preserved; this release has no database migration. / 保留现有账号、路由、统计与客户端配置；本版本没有数据库迁移。
- After upgrading, managed clients need their model catalog re-applied to pick up the DuMate image capability; Antigravity sessions pick up the new gateway behavior immediately. / 升级后需要重新应用受管客户端的模型目录才能拿到 DuMate 的图片能力；Antigravity 会话会立即使用新的网关行为。
