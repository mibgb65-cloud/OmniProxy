# v1.2.7-beta.4 - Dashboard layout and responsive polish / 仪表盘布局与响应式优化

This beta improves the dashboard account-status presentation, consolidates the frontend theme cascade, and makes the desktop interface adapt cleanly from wide screens down to narrow windows.

本次 beta 优化仪表盘账号状态展示，收敛前端主题样式层叠，并完善桌面界面从宽屏到窄窗口的响应式表现。

## Features / 新特性

- **Clearer account status summary**: Normal, invalid, and at-risk accounts now share one aligned three-column row with state-aware colors; secondary states remain on a compact single line.
  - **更清晰的账号状态概览**：正常、无效和高风险账号统一为对齐的三栏布局，并根据状态显示颜色；次级状态保持紧凑单行展示。
- **Responsive dashboard layout**: Dashboard cards switch to a single column when the available workspace becomes narrow, while the existing mobile sidebar continues to use an off-canvas layout.
  - **响应式仪表盘布局**：工作区变窄时仪表盘卡片自动切换为单列，移动端侧栏继续使用抽屉式布局。

## Bug Fixes / 问题修复

- **No clipped status details at medium widths**: The 1024px desktop layout no longer squeezes three metric cards into a narrow workspace or clips account-state details.
  - **修复中等宽度信息裁切**：1024px 桌面布局不再把三张指标卡挤入狭窄工作区，账号状态详情也不会被裁切。
- **Removed fixed page minimum width**: The application shell no longer forces a 1240px minimum width, preventing horizontal overflow in narrow windows.
  - **移除固定页面最小宽度**：应用外壳不再强制 1240px 最小宽度，避免窄窗口出现横向溢出。

## Breaking Changes / 不兼容更新

- None / 无

## Refactor & Performance / 重构与优化

- Consolidated the canonical light and dark theme tokens into a single stylesheet and removed obsolete overrides from later cascade layers.
  - 将明暗主题的最终变量收敛到统一样式表，并移除后续层叠中的过时覆盖。
- Removed duplicated dashboard, metric-card, and panel rules so component styles have clear ownership and predictable breakpoint behavior.
  - 清理重复的仪表盘、指标卡和面板规则，使组件样式归属及断点行为更加明确。
- Added explicit image dimensions and improved loading-state semantics to reduce layout shifts and improve assistive feedback.
  - 为界面图片补充明确尺寸，并改进加载状态语义，减少布局偏移并提升辅助反馈。
