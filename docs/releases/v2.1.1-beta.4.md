# OmniProxy v2.1.1-beta.4 - 更新完成提示与弹窗退出动画 / Post-update notice and dialog exit transitions

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对公开正式版 `v2.1.0`，本次用户可见改动是升级结束后的反馈与弹窗过渡；同时包含本地 `v2.1.1-beta.1`／`beta.2`／`beta.3` 的发布说明排版改动，取代这三个本地版本。

## 新特性 / Features

- **更新完成浮窗**：安装结束并以新版本重新打开后，自动弹出「更新完成」，说明「升级前版本 → 当前版本」，正文列出本版新增内容，不再出现升级后毫无反馈的空档。
  - **Update-complete dialog**: after the installer finishes and the app reopens, a one-time dialog shows the previous version, the current version and what changed.
- **本版说明走同一套排版**：正文取构建内置的 `docs/releases/v<运行版本>.md`，与升级浮窗、设置页「当前版本更新日志」共用 Markdown 渲染与链接白名单；提示本身不联网。
  - **Same renderer everywhere**: the body reuses the bundled release note for the running version with the shared Markdown renderer and no extra network request.
- **只提示一次**：确认、关闭按钮、Esc 或点击遮罩都算已读，回执写入 `updates/status.json`；写入失败时下次启动再提示，不假装已读。
  - **Shown once**: confirming, the close button, Esc or the overlay records the acknowledgement in `updates/status.json`; a failed write shows it again next launch instead of silently pretending it was read.
- **弹窗淡入淡出**：设置与关于、升级浮窗、更新完成浮窗的出现与消失都有 150ms 的淡入淡出与轻微缩放，关闭时不再闪一下就消失；系统要求减少动画时直接切换。
  - **Dialog transitions**: the settings window and both update dialogs fade and scale in and out over 150ms instead of vanishing instantly; reduced-motion users get an immediate switch.

## 修复 / Fixes

- 关闭「设置与关于」窗口时不再瞬间消失：内容改为常驻 Portal 并补齐退出动画，关闭后仍会释放表单与异步结果。
- 升级浮窗与设置页的说明正文此前可能显示 `##`、`**`、反引号等原始记号，现在统一按 Markdown 排版。
- 升级浮窗改为「固定标题栏 + 可滚动正文 + 固定操作区」，版本摘要按「当前版本 → 可升级版本」分区。

## 安全边界 / Safety boundary

- 说明正文中的 HTML 标签只作为文本显示，不执行脚本，也不加载远端图片（仅保留替代文字）。
- 只有 `http(s)` 链接与以 `/` 开头的站内路径生成可点击入口，并带 `rel="noreferrer"`；`javascript:` 等其余协议保持纯文本。
- 「更新完成」提示的版本来源与回执全部来自本地记录，不接受前端传入的版本、路径或 URL。

## 升级说明 / Upgrade notes

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- Windows 数字版本为 `2.1.1.0`；完整版本递增至 `2.1.1-beta.4`，高于公开的 `2.1.0` 与本地 `2.1.1-beta.1`、`beta.2`、`beta.3`。
- 安装身份、安装目录与数据目录沿用既有设置；无新增数据库迁移、无新增依赖。
- 不修改已有账号、路由、用量留存或本地客户端配置；建议更新前正常退出应用并保留数据备份。

## 已知边界 / Known limits

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 本次为本地构建，不会出现在远端自动更新渠道。
- 弹窗过渡与「更新完成」排版已通过生产 CSS 核对与隔离 Chromium 截图验证，原生 WebView2 窗口与 140% 字号观感需在本地更新后确认。
- 其余业务弹窗（新增账号、请求详情、删除确认等）仍沿用旧的即时挂载写法，本次未一并调整。
- 完整质量门、安装器版本资源与 SHA256 校验结果见
  [TASK-20261029-007](../tasks/completed/2026-10/TASK-20261029-007-build-local-v2.1.1-beta.4-installer.md)。

## 本版首次触发「更新完成」提示

从 `2.1.1-beta.2`／`beta.3` 或更早版本更新到本版时，重启后应看到一次「更新完成」浮窗；
若浮窗未出现，说明本次更新不是由应用内下载并安装的（例如手动运行安装器），该情况按设计不提示。
