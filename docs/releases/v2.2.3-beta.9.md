# OmniProxy v2.2.3-beta.9

## Features / 新功能

- Google subscription (Antigravity) now accepts agent-shaped requests from Claude Code and Codex. The refusal that used to surface as a misleading `429` is handled explicitly instead of being retried. / Google 订阅（Antigravity）现在能正常处理 Claude Code、Codex 这类 Agent 形态的请求；此前被上游当成额度耗尽拒绝、再被误报成 `429` 的情况改为显式处理，不再反复重试。
- New settings card 「Google 订阅请求」 with a 「按原文发送 system prompt」 switch. It is off by default: a few identity and billing lines in the agent's system prompt are split word by word (zero-width marks, the model still reads the original meaning). Turning it on sends the prompt exactly as written, for comparison or when the upstream stops rejecting it. / 设置页新增「Google 订阅请求」卡片与「按原文发送 system prompt」开关。默认关闭：system prompt 里少数身份与计费标记会按词打散（零宽字符，模型仍按原意阅读）。开启后按原文发送，用于对照，或在上游不再拒绝时使用。
- A prompt that the upstream turns away is reported as a non-retryable `400 prompt_turned_away` with a readable message, instead of an empty `429` and a failover storm. / 被上游拒绝的 prompt 现在报为不可重试的 `400 prompt_turned_away` 并带可读原因，不再是空响应 `429` 加连锁换号。
- The same prompt refused within the last 6 hours is skipped without a request when another candidate account exists, so a client retry does not walk the whole pool. / 同一 prompt 在 6 小时内已被拒绝时，如果还有其它候选账号，就直接跳过、不发请求，客户端重试不会再把整个账号池跑一遍。
- A capacity `429` now rests the account until the reset time the upstream reports (up to 8 days) and fails over to another candidate; with a single account the real error is returned instead of a silent retry loop. / 容量 `429` 现在按上游给出的重置时间让账号休息（最长 8 天）并在有候选时换号；只有一个账号时返回真实错误，不再静默重试。
- Agent requests get the upstream's expected shape: history repair for interrupted tool turns, model-family generation parameters and thinking budgets, `VALIDATED` tool mode for Claude, unsigned tool turns filled with the skip validator, a stable `sessionId`, entitlement-based model catalog filtering (free/paid tiers, disabled and hidden models), and the current protocol version in the client identity. / Agent 请求补齐上游期望的形态：中断的工具轮次历史修复、按模型族设置生成参数与思考预算、Claude 的 `VALIDATED` 工具模式、为未签名工具轮次补跳过校验、稳定 `sessionId`、按权益过滤模型目录（免费／付费档、停用与隐藏模型），以及客户端标识里带上实时协议版本。

## Bug Fixes / 问题修复

- The Google subscription agent chain no longer fails with `429` on every request from Claude Code or Codex, which previously made the subscription unusable for agent clients while direct chat still worked. / Google 订阅 Agent 链路不再对 Claude Code、Codex 的每个请求都返回 `429`；此前订阅账号在 Agent 客户端上完全不可用，而普通对话仍正常。
- A refusal from the upstream is no longer mistaken for rate limiting, so an account is not parked or rotated for a prompt-level rejection. / 上游的 prompt 拒绝不再被当成限流，账号不会因为一次 prompt 级拒绝被降权或轮换。

## Breaking Changes / 不兼容变更

None / 无。No new database migration or public API change / 无新增数据库迁移或公共 API 变更。The paid-tier field is stored with the existing Google credential and is filled on the next authorization; accounts that have not re-authorized behave exactly as before / 付费档信息保存在既有 Google 凭据中，下次授权时填入；尚未重新授权的账号行为与之前完全一致。The default prompt form differs from earlier betas (split instead of verbatim), which is the intended fix and is switchable in settings / 默认 prompt 形态与更早的 Beta 不同（打散而非原文），这是本次修复本身，可在设置页切换。

## Refactor & Performance / 重构与性能

- Google subscription request shaping, refusal handling and error classification moved into dedicated files under `internal/provider/antigravity/` (prompt refusal, refusal marks, upstream errors, chat family, chat history, tool signatures, entitlement tiers); the gateway gained one small helper for refusal/quota bookkeeping. No new dependency. / Google 订阅的请求整形、拒绝处理与错误归类拆到 `internal/provider/antigravity/` 下的独立文件（prompt 拒绝、拒绝标记、上游错误、模型族、历史、工具签名、权益档位），网关只新增一处拒绝／配额记账辅助。No new dependency / 无新增依赖。

- Existing accounts, routes, statistics and client configuration are preserved; this release has no database migration. / 保留现有账号、路由、统计与客户端配置；本版本没有数据库迁移。

## Verification and limits / 校验与边界

- The implementation task passed format check, lint, type check, every Go test package and the Windows production build: 147 frontend files / 895 tests at limited concurrency, all Go packages. / 实现任务已通过格式、lint、类型检查、Go 全部测试包与 Windows 生产构建：前端 147 文件／895 项（限并发），Go 全部包。
