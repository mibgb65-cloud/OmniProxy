# v1.3.0-beta.3 - Correct Codex 5-hour window activation detection / 修正 Codex 5h 窗口激活检测

This beta fixes the Codex quota behavior reported in `v1.3.0-beta.2`: an unused 5-hour window could be returned with `used_percent: 0` and a reset time that moved forward on every refresh, which was incorrectly treated as an active window.

本次 Beta 修复 `v1.3.0-beta.2` 中反馈的 Codex 额度问题：未使用的 5 小时窗口可能返回 `used_percent: 0`，且每次刷新时重置时间向后滚动，之前会被错误识别为已启动窗口。

## Changes / 变更

- **Rolling-window detection**: Compare successive usage responses and the expected five-hour / weekly duration to identify a window that has not started yet.
  - **滚动窗口检测**：结合连续两次额度响应和五小时 / 一周的预期时长，识别尚未开始计时的窗口。
- **Accurate quota display**: The OpenAI quota page shows `未启动` and explains the next action instead of displaying a misleading `已用 0%` with a moving reset time.
  - **准确额度显示**：OpenAI 额度页显示「未启动」及下一步说明，不再把滚动重置时间显示成误导性的「已用 0%」。
- **Activation regression coverage**: Added backend and frontend tests for rolling unused windows and stable zero-usage windows.
  - **激活回归测试**：新增滚动未使用窗口与固定 0% 使用窗口的后端、前端测试。

## Upgrade Guidance / 升级说明

- Existing `v1.3.0-beta.1` and `v1.3.0-beta.2` installations can upgrade directly. Their data and the auto-activation switch are preserved.
  - 现有 `v1.3.0-beta.1` 和 `v1.3.0-beta.2` 可直接升级，数据及自动激活开关会保留。
- After upgrading, refresh the OpenAI quota page once. Accounts whose 5-hour reset time keeps moving while usage remains 0% will be marked `未启动` and can be activated with the existing button or automatic setting.
  - 升级后刷新一次 OpenAI 额度页即可；如果账号 5h 重置时间持续后移且使用量仍为 0%，会标记为「未启动」，可使用现有按钮或自动激活设置启动。
- No account-pool or local-data migration is required.
  - 无需迁移账号池或本地数据。
