# OmniProxy v2.2.3-beta.24

## Changes / 本版内容

- New built-in provider: Baidu DuMate (百度搭子) personal edition, the thirteenth default-enabled provider. Sign in through the local DuMate desktop app (read-only reuse of `auth.json` + `.cookie-key`, decrypted locally) or paste the Cookie request header copied from a browser signed in to `console.bce.baidu.com`; OmniProxy verifies the remote account identity before saving, keeps the cookie only in the Windows-protected credential store (never in SQLite, logs or UI), and binds each account to its own Baidu identity so switching accounts in the desktop app never overwrites an existing account. The gateway exchanges the cookie for a short-lived gateway token, merges concurrent refreshes, and forwards Chat Completions; Responses and Messages requests are converted through the existing protocol pipeline. The point panel shows available / used points and the next expiry, distinguishes live results, a retained snapshot and a failed query, and supports manual daily check-in with an explicit “submitted but not yet credited” state. Adapter only publishes the two model aliases the upstream actually exposes (`model-text`, `dm-auto-model/text.L0`) and does not claim any underlying model or context size. / 新增内置服务商「百度搭子 DuMate」个人版（第十三个默认启用的提供商）。可只读复用本机搭子桌面端登录态（本地解密 `auth.json` + `.cookie-key`），或粘贴浏览器登录 `console.bce.baidu.com` 后请求头里的 Cookie；OmniProxy 先用远端身份核对再保存，Cookie 只进入 Windows 受保护凭据库，不写入数据库、日志或界面，并按百度账号身份绑定，桌面端切换账号不会覆盖已有账号。网关用 Cookie 换取短期 gateway token、合并并发刷新后转发 Chat Completions，Responses／Messages 经既有协议转换链路。积分面板展示可用／已用积分与最近到期时间，区分实时结果、保留快照和查询失败，并支持手动每日签到（含「已提交但尚未到账」状态）。适配器只公布上游实际暴露的两条模型别名（`model-text`、`dm-auto-model/text.L0`），不宣称底层模型或上下文容量。
- Also inherited, if you have not installed beta.19–beta.23 yet: the usage page analytics view and its two-column structure layout, the local proxy detection fix, the compact Google account card, Antigravity inline images, Google account rotation settings (migration 047), variant reasoning levels taken from the model name, and in-progress requests pinned with a “Finished” divider. / 如果尚未安装 beta.19–beta.23，本版也包含：用量页分析视图与结构区两栏布局、本机代理探测修复、Google 账号卡片瘦身、Antigravity 内联图片、Google 订阅账号轮换设置（迁移 047）、以变体型号为准的推理等级、请求页进行中记录置顶并带「已结束」分隔行。

## Known limits / 已知边界

- DuMate check-in is manual only in this version; automatic check-in is not implemented. / 本版 DuMate 只支持手动签到，未实现自动签到。
- DuMate is an unofficial personal-edition integration: the upstream interface may change, and real-account validation (model calls, tool use, reasoning usage, point consumption, check-in credit) has not been performed. / DuMate 属于非官方个人版接入：上游接口可能变更，尚未用真实账号验证模型调用、工具调用、推理用量、积分消耗与签到到账。
- Enterprise DuMate and Qianfan API Key / Token Plan are not part of this provider. / DuMate 企业版与千帆 API Key／Token Plan 不属于本提供商。

## Breaking Changes / 不兼容变更

- None for existing providers, accounts, routing rules or API behavior; the new provider is simply added and can be switched off like the others. / 对既有提供商、账号、路由规则与 API 行为无不兼容变更：新提供商只是追加，可像其他提供商一样停用。
- Database migration 048 only inserts the `builtin_dumate` provider row; it does not alter existing tables, accounts or credentials. Migration 047 still applies only if the installed build predates beta.17. / 数据库迁移 048 只插入 `builtin_dumate` 提供商行，不修改既有表、账号或凭据；迁移 047 仍只在安装版本早于 beta.17 时执行。
- No public API change. / 无公共 API 变更。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release. Fully exit OmniProxy from the system tray, back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布。请先从托盘完全退出 OmniProxy，备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.24`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`. / 应用／前端版本为 `2.2.3-beta.24`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
