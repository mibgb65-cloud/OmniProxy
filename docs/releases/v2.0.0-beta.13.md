# OmniProxy v2.0.0-beta.13（本地生产安装版）

本版基于 Beta.12，加入 Google / Antigravity 订阅模型自动同步和受管 Agent 目录更新。使用 production 标签构建 Windows amd64 NSIS 安装包，仅供用户本地覆盖更新，不自动安装或对外发布。

## Google 模型自动同步

- 启动应用、Google 登录／授权更新或成功刷新账号模型列表后，后台自动同步已启用订阅账号的受支持模型，不再需要逐账号点击同步，也不依赖账号页一直打开。
- 同步复用现有网关目录及各 Agent 的协议适配，只提供实际支持的模型，不按套餐名推断权限；普通 Gemini API Key 的能力边界保持不变。
- 后台串行处理并合并重复通知，每账号有独立超时。一个账号失败不阻断其他账号，失败保留上次成功目录，不自行持续重试；不自动启动网关或发送推理请求。
- 账号卡片保留“重新同步到 AI Agent”手动重试入口，并将“已接入 N 个”改为“网关支持 N 个”，区分协议适配能力和客户端实际配置状态。

## Agent 接入与配置保护

- 自动刷新已经由 OmniProxy 管理且没有外部改动的客户端模型目录；未接入的 Agent 仍需在“网关 → 客户端接入”预览并确认一次配置。
- 用户手动限定的模型范围不会自动扩展，仍可用的默认模型保持不变；外部修改的文件保留，继续使用原有备份和恢复保护。
- 已接入 Agent 的实际模型菜单在同步后刷新。部分运行中的客户端不会热加载，需要重新加载模型菜单或重启；若以前只选择了部分模型，需要重新勾选希望加入的 Google 模型。
- 保留 Beta.12 的订阅刷新体验、额度与重置时间快照留存、River 型号及请求分页优化。本版没有新增业务依赖或数据库迁移。

## 安装与验收边界

由用户自行退出旧版并运行安装包，沿用既有安装身份、安装目录和数据保留流程；安装后在关于页确认版本为 2.0.0-beta.13。

本版完成自动同步、配置保护的离线回归和完整质量门；真实 Google 权限、各 Agent 重载／推理调用、覆盖升级及安装版重启仍需用户本地验收。构建只包含已提交源码，不纳入其他任务仍在进行的网关启动、Codex 登录同步试验或未跟踪工具，不改写客户端登录。

本地安装包未签名，Windows 可能提示未知发布者；机器级安装需要管理员确认。构建过程不停止或替换现有生产程序，不自动运行安装器。
