# OmniProxy v2.2.1-beta.1 - 仪表盘卡片填充与账号切换栏稳定 / Denser dashboard cards and a stable provider dock

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对公开正式版 `v2.2.0`，本次用户可见改动为仪表盘在宽窗口不再留大块空白，以及账号页提供商切换栏的滚动表现。

## 新特性 / Features

- **仪表盘右侧卡片自适应填充**：窗口放大时，「待处理问题」与「资源概况」不再只按内容撑高、在下方留出几百像素的空洞，而是与左侧的高卡片等高，脚注信息统一贴住卡底。
  - **Cards fill their row**: on wide windows the issue and resource cards stretch to the row height instead of leaving a large empty area underneath.
- **「待处理问题」空态变成体检清单**：没有问题时不再只剩一行「暂无已确认的待处理问题」，而是列出订阅登录、额度与余额、路由配置三项的实际结果（`正常 N` 或琥珀色 `N 项待处理`）；有问题时按账号／资源／路由分组，并在列表后带出一行「其余正常」。
  - **Empty state as a checklist**: the issue card reports subscription, quota and routing health row by row, and groups real issues by kind.
- **「资源概况」补齐分布信息**：新增健康度分段条（正常／耗尽／失败／待确认，含图例与无障碍标签），供应商列表按问题数排序并给出状态点阵与计数，缓存时间、最近检查与「查看配额」收口到卡底。
  - **Resource overview detail**: a health distribution bar plus a per-provider status breakdown, with cache and entry points pinned to the card footer.
- **趋势图随窗口增高**：调用趋势的绘图高度改为分档变量（13 / 14.5 / 16.5rem），超宽窗口下把左右 2:1 收成 1.75:1，避免柱状图被拉扁。
  - **Taller trend chart**: the chart grows with the window and the column ratio narrows on very wide screens.

## 修复 / Fixes

- **账号页提供商切换栏不再上下移动**：展开账号详情后，内容区使用有界工作区，详情在自己内部滚动，底部切换栏固定在底部且不再遮挡账号内容；Bento 吸顶动画的副本保留原有滚动位置。
  - **Provider dock stays put**: expanding an account no longer pushes the provider switcher around or covers account content, and the animated copy keeps its scroll position.

## 一致性 / Consistency

- 「体检清单」与「待处理问题」列表共用同一套过滤口径，并有单元测试断言两者的问题总数相等，不会出现「清单说正常、列表里有问题」。
- 状态色点不单独承载信息（附屏幕阅读器文本），健康条带 `role="img"` 与完整文案标签。

## 升级说明 / Upgrade notes

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- Windows 数字版本为 `2.2.1.0`；完整版本递增至 `2.2.1-beta.1`，高于公开的 `2.2.0` 与本地 `2.1.1-beta.5`。
- 安装身份、安装目录与数据目录沿用既有设置；无新增数据库迁移、无新增依赖。
- 不修改已有账号、路由、用量留存或本地客户端配置；建议更新前正常退出应用并保留数据备份。

## 已知边界 / Known limits

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 本次为本地构建，不会出现在远端自动更新渠道。
- 布局已在隔离 Chromium 的 2560×1392 与 1440×900 下核对，原生 WebView2 窗口的实际观感（尤其行高）需在本地更新后确认。
