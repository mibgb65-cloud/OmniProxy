# OmniProxy v2.0.0-beta.3

修复 Codex WebSocket 预热被误当成正式模型调用，以及转发失败时错误状态丢失的问题。

- 正确处理 Codex 的 `generate=false` 连接预热：由网关本地响应并保留会话上下文，不调用上游模型，也不计入模型请求和用量。正式请求才合并上下文并转发，避免传输专用字段进入 HTTP 上游。
- HTTP 与 WebSocket 共用上游失败分类；请求拒绝、认证失败、余额不足及限流不再全部显示为通用 502。错误帧保留状态、固定错误码和合法的重试等待时间，账号冷却记录与尝试结果保持一致。
- 收到 `response.completed` 即完成请求，不再等待上游关闭连接；不完整流仍明确失败，嵌套上游错误原文不会泄露给客户端。
- 加强 `generate`、前序响应引用及流格式校验，并增加临时数据库回归与真实本机 Codex CLI 的离线契约测试。

已在独立配置目录、假密钥、模拟上游和随机本地端口中验证 Codex CLI 0.163.0。隔离测试没有修改用户现有 Codex 配置或登录状态，不代表真实账号的模型权限、额度及所有上游参数已通过验收；此前历史上游 400 的具体原因仍不能仅凭模拟测试确认。

Windows amd64 测试版。请同时下载安装器和同名 `.sha256` 文件校验。支持覆盖安装与应用内下载、校验、重启静默更新；卸载保留本地数据。Beta.1／Beta.2 用户可使用「正式版与 Beta 测试版」渠道检查更新，实际调用前仍需启动网关并确认客户端已接入。

本版保留 Beta.2 的历史统计库保护、独立快捷方式图标及正式更新渠道修复，不改变现有账号／数据迁移边界。发布本身不会自动切换客户端配置或升级本机应用。

本版尚未接入代码签名。升级及历史数据兼容边界见 [升级说明](https://github.com/mibgb65-cloud/OmniProxy/blob/main/docs/product/UPGRADE.md)。
