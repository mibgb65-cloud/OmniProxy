# OmniProxy v2.2.3-beta.18

## Bug Fixes / 问题修复

- Images sent from Antigravity now reach Gemini instead of failing locally. The gateway's request shaper only accepted plain text parts, so an inline screenshot or photo produced an immediate `400 unsupported_content` from OmniProxy itself — the request never reached Google. Inline `data:` images (PNG, JPEG, WebP, GIF, HEIC, HEIF; up to 16 MiB of base64 per image) are now converted to the upstream `inlineData` part and travel alongside the text of the same message. / Antigravity 发的图片现在会真正送到 Gemini，不再在本地失败。整形层此前只接受纯文本 part，因此内联截图或照片会被 OmniProxy 直接返回 `400 unsupported_content`，请求根本没到 Google。现在内联 `data:` 图片（PNG／JPEG／WebP／GIF／HEIC／HEIF，单图 base64 上限 16 MiB）会转换为上游 `inlineData`，与同一条消息的文本一起发送。
- Anything that cannot be inlined is still rejected explicitly rather than silently dropped: remote `https://` image URLs (the upstream does not fetch them for us), formats outside the list above, and images placed in system, assistant or tool-result messages. / 无法内联的形式仍然明确失败，而不是被静默丢弃：远程 `https://` 图片地址（上游不会代为下载）、清单之外的格式，以及出现在 system／assistant／工具结果里的图片。

## Breaking Changes / 不兼容变更

None / 无。No database migration, no public API change; text-only requests, tools, thinking levels and other providers are untouched / 无新增数据库迁移、无公共 API 变更；纯文本请求、工具、思考档位与其它提供商均未改动。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release. Fully exit OmniProxy from the system tray (the running instance is beta.16 or beta.17), back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布。请先从托盘完全退出 OmniProxy（当前运行的是 beta.16 或 beta.17），备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.18`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`. / 应用／前端版本为 `2.2.3-beta.18`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
- This build also contains the previous local build (beta.17): the Google account settings panel with queue/balanced rotation (migration 047) and the fix that keeps a model's own reasoning level. / 本版同时包含上一版（beta.17）内容：Google 账号设置面板的队列／平衡轮换（迁移 047）与型号自带推理档位的修复。
- No database change in this build; accounts, routes, statistics and client configuration are preserved. / 本版无数据库变更；账号、路由、统计与客户端配置保留。

## Verification and limits / 校验与边界

- `task --force verify` passed: format check, lint, typecheck, Go test packages, frontend suite (148 files / 902 tests) and the Windows production build. / `task --force verify` 通过：格式检查、lint、类型检查、Go 测试包、前端测试（148 文件／902 项）与 Windows 生产构建。
- Verified end-to-end on an isolated instance (copy of the production data directory, separate port, running app untouched): a non-streaming request carrying a 1×1 PNG returned 200 with `OK`; a streaming request with the same image returned 200 and the model described the pixel (“solid coral-pink image”), proving the image bytes actually reached Gemini rather than being dropped. / 隔离实例（生产数据目录副本、独立端口，未触碰运行中的应用）端到端验证：带 1×1 PNG 的非流式请求返回 200 并回答 `OK`；同一图片的流式请求返回 200，模型把这个像素描述成 “solid coral-pink image”，说明图片字节确实到达 Gemini，没有被丢弃。
- The model catalog still publishes `supportsImages` from account metadata, which the Google subscription snapshot does not include; if the desktop hides its attach button for a model that can actually see images, that flag is the reason and can be revisited. / 模型目录的 `supportsImages` 仍按账号元数据发布，而 Google 订阅快照没有这个字段；如果桌面端对某个实际能看图的模型隐藏了附件按钮，原因就是这个标记，可以再调整。
- The desktop client's own 60-second cut-off for long-thinking models (`499 request_cancelled` on `gemini-4-argon-high`) is unchanged and cannot be fixed from the gateway. / 桌面端对长思考模型自己的 60 秒上限（`gemini-4-argon-high` 的 `499 request_cancelled`）本版未变，也无法从网关修复。
- The local installer is unsigned and may trigger an unknown-publisher or SmartScreen warning. Building does not install or launch the application. / 本地安装器未签名，可能触发未知发布者或 SmartScreen 提示；构建不安装、不启动应用。
