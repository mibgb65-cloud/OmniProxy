# OmniProxy v2.2.1-beta.4 - 账号卡片列宽修正 / Account card width fixed

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对本地 `v2.2.1-beta.3`，本次修正账号页原位展开面板里账号卡片被拉成半个屏幕宽的问题。

## 修复 / Fixes

- **卡片宽度封顶，超宽窗口只加列不加宽**：展开面板的卡片网格此前被固定两列等分，
  2560×1392 全屏时单卡约 1075px，卡片里的额度进度条、5h／一周数值与 Token 三列全被摊平。
  现在沿用详情页既定规则（`auto-fill` + `clamp(20rem, …, 28rem)`），单卡不超过 28rem，
  宽屏自动增加列数：同一宽度下从 2 列 × ≈1075px 变为 4 列 × 448px。
  - **Capped width, more columns**: the expanded panel used to force two equal columns, so each
    card stretched to roughly 1075px on a 2560px-wide window and its quota bars and metrics
    flattened out. It now reuses the detail-page rule: at most 28rem per card, extra columns
    as the window grows (4 × 448px where it used to be 2 × 1075px).
- **窄面板不再留大片空白**：只剩一列时该列用满 28rem 上限，而不是停在 20rem 最小宽度。
  - **No dead space when narrow**: a single column grows to the 28rem cap instead of stopping at 20rem.
- **回归保护**：新增 CSS 断言测试，锁住「自动增列 + 单卡封顶」，禁止再写固定列数。
  - **Regression guard**: new CSS assertions pin the auto-fill layout and reject fixed column counts.
