# OmniProxy v2.2.3-beta.6

## Features / 新功能

None / 无。

## Bug Fixes / 问题修复

- The dashboard, usage and requests pages no longer show a manual refresh button. They already update automatically: the dashboard reloads on local activity events and when the window becomes visible again, while usage and requests poll every 5 seconds.
  - 仪表盘、用量页与请求页不再显示手动刷新按钮。三页本就自动更新：仪表盘在本地记账事件和窗口重新可见时重新读取，用量与请求页每 5 秒轮询一次。
- The logs footer keeps a constant height: the "Jump to latest" button and the "Following latest" text now share a fixed 32px row, so switching between paused and following no longer resizes the log list or makes the page jump.
  - 日志页脚高度保持恒定：「回到最新」按钮与「自动跟随最新」提示共用固定 32px 行高，暂停与跟随状态切换不再改变日志列表高度，页面不再跳动。
- Refresh failures on the dashboard now say they retry automatically instead of asking for a refresh action that no longer exists.
  - 仪表盘统计读取失败的提示改为「稍后自动重试」，不再指向已移除的刷新按钮。

## Breaking Changes / 不兼容变更

None / 无。No new database migration or public API change / 无新增数据库迁移或公共 API 变更。

## Refactor & Performance / 重构与性能

- Removed the refresh-only dashboard hook fields, unused spin icons and the `dash.refresh` / `activity.refresh` translation keys.
  - 删除仅为刷新按钮存在的仪表盘 hook 字段、未使用的旋转图标，以及 `dash.refresh`／`activity.refresh` 文案键。No new dependency / 无新增依赖。

## Local update / 本地更新

- This is a local Windows amd64 Beta production installer, not a public release. Fully exit OmniProxy from the system tray, back up the current data directory, then run the installer over the existing installation.
  - 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布。请先从托盘完全退出 OmniProxy，备份当前数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.6`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`.
  - 应用／前端版本为 `2.2.3-beta.6`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
- Existing accounts, routes, statistics and client configuration are preserved; this release has no database migration.
  - 保留现有账号、路由、统计与客户端配置；本版本没有数据库迁移。

## Verification and limits / 校验与边界

- The implementation task passed the full frontend suite (146 files / 893 tests with 4 workers), all Go package tests and the production build. `task verify` was run but hit 5-second timeouts in three unrelated existing frontend files under default parallelism; those files pass in isolation.
  - 实现任务已通过全量前端测试（限 4 worker，146 文件／893 项）、Go 全部包测试与生产构建；`task verify` 已运行，但默认并发下 3 个无关既有前端文件出现 5 秒超时，单独重跑通过。

  - 本次打包不重跑测试或 `task verify`；生产编译及安装器元数据／SHA256 核对仅代表构建验收，不代表重新通过完整测试。
- The local installer is unsigned and may trigger an unknown-publisher or SmartScreen warning. Building does not install or launch the application.
  - 本地安装器未签名，可能触发未知发布者或 SmartScreen 提示；构建不安装、不启动应用。
