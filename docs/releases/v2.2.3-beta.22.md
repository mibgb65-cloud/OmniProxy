# OmniProxy v2.2.3-beta.22

## Changes / 本版内容

- The usage page is now a full analytics view. Six KPI cards cover lifetime tokens, lifetime requests, 30-day tokens with a comparison against the previous 30 days, average tokens per request, the cache-hit lower bound and the 30-day success rate. A daily trend switches between 7/14/30 days and tokens/requests, and the page adds a token-composition donut, model/provider/account shares, a top-6 model daily stack with the rest folded into “Other”, a 24-hour request distribution and 30-day request quality (success rate, average latency, average first token). Everything is computed read-only from the existing `usage_buckets`, `usage_provider_models`, `usage_accounts` and `dashboard_buckets`; there is no new migration and no chart library. / 用量页扩展为完整分析视图。6 个 KPI 覆盖累计 Token、累计请求、近 30 天 Token（含与上一个 30 天的环比）、平均每请求 Token、缓存命中下界与近 30 天成功率；每日趋势可在 7／14／30 天和 Token／请求数之间切换，另有 Token 构成环形图、模型／提供商／账号占比、Top 6 模型每日堆叠（其余合并为「其他」）、24 小时请求时段分布与近 30 天请求质量（成功率、平均耗时、平均首字）。全部只读现有 `usage_buckets`、`usage_provider_models`、`usage_accounts` 与 `dashboard_buckets`，无新增迁移、无图表库。
- Local proxy detection no longer fills a scheme into the address field. Clicking a detected endpoint used to write `auto://127.0.0.1` into the editable host, so both Test and Save failed with `proxysettings: invalid input: host`. Discovery now returns the host separately, the form stops parsing the display text, and an address containing a scheme, port or path is rejected inline with a clear message while Test/Save stay disabled. / 本机代理探测不再把协议写进地址字段。此前点击探测结果会把 `auto://127.0.0.1` 填进可编辑的主机，测试与保存都报 `proxysettings: invalid input: host`。现在探测结果单独返回主机，表单不再反解展示文本；地址含协议、端口或路径时就地给出说明，并禁用测试／保存。
- Also inherited from beta.19–beta.21: compact Google account card, Antigravity inline images, Google account rotation settings (migration 047), variant reasoning levels taken from the model name, and in-progress requests pinned to the top of the request list with a “Finished” divider. / 同时沿用 beta.19–beta.21：Google 账号卡片恢复紧凑、Antigravity 内联图片、Google 订阅账号轮换设置（迁移 047）、以变体型号为准的推理等级，以及请求页进行中记录置顶并带「已结束」分隔行。

## Breaking Changes / 不兼容变更

- The usage page replaces the old three-card layout with the new analytics sections; the underlying data meaning is unchanged. / 用量页以新的分析区块替换旧的三卡布局，数据口径不变。
- The proxy address field now rejects schemes, ports and paths before saving. Previously such input reached the backend and failed with a raw error. / 代理地址字段现在会在保存前拒绝协议、端口与路径；此前这类输入会到后端才以原始错误失败。
- No new database migration. Migration 047 only runs if the installed build predates beta.17. / 无新增数据库迁移；仅当安装版本早于 beta.17 时执行迁移 047。
- No public API change. / 无公共 API 变更。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release. Fully exit OmniProxy from the system tray, back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布。请先从托盘完全退出 OmniProxy，备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.22`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`. / 应用／前端版本为 `2.2.3-beta.22`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。

## Verification and limits / 校验与边界

- Both feature tasks passed `task verify` (latest run: format check, lint, typecheck, Go test packages, frontend suite 151 files / 924 tests, and the Windows production build). / 两项功能任务的 `task verify` 均通过（最近一次：格式检查、lint、类型检查、Go 测试包、前端 151 文件／924 项测试与 Windows 生产构建）。
- The proxy fix is covered by a Go assertion that discovery returns the plain host alongside the scheme-prefixed display endpoint, and by dialog tests that fill a real `auto://127.0.0.1:7890` result and reject an address still containing a scheme. / 代理修复由 Go 断言（发现结果同时返回纯主机与带协议的展示端点）和弹窗测试（回填真实的 `auto://127.0.0.1:7890`、拒绝仍含协议的地址）覆盖。
- The usage page's 19 model/insight tests cover the 7/14/30-day series, BigInt sums, comparisons, shares, top-6 stacking and empty data. / 用量页的 19 项模型／洞察测试覆盖 7／14／30 天序列、BigInt 求和、环比、占比、Top 6 堆叠与空数据。
- The local installer is unsigned and may trigger an unknown-publisher or SmartScreen warning. Building does not install or launch the application. / 本地安装器未签名，可能触发未知发布者或 SmartScreen 提示；构建不安装、不启动应用。
