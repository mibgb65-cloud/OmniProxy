# v1.3.2-beta.2 - GPT-6 Sol and Luna support / GPT-6 Sol 与 Luna 模型适配

This beta adds `gpt-6-sol` and `gpt-6-luna` to OmniProxy's model selection, client configuration, and pricing rules. Existing default models remain unchanged.

本次 Beta 为 OmniProxy 增加 `gpt-6-sol` 和 `gpt-6-luna` 模型选择、客户端配置和费用估算规则，现有默认模型保持不变。

## Features / 新特性

- **GPT-6 Sol and Luna selectable**: Both models are now available in the Codex model picker, the Codex and OpenAI-compatible gateway presets, and the generated OpenCode and Pi model lists.
  - **GPT-6 Sol 与 Luna 可选**：两个模型已加入 Codex 模型选择、Codex 与 OpenAI 兼容网关预设，以及生成的 OpenCode、Pi 模型列表。
- **Codex configuration and profiles**: Codex configuration and model profiles use a 1,050,000-token context window and a 900,000-token auto-compaction threshold for Sol and Luna, with the existing `xhigh` reasoning setting.
  - **Codex 配置与模型配置文件**：Sol 与 Luna 使用 1,050,000 token 上下文窗口和 900,000 token 自动压缩阈值，沿用 `xhigh` 推理档位。
- **Model-name normalization**: Chat Completions to Codex Responses conversion now normalizes `gpt-6-sol` and `gpt-6-luna`, including prefixed names such as `openai/gpt-6-sol`, display-style capitalization such as `GPT-6 Sol`, and effort-suffixed aliases such as `gpt-6-sol-high`. Reasoning effort is preserved, including `none`, which Sol and Luna support.
  - **模型名规范化**：Chat Completions 转 Codex Responses 时支持 `gpt-6-sol`、`gpt-6-luna` 的规范化，覆盖 `openai/gpt-6-sol` 前缀名称、`GPT-6 Sol` 展示形式大小写和 `gpt-6-sol-high` 等推理档位别名，并保留推理档位（含 Sol、Luna 支持的 `none`）。
- **Pricing rules**: Added standard token prices plus cache and long-context metadata for Sol ($2 input / $10 output, $0.2 cached input, $2.5 cache writes) and Luna ($0.1 input / $0.5 output, $0.01 cached input, $0.125 cache writes), both with the 272K long-context multipliers.
  - **计价规则**：加入 Sol（输入 $2 / 输出 $10，缓存输入 $0.2，缓存写入 $2.5）与 Luna（输入 $0.1 / 输出 $0.5，缓存输入 $0.01，缓存写入 $0.125）的标准 token 单价及缓存、长上下文参数，长上下文档位阈值与其他 GPT-6 模型一致。

## Compatibility And Upgrade Guidance / 兼容性与升级说明

- Existing model defaults (`gpt-5.6-sol` / `gpt-5.6-terra` / `gpt-5.6-luna`), account pools, routes, history, and billing summaries are preserved. No local-data migration is required.
  - 保留现有默认模型（`gpt-5.6-sol` / `gpt-5.6-terra` / `gpt-5.6-luna`）、账号池、路由、历史和费用汇总，无需迁移本地数据。
- Select GPT-6 Sol or Luna in the gateway routing page or the Codex model configuration. Run the client configuration action again to add them to an existing OpenCode or Pi configuration.
  - 请在网关路由页或 Codex 模型配置中选择 GPT-6 Sol 或 Luna；已有 OpenCode、Pi 配置需重新执行客户端配置操作以添加这两个模型。
- Upstream access still depends on model availability for the selected account. Sol and Luna roll out in ChatGPT Work and Codex for paid tiers and are available in the API; requests may fail on accounts or plans without access.
  - 实际调用取决于所选账号是否已开放该模型。Sol 与 Luna 面向付费用户的 ChatGPT Work、Codex 上线并同时提供 API 访问；未开放的账号或套餐可能请求失败。
- Model parameters were checked against the [official OpenAI documentation](https://developers.openai.com/api/docs/guides/latest-model). No live paid upstream request was made during local validation.
  - 模型参数已核对 OpenAI 官方文档；本地验证没有发送真实付费上游请求。
