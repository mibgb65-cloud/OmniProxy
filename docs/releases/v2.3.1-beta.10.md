# OmniProxy v2.3.1-beta.10

## New Features / 新功能

- The Quota page now shows Baidu DuMate points instead of “Not supported yet” / 「暂不支持」. DuMate login-state accounts display the official remaining points, used / total and the expiry of the nearest active points package, plus the locally recorded token usage underneath. / 配额页现在显示百度搭子 DuMate 的官方积分，不再标为「暂不支持」。登录态账号会展示可用积分、已用／总量与最近一个有效积分包的到期信息，下方同时列出该账号本机记录的 Token 用量。
- Points and token usage are two different sources and are never converted into each other: points come from the DuMate console, tokens come from this app's request history, and the card keeps the existing note that local usage is not the official bill. / 积分与 Token 用量是两种来源，互不换算：积分来自 DuMate 控制台，Token 来自本应用的请求记录，卡片保留「本机用量不是官方账单」的说明。
- The points query has three states and the quota card maps them honestly: `live` compares remaining points for available / exhausted, `stale` (console temporarily failed but a successful snapshot is retained) is shown as “refresh needed” with the retained values, and `unavailable` is shown as a query failure. None of them is reported as zero points. / 积分查询本身有三态，配额卡如实映射：`live` 按剩余积分判充足／不足；`stale`（控制台暂时失败但保留期内有成功快照）显示为「待刷新」并保留数值；`unavailable` 显示为查询失败。三者都不会被报成零积分。
- Accounts whose login state is no longer valid are not queried at all: the card shows “sign in required” and the DuMate console is not contacted, matching the accounts page behaviour. / 登录态失效的账号不再发起查询：卡片显示「需要登录」且不访问 DuMate 控制台，与账号页行为一致。

## Breaking Changes / 不兼容变更

None / 无。No database migration, no public API change, no gateway or routing change. The points query reuses the existing `DuMatePoints` binding and the same query key as the accounts page, so the cache is shared instead of hitting the console twice. / 无数据库迁移、无公共 API 变更、不改网关与路由。积分查询复用既有 `DuMatePoints` 绑定与账号页相同的查询键，两处共享缓存，不会重复访问控制台。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release and not signed. Fully exit OmniProxy from the system tray, back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布、未签名。请先从托盘完全退出 OmniProxy，备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.3.1-beta.10`; Windows numeric resources: `2.3.1.0`; NSIS installer base version: `2.3.1`. / 应用／前端版本为 `2.3.1-beta.10`，Windows 数字资源版本为 `2.3.1.0`，NSIS 安装器基础版本为 `2.3.1`。
- Existing accounts, routes, statistics and client configuration are preserved; this release has no database migration. The DuMate card queries the console when the Quota page opens; the sign-in button remains on the account detail page. / 保留现有账号、路由、统计与客户端配置；本版本没有数据库迁移。打开配额页时 DuMate 卡片会查询控制台积分，签到入口仍在账号详情页。

## Verification boundary / 验证边界

- `task verify` passed before packaging: format, lint (`go vet`／`staticcheck`／ESLint), `tsc --noEmit`, all Go packages, frontend tests and the Windows production build. / 打包前 `task verify` 通过：格式、lint（`go vet`／`staticcheck`／ESLint）、`tsc --noEmit`、Go 全包、前端测试与 Windows 生产构建。
- New coverage: DuMate is classified as a points resource with a queryable refresh; the three query states map to available, refresh-needed and query-failed (never zero points); an invalidated login state neither queries the console nor shows points; and a page-level test asserts that the card renders official points and local token usage together without the “not supported” wording. / 新增覆盖：DuMate 被归类为可查询的积分资源；三种查询状态分别映射为充足、待刷新与查询失败（都不是零积分）；登录态失效时既不访问控制台也不显示积分；页面级测试断言卡片同时渲染官方积分与本机 Token 用量，且不再出现「暂不支持」。
- Not verified: a real desktop window against the real DuMate account (console response timing and card layout next to other providers), and the real points value after a manual sign-in. / 未验证：真实桌面窗口里真实 DuMate 账号的控制台响应时序与卡片在其它服务商旁的布局，以及手动签到后的真实积分变化。
