# OmniProxy v2.5.1

Windows amd64 patch release for the setup flow. /
这是一个修正 Windows amd64 安装流程的补丁版本。

## Features / 新功能

None / 无。

## Bug Fixes / 修复

- The Windows setup helper now opens the desktop user's token with the permissions required to look up AppData. This addresses a compatibility issue that could stop setup between the program-folder and data-folder pages. / Windows 安装辅助程序现在按 API 要求打开桌面用户令牌再查找 AppData，修正了一个可能导致安装在程序目录页与数据目录页之间中止的兼容问题。
- When setup cannot identify the current data folder, it shows an `OMNI-DATA-*` code that identifies the failed step without exposing a local path. Setup still stops instead of guessing a data folder. / 无法确认当前数据位置时，安装器会显示区分失败环节的 `OMNI-DATA-*` 诊断码，不暴露本机路径。安装器仍会停止，不会猜测默认位置。

## Breaking Changes / 不兼容变更

None. No database migration or change to existing data locations. / 无。没有数据库迁移，也不改变已有数据位置。

## Refactor & Performance / 重构与性能

None / 无。

## Upgrade / 更新

- From v2.5.0 or the local v2.5.1-beta.1, exit OmniProxy from the notification area, back up the data folder, and install over the existing program folder. Keep the current data location. / 从 v2.5.0 或本地 v2.5.1-beta.1 更新时，请从托盘完全退出 OmniProxy，备份数据目录后覆盖安装到原程序目录，保留当前数据位置。
- The installer fix was tested on Windows 11. The reported Windows 10 first-install failure has not been reproduced on Windows 10 hardware. If setup still stops, share the `OMNI-DATA-*` code; no local path is needed. / 安装器修复已在 Windows 11 上进行专项验证，尚未在 Windows 10 实机复现原报告的首次安装失败。如果安装仍中止，请提供 `OMNI-DATA-*` 诊断码，无须提供本机路径。
