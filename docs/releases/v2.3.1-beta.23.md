# OmniProxy v2.3.1-beta.23

## Bug Fixes / 问题修复

- An account card whose identity no longer returns a plan now reads “无套餐” (No plan) instead of “套餐未知” (Unknown plan). The badge and the credits card take their plan from two different sources, so the old wording wrongly suggested the plan was merely unrecognized. / 账号身份没有返回套餐字段时，账号卡徽章现在显示「无套餐」（No plan），不再显示「套餐未知」。该徽章与额度卡的套餐名来自两个不同来源，旧文案会让人误以为只是「没认出来」。
- Antigravity (Google subscription) plan badges now show readable tier names instead of raw backend ids: `g1-ultra-tier` → **Ultra** (rose), `g1-pro-tier` → **Pro** (amber), `g1-free-tier`／`free-tier` → **Free**. Other identifiers are still shown verbatim with the neutral badge. / Antigravity（Google 订阅）的套餐徽章不再直接显示后端标识：`g1-ultra-tier` → **Ultra**（rose）、`g1-pro-tier` → **Pro**（amber）、`g1-free-tier`／`free-tier` → **Free**。其它标识仍原样显示并使用中性配色。

## Breaking Changes / 不兼容变更

None / 无。No database migration, no API change, no stored-data change: `auth_plan` keeps the upstream identifier and the mapping happens only when rendering. / 无数据库迁移、无 API 变更、无存量数据变化：`auth_plan` 仍保存上游标识，映射只发生在渲染时。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release and not signed. Fully exit OmniProxy from the system tray, back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布、未签名。请先从托盘完全退出 OmniProxy，备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.3.1-beta.23`; Windows numeric resources: `2.3.1.0`; NSIS installer base version: `2.3.1`. / 应用／前端版本为 `2.3.1-beta.23`，Windows 数字资源版本为 `2.3.1.0`，NSIS 安装器基础版本为 `2.3.1`。
- After upgrading, open the Google / Antigravity account page: the badge shows `Ultra` or `Pro` in its own colour. WorkBuddy accounts still show “无套餐” on the badge while the credits card keeps showing the billing-side package name (e.g. 体验版／Free) — the two sources are intentionally not merged in this version. / 升级后打开 Google／Antigravity 账号页，徽章会显示带配色的 `Ultra` 或 `Pro`。WorkBuddy 账号的徽章仍显示「无套餐」，额度卡标题旁仍显示计费接口给出的套餐名（如 体验版／Free）——本版本有意不合并这两个来源。

## Verification boundary / 验证边界

- `task verify` passed before packaging: format, lint (`go vet`／`staticcheck`／ESLint), `tsc --noEmit`, all Go packages, frontend tests and the Windows production build. / 打包前 `task verify` 通过：格式、lint（`go vet`／`staticcheck`／ESLint）、`tsc --noEmit`、Go 全包、前端测试与 Windows 生产构建。
- Covered by tests: empty／whitespace plan renders “无套餐”, tier mapping for Ultra／Pro／Free, distinct badge colours for Ultra and Pro, unknown identifiers keep their raw text and neutral colour. / 测试覆盖：空值与空白套餐渲染「无套餐」、Ultra／Pro／Free 档位映射、Ultra 与 Pro 配色不同、未知标识保留原文与中性配色。
- **Not verified visually in this version**: the badge colours were checked by unit tests against class names, not by a screenshot on a real account page. / **本版本未做界面截图核对**：徽章配色由单元测试按类名校验，未在真实账号页截图确认。
