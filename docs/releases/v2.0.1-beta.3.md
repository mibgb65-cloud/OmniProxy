# OmniProxy v2.0.1-beta.3

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 界面：主题切换改为圆形扩散过渡

标题栏右上角的亮／暗模式按钮不再整屏直接跳变，改为从点击位置向四周扩散的圆形过渡：

- 新主题以点击位置为圆心，从 `circle(0px)` 扩散到覆盖视口的半径（取点击点到最远屏幕角的距离），
  约 700ms、`cubic-bezier(0.4, 0, 0.2, 1)` 缓动铺满窗口；旧主题不做淡出，扩散过程中不会整屏闪烁。
- 基于浏览器原生 View Transitions API（`document.startViewTransition`），并关闭该 API 默认的
  交叉淡入淡出，只保留新主题的圆形展开；新主题始终绘制在旧主题之上平滑展开。
- 键盘操作（Enter／Space）时以按钮中心为圆心，不会从窗口左上角扫过。
- 运行时不支持该 API、系统要求「减少动画」或浏览器拒绝启动过渡时，主题立即切换，
  色板、`color-scheme` 与按钮图标与状态保持一致，不会残留动画样式。
- 主题偏好、持久化与其它窗口按钮行为不变。

## 其他

- 文档与任务记录归档；产品行为无其它变化。

## 升级说明

- 覆盖安装即可，无新增数据库迁移、无新增依赖。
- 数字版本仍是 `2.0.1.0`（同一 patch 的 beta 递增不改数字版本），安装身份、安装目录与数据目录
  沿用原设置；路由、别名、账号、客户端配置、用量、额度留存快照与重置操作记录保持不变。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 主题扩散动画的观感（不同窗口尺寸、非 100% 缩放下的圆心覆盖范围与节奏）只在单元测试与
  构建产物层面核对，**尚未在真实窗口人工验收**；若某些缩放下扩散边缘显得过快或过慢，
  后续只需调整 `theme-reveal.css` 的时长与半径计算。
- WebView2 之外的运行时（例如未来若改用不支持 View Transitions 的引擎）会退化为立即切换。
