# OmniProxy v2.5.1-beta.1

Local Windows amd64 production build for testing the installer change before v2.5.1. /
这是用于验证 v2.5.1 安装器改动的本地 Windows amd64 生产构建。

## Bug Fixes / 修复

- Request the Windows token permissions required to find the desktop user's AppData from the installer. This addresses a compatibility issue in the setup step that runs after you choose the program folder. / 安装器按 Windows API 要求取得用户令牌权限，再查询当前桌面用户的 AppData。修正选择程序目录并点「下一步」后，确定用户数据位置时的一个兼容问题。
- If setup still cannot verify the data folder, the error includes an `OMNI-DATA-*` code that identifies the failed step. The message does not expose local paths, and setup stops without changing existing data. / 如果仍无法确认数据位置，弹窗会显示指出失败环节的 `OMNI-DATA-*` 诊断码，不显示本机路径。安装保持停止，已有数据不变。

## Local update / 本地覆盖更新

- Close OmniProxy from the Windows notification area, back up the current data directory, and run the Beta installer over the existing program folder. Keep the existing data location. No database migration is included. / 从 Windows 托盘完全退出 OmniProxy，备份当前数据目录后，在原程序目录覆盖安装，并保留原有数据位置。本版本不含数据库迁移。
- This local Beta is unsigned and is not a public GitHub release. The original Windows 10 failure has not been reproduced on a Windows 10 machine. / 本地 Beta 未签名，不是 GitHub 公开发布。原反馈场景尚未在 Windows 10 实机复现。
