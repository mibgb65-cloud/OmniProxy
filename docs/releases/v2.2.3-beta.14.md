# OmniProxy v2.2.3-beta.14

## Bug Fixes / 问题修复

- Antigravity requests no longer fail with `400 unsupported_protocol`. The desktop app's Chat body goes through the Antigravity-specific parser, which filled the stream, effort and body fields but never marked the protocol, so the gateway treated it as an unknown protocol and rejected it before anything reached Google. Every Google model — including exact IDs such as `gemini-3.8-flash-high` — failed this way. The parser now marks Chat requests as `chat`, exactly like the regular `/v1/chat/completions` path. / Antigravity 请求不再报 `400 unsupported_protocol`。桌面端的 Chat 正文走 Antigravity 专用解析分支，该分支只填了 stream、档位和正文，没有标记协议，网关当成未知协议在任何请求到达 Google 之前就拒绝了；所有 Google 模型（包括 `gemini-3.8-flash-high` 这类精确 ID）都失败。现在解析层统一标记 `chat`，与普通 `/v1/chat/completions` 分支一致。
- The model-family fix from beta.13 is included and now reaches upstream: `gemini-4-argon` resolves to `gemini-4-argon-high`, `-medium` or `-low` by the requested level, `claude-opus-4-6` to `claude-opus-4-6-thinking`, `gpt-oss-120b` to `gpt-oss-120b-medium`. / beta.13 的家族模型名修复一并包含，并且现在真正到达上游：`gemini-4-argon` 按档位解析到 `-high`／`-medium`／`-low`，`claude-opus-4-6` → `claude-opus-4-6-thinking`，`gpt-oss-120b` → `gpt-oss-120b-medium`。

## Verification and limits / 校验与边界

- `task --force verify` passed: format check, lint, typecheck, Go test packages, frontend suite (147 files / 898 tests) and the Windows production build. / `task --force verify` 通过：格式检查、lint、类型检查、Go 测试包、前端测试（147 文件／898 项）与 Windows 生产构建。
- End-to-end requests were run against an isolated instance built from this source, using a copy of the production data directory on a separate port, so the running app was untouched: `gemini-4-argon` (no level) → 200 `gemini-4-argon-high`; `gemini-4-argon` + `medium` → 200 `gemini-4-argon-medium`; `claude-opus-4-6` → 200 `claude-opus-4-6-thinking`; `gpt-oss-120b` → 200 `gpt-oss-120b-medium`; `gemini-3.8-flash` + `low` with `stream:true` → 200 SSE. / 端到端请求在由本源码构建的隔离实例上执行（生产数据目录的副本、独立端口，未触碰正在运行的应用）：`gemini-4-argon`（无档位）→ 200 `gemini-4-argon-high`；`gemini-4-argon` + `medium` → 200 `gemini-4-argon-medium`；`claude-opus-4-6` → 200 `claude-opus-4-6-thinking`；`gpt-oss-120b` → 200 `gpt-oss-120b-medium`；`gemini-3.8-flash` + `low` 且 `stream:true` → 200 SSE。
- One `gemini-4-argon-medium` attempt returned `502 operation_failed` after exactly 30 s and succeeded on retry in 28 s: these thinking models are slow, so a long generation can hit the 30 s non-streaming request limit. Streaming requests are not affected. / 一次 `gemini-4-argon-medium` 在正好 30 秒时返回 `502 operation_failed`，重试 28 秒成功：思考型模型较慢，长生成可能撞上非流式请求的 30 秒时限；流式请求不受影响。
- The desktop app itself has not been re-tested here; after installing, send a message in Antigravity and the request detail should show the resolved variant with status 200. / 桌面端本身未在此环境复测；安装后在 Antigravity 发一条消息，请求明细应显示解析后的变体与 200 状态。
- The local installer is unsigned and may trigger an unknown-publisher or SmartScreen warning. Building does not install or launch the application. / 本地安装器未签名，可能触发未知发布者或 SmartScreen 提示；构建不安装、不启动应用。
