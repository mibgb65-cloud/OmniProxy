# v1.2.9 - Codex compatibility and quota accuracy / Codex 兼容性与额度准确性

This stable release consolidates the v1.2.9 beta line. It improves Codex one-click authentication, adds native DeepSeek Responses profiles, supports Codex Live WebSockets, preserves separate Team email accounts, and makes weekly quota estimates reset-credit aware.

本正式版整合 v1.2.9 beta 系列改动：改进 Codex 一键配置认证，新增 DeepSeek 原生 Responses profile，支持 Codex Live WebSocket，分别保留 Team 工作区中的不同邮箱账号，并让周额度预估感知刷新卡。

## Features / 新特性

- **Native DeepSeek Codex Responses profiles**: Codex one-click configuration exposes DeepSeek V4 Pro and V4 Flash through dedicated Responses profiles while preserving OpenAI GPT profiles.
  - **DeepSeek 原生 Codex Responses profile**：Codex 一键配置通过独立 Responses profile 提供 DeepSeek V4 Pro 与 V4 Flash，同时保留 OpenAI GPT profile。
- **Model-specific DeepSeek defaults**: DeepSeek profiles use HTTP/SSE transport, a 1,048,576-token context window, a 95% automatic compaction threshold, and high reasoning effort.
  - **DeepSeek 按模型默认值**：DeepSeek profile 使用 HTTP/SSE 传输、1,048,576 Token 上下文、95% 自动压缩阈值和高推理档位。

## Bug Fixes / 问题修复

- **Compatible Codex login mode**: One-click configuration uses ChatGPT login only when the selected ID token includes the required plan claim. Incomplete metadata falls back to local API login without modifying signed tokens or bypassing the OmniProxy account pool.
  - **Codex 登录模式兼容**：只有所选 ID Token 包含必需的套餐声明时，一键配置才使用 ChatGPT 登录。元数据不完整时会安全回退到本地 API 登录，不修改已签名令牌，也不绕过 OmniProxy 账号池。
- **Codex Live WebSocket forwarding**: `/codex/v1/live` Upgrade requests now use the bidirectional WebSocket proxy with the selected account's authentication instead of returning `404 Not Found` through ordinary HTTP forwarding.
  - **Codex Live WebSocket 转发**：`/codex/v1/live` Upgrade 请求现在使用带有已选账号鉴权的双向 WebSocket 代理，不再通过普通 HTTP 转发返回 `404 Not Found`。
- **Team email accounts stay separate**: OAuth identity matching checks email before `account_id`, preventing two emails in one Team workspace from replacing each other while preserving same-account refresh and legacy matching.
  - **Team 邮箱账号分别保留**：OAuth 身份匹配会先检查邮箱，再使用 `account_id`，防止同一 Team 工作区中的两个邮箱互相覆盖，同时保留同账号刷新和旧数据匹配。
- **Reset-credit-aware weekly estimates**: When a reset credit actually changes the weekly window, OmniProxy persists a pre-reset Token baseline and estimates from post-reset input, output, and cache deltas. Five-hour-only resets and natural weekly rollover remain isolated.
  - **刷新卡感知周额度预估**：刷新卡确实改变周窗口时，OmniProxy 会持久化刷新前 Token 基线，并根据刷新后的输入、输出和缓存增量估算；仅 5 小时重置和周窗口自然轮换保持独立。

## Upgrade Guidance / 升级说明

- Run Codex one-click configuration again after upgrading so existing `~/.codex/auth.json` and `config.toml` files receive the compatible login mode and new DeepSeek provider profiles. Restart Codex clients afterward.
  - 升级后请重新执行一次 Codex 一键配置，使现有 `~/.codex/auth.json` 和 `config.toml` 写入兼容的登录模式与新 DeepSeek provider profile，然后重启 Codex 客户端。
- Accounts already overwritten by an older Team identity bug cannot be restored automatically. Sign in again or import the missing email account once.
  - 旧版 Team 身份问题已覆盖的账号无法自动恢复；请重新登录或导入一次缺失的邮箱账号。
- Reset credits consumed before the reset-aware baseline was available are not reconstructed heuristically. Normal estimation resumes with the next weekly window.
  - 刷新卡感知基线可用之前已使用的刷新卡不会被启发式反向推测；下一个周窗口将恢复常规预估。
- Existing account pools, local configuration, request history, billing summaries, and theme state remain compatible with v1.2.8 and the v1.2.9 beta line. No local-data migration is required.
  - 现有账号池、本地配置、请求历史、费用汇总和主题状态与 v1.2.8 及 v1.2.9 beta 系列保持兼容，无需迁移本地数据。
- Beta users can upgrade directly to v1.2.9. The stable version compares newer than every v1.2.9 beta tag.
  - Beta 用户可直接升级到 v1.2.9；正式版版本顺序高于所有 v1.2.9 beta 标签。
- The macOS universal DMG remains unsigned and not notarized. Quit OmniProxy before replacing the app in Applications.
  - macOS Universal DMG 仍未签名且未公证；替换 Applications 中的应用前请先退出 OmniProxy。
