# OmniProxy v2.2.3-beta.1

## Features / 新功能

None / 无。

## Bug Fixes / 问题修复

None / 无。

## Breaking Changes / 不兼容变更

None. No new database migrations or intentional business API changes.

无。不新增数据库迁移，不主动改变业务 API。

## Refactor & Performance / 重构与性能

- Upgrade the desktop framework from Wails `v3.0.0-beta.30` to the stable `v3.1.0` release. The Go module, frontend runtime and build CLI are aligned; existing Taskfile builds are retained without enabling experimental Wake.
  - 桌面框架从 Wails `v3.0.0-beta.30` 升级至正式版 `v3.1.0`，同步 Go 模块、前端运行时和构建 CLI；保留现有 Taskfile，不启用实验性 Wake 构建系统。
- Regenerate bindings and Windows icon metadata with the new CLI. All icon dimensions and pixels remain unchanged.
  - 使用新版 CLI 重新生成绑定与 Windows 图标元数据，图标尺寸和像素保持不变。

## Upgrade notes / 升级说明

- This is a local Windows amd64 Beta production installer for manual in-place updates, not a public release. Fully quit OmniProxy from the system tray and back up the current data directory before running the installer over the existing installation.
  - 本版本为供手动覆盖更新的本地 Windows amd64 Beta 生产安装包，未公开发布。更新前请从托盘完全退出 OmniProxy，并备份当前数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.1`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`.
  - 应用／前端版本为 `2.2.3-beta.1`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
- Existing accounts, data-location settings and update preferences remain unchanged. This framework update adds no new database migration.
  - 既有账号、数据位置与更新偏好保持不变，本次框架升级不增加数据库迁移。

## Verification and limits / 校验与边界

- Tests and the full quality gate are not repeated for this package, as explicitly requested. The preceding Wails upgrade passed 51 Go test packages, 890 frontend tests and an isolated development build with Vitest limited to four workers.
  - 按用户明确要求，本包不重复运行测试与完整质量门；前序 Wails 升级任务已在 Vitest 限 4 并发下通过 51 个 Go 测试包、890 项前端测试和隔离开发构建，不将其冒称为本生产包重新通过完整质量门。
- This local package is unsigned. SHA256 and native version-resource checks do not replace Authenticode signing or real installation acceptance; Windows may show an unknown-publisher warning.
  - 本地包未签名；SHA256 与原生版本资源校验不等于 Authenticode 签名或实际安装验收，Windows 可能提示未知发布者。
- The build does not install or launch the application. Native window/tray behavior and in-place installation remain for local acceptance.
  - 构建过程不安装、不启动应用，原生窗口／托盘行为与覆盖安装由本地更新后验收。
