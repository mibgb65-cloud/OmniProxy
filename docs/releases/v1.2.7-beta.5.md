# v1.2.7-beta.5 - Release page link fix / 发布页链接修复

This beta fixes the update action so that opening a release page never falls back to downloading an installer.

本次 beta 修复更新入口，确保打开发布页时不会误触发安装包下载。

## Bug Fixes / 问题修复

- **Release page action opens only the release page**: The “打开发布页” action now uses only the GitHub release page URL. It no longer falls back to an installer asset URL when the page URL is available.
  - **发布页按钮只打开发布页**：“打开发布页”操作现在只使用 GitHub Release 页面地址；页面地址缺失时也不会回退到安装包地址。
- **Download and release actions are separated**: “下载更新” continues to use the installer download URL, while “发布页” always opens the release page.
  - **下载与发布页操作分离**：“下载更新”继续使用安装包下载地址，“发布页”始终打开 Release 页面。
