# OmniProxy v2.1.1-beta.1 - 升级浮窗布局与发布说明排版 / Upgrade dialog layout and release-note rendering

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对公开正式版 `v2.1.0`，本次唯一的用户可见改动是升级浮窗。

## 新特性 / Features

- **升级浮窗三段式布局**：标题栏与操作区固定，中间独立滚动版本摘要与发布说明，长说明不再把按钮顶出视野。
  - **Three-section dialog**: the header and action bar stay fixed while the version summary and release notes scroll in between.
- **版本摘要分区**：按「当前版本 → 可升级版本」两栏展示，下方元信息行给出发布时间、安装包大小与「打开发布页面」入口。
  - **Structured summary**: current version, target version, publish time, package size and the release-page link in one card.
- **发布说明按 Markdown 排版**：标题、段落、`行内代码`、**加粗**、*斜体*、~~删除线~~、链接、有序／无序及嵌套列表、引用、代码块与分隔线都按语义渲染，不再原样显示 `#` 或 `**`。
  - **Release notes rendered as Markdown**: headings, paragraphs, inline code, emphasis, links, nested lists, quotes, code blocks and rules.
- **安全边界不变**：发布说明中的 HTML 只作为文本显示，`javascript:` 等非 http(s) 链接不生成可点击入口，远端图片不加载、只保留替代文字。

## 升级说明 / Upgrade notes

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- Windows 数字版本为 `2.1.1.0`；完整版本递增至 `2.1.1-beta.1`，高于公开的 `2.1.0`。
- 安装身份、安装目录与数据目录沿用既有设置；无新增数据库迁移、无新增依赖。
- 不修改已有账号、路由、用量留存或本地客户端配置；建议更新前正常退出应用并保留数据备份。

## 已知边界 / Known limits

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 本次为本地构建，不会出现在远端自动更新渠道。
- 浮窗改动通过隔离 Chromium 的深浅主题、空闲／可重启与 900×560 窄窗截图核对，
  原生 WebView2 窗口与 140% 字号观感需在本地更新后确认。
