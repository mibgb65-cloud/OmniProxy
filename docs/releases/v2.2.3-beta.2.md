# OmniProxy v2.2.3-beta.2

## Features / 新功能

- OpenAI subscription model catalogs now refresh automatically in the background after app startup, authorization changes and account updates. Only accounts whose current credential version has no catalog rows are synced; an empty official catalog is treated as that version's terminal result.
  - OpenAI 订阅模型目录会在应用启动、授权变化和账号更新后自动后台补齐；只处理当前凭据版本没有任何模型行的账号，官方空目录按该版本终态处理。
- The model catalog page now exposes passive sync state (`syncing`, `automatic sync incomplete`, or pending accounts) without requiring a confirmation dialog.
  - 模型目录页显示被动的同步状态（同步中、自动同步未完成或待同步账号），不弹出需要用户确认的提示。

## Bug Fixes / 问题修复

- Fixed the silent loss of `balanced` account rotation when the OpenAI model catalog was missing or stale. The `/codex/v1` transparent entry now applies the same same-pool `queue` / `balanced` selection to its fallback candidates instead of always using the first account.
  - 修复 OpenAI 模型目录缺失或过期时 `balanced` 账号轮换静默失效：`/codex/v1` 透明入口的兜底候选现在应用同一套同池队列／平衡选号，不再固定第一个账号。
- Fallback selection degrades to the original order if reading the rotation setting or revalidating candidates fails; only a fully cooling pool returns the existing `account_pool_cooling` error.
  - 兜底选号在设置读取或候选复核失败时退回原顺序；只有全部候选冷却时才返回既有 `account_pool_cooling` 错误。
- Automatic sync failures preserve the last successful catalog, record only a stable error code, and do not block requests. Empty catalogs are not retried repeatedly within the same app run and credential version.
  - 自动同步失败保留上次成功目录，只记录固定错误码，不阻塞请求；空目录在同一应用运行与凭据版本内不会反复重试。

## Breaking Changes / 不兼容变更

None. No new database migrations or intentional business API changes.

无。不新增数据库迁移，不主动改变业务 API。

## Refactor & Performance / 重构与性能

- Generalized the existing Google subscription catalog auto-sync into a shared background component; Google behavior is unchanged and the new OpenAI path adds stale-only filtering plus per-version attempt throttling.
  - 将既有 Google 订阅目录自动同步泛化为共享后台组件；Google 行为不变，OpenAI 路径增加仅陈旧账号过滤与按版本尝试去重。
- Added a read-only sync status query for the model catalog page. No new database table, credential access or upstream probe is introduced.
  - 为模型目录页增加只读同步状态查询，不新增数据库表、凭据访问或上游探测。

## Upgrade notes / 升级说明

- This is a local Windows amd64 Beta production installer for manual in-place updates, not a public release. Fully quit OmniProxy from the system tray and back up the current data directory before running the installer over the existing installation.
  - 本版本为供手动覆盖更新的本地 Windows amd64 Beta 生产安装包，未公开发布。更新前请从托盘完全退出 OmniProxy，并备份当前数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.2`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`.
  - 应用／前端版本为 `2.2.3-beta.2`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
- Existing accounts, data-location settings and update preferences remain unchanged. This update adds no database migration.
  - 既有账号、数据位置与更新偏好保持不变，本次更新不增加数据库迁移。
- After updating, OpenAI catalogs that were invalidated by re-authorization are filled automatically; if the background sync cannot complete, the model catalog page allows a manual retry.
  - 更新后，重新授权导致的 OpenAI 目录失效会自动补齐；若后台同步未完成，可在模型目录页手动重试。
