# OmniProxy v2.2.3-beta.19

## Changes / 本版内容

- The Google account card is compact again. The “Resync to AI agents” button and its long paragraph are gone: catalog sync already happens on startup, sign-in, legacy import and model refresh, and the card's own refresh icon triggers a sync after it reads the official model picker — so the manual retry path is still there, just not as a second button. The sync scope is now explained inside the expanded model list. / Google 账号卡片回到紧凑形态：「重新同步到 AI Agent」按钮与那段长说明已移除。目录同步本来就发生在启动、登录、导入旧版数据与刷新模型列表时，而卡片右上角的刷新图标在成功读取官方选择器后也会触发一次同步——手动重试仍然存在，只是不再占第二个按钮。同步范围改为在展开的模型列表里说明。
- Images sent from Antigravity reach Gemini instead of failing locally. Inline `data:` images (PNG, JPEG, WebP, GIF, HEIC, HEIF; up to 16 MiB of base64 per image) are converted to the upstream `inlineData` part and travel with the text of the same message. Remote image URLs, other formats, and images inside system, assistant or tool-result messages still fail explicitly. / Antigravity 发的图片会送到 Gemini，不再在本地失败。内联 `data:` 图片（PNG、JPEG、WebP、GIF、HEIC、HEIF，单图 base64 上限 16 MiB）转换为上游 `inlineData`，与同一条消息的文本一起发送。远程图片地址、其它格式，以及出现在 system／assistant／工具结果里的图片仍然明确失败。
- Google subscription accounts gained their own settings panel with queue/balanced account rotation (new `google_settings` table, migration 047). / Google 订阅账号新增「Google 账号设置」面板，可切换队列轮换／平衡切换（新表 `google_settings`，迁移 047）。
- A model that already carries its reasoning level keeps it: Antigravity's `gemini-4-hydrogen-high` is no longer reported or executed as `low` just because the client also sent an effort field. / 型号自带推理档位时以型号为准：Antigravity 的 `gemini-4-hydrogen-high` 不再因为客户端另带档位字段而被记录并执行为 `low`。

## Breaking Changes / 不兼容变更

- Migration 047 creates `google_settings` (default `queue`) on first start; no existing table, account or setting is modified. If you skipped beta.17/beta.18 this is the only schema change. / 首次启动执行迁移 047 新建 `google_settings`（默认 `queue`），不改动任何已有表、账号或设置。如果跳过了 beta.17／beta.18，这是唯一的表结构变更。
- The removed button has no replacement control on the card; use the refresh icon (or the routing page) to retry a failed sync. / 被移除的按钮在卡片上没有替代控件；同步失败时用刷新图标（或路由页）重试。
- No public API change. / 无公共 API 变更。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release. Fully exit OmniProxy from the system tray, back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布。请先从托盘完全退出 OmniProxy，备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.19`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`. / 应用／前端版本为 `2.2.3-beta.19`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。

## Verification and limits / 校验与边界

- `task --force verify` passed: format check, lint, typecheck, Go test packages, frontend suite (148 files / 901 tests) and the Windows production build. / `task --force verify` 通过：格式检查、lint、类型检查、Go 测试包、前端测试（148 文件／901 项）与 Windows 生产构建。
- Images were verified end-to-end on an isolated instance (copy of the production data directory, separate port): a non-streaming and a streaming request carrying a 1×1 PNG both returned 200, and the model described the pixel, proving the bytes reached Gemini. / 图片在隔离实例（生产数据目录副本、独立端口）做了端到端验证：带同一张 1×1 PNG 的非流式与流式请求都返回 200，模型描述出了这个像素，说明图片字节确实到达 Gemini。
- Model catalog still publishes `supportsImages` from account metadata, which the Google snapshot does not include. / 模型目录的 `supportsImages` 仍按账号元数据发布，而 Google 快照里没有该字段。
- The desktop client's own 60-second cut-off for long-thinking models (`499 request_cancelled` on `gemini-4-argon-high`) is unchanged. / 桌面端对长思考模型自己的 60 秒上限（`gemini-4-argon-high` 的 `499 request_cancelled`）本版未变。
- The local installer is unsigned and may trigger an unknown-publisher or SmartScreen warning. Building does not install or launch the application. / 本地安装器未签名，可能触发未知发布者或 SmartScreen 提示；构建不安装、不启动应用。
