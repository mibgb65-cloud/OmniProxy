# OmniProxy v2.1.1-beta.5 - 全部弹窗与浮层的进出过渡 / Transitions for every dialog and popover

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

This local prerelease is an unsigned Windows amd64 production build for in-place updates on this machine only.

相对公开正式版 `v2.1.0`，本次用户可见改动集中在「关闭弹窗时闪一下就消失」；同时包含本地 `beta.1`–`beta.4` 的更新完成提示与发布说明排版改动，取代这四个本地版本。

## 新特性 / Features

- **全部弹窗与浮层都有进出过渡**：设置与关于、账号新增／编辑／删除确认、订阅登录、请求详情、Google 项目、代理设置、路由编辑／删除、服务商优先级编辑、升级浮窗与更新完成浮窗，以及账号设置、MiMo 访问详情、模型预览、订阅模型、重置卡浮层——出现时淡入并轻微放大，关闭时淡出并轻微缩小（150ms），不再闪一下消失。
  - **Consistent dialog transitions**: every modal, confirmation and popover fades and scales in and out over 150ms instead of vanishing instantly.
- **全局提示也有退出过渡**：自动消失的成功／警告提示改为淡出并下滑，而不是突然不见。
  - **Toast exit**: auto-dismissed status toasts fade and slide out.
- **重新打开仍是干净表单**：内容常驻以保留关闭动画后，重新打开会换一个新实例，上次的草稿和临时状态不会残留。
  - **Fresh forms on reopen**: dialogs stay mounted for the exit animation but get a new instance each time they reopen.
- **更新完成浮窗**：安装结束并以新版本重新打开后自动弹出一次，说明「升级前版本 → 当前版本」并列出本版新增内容。
  - **Update-complete dialog**: shown once after the installer finishes and the app reopens.

## 修复 / Fixes

- 关闭「设置与关于」等弹窗时不再瞬间消失（TASK-20261029-006／008 的根因都是条件挂载绕过 Radix 的关闭态）。
- 升级浮窗、设置页说明正文不再显示 `##`、`**`、反引号等原始记号，统一按 Markdown 排版。
- 升级浮窗改为「固定标题栏 + 可滚动正文 + 固定操作区」。

## 安全边界 / Safety boundary

- 说明正文中的 HTML 标签只作为文本显示，不执行脚本，也不加载远端图片（仅保留替代文字）。
- 只有 `http(s)` 链接与以 `/` 开头的站内路径生成可点击入口，并带 `rel="noreferrer"`；其余协议保持纯文本。
- 「更新完成」提示的版本来源与回执全部来自本地记录，不接受前端传入的版本、路径或 URL。
- 弹窗常驻只影响渲染时机：未打开的弹窗不会读取设置、订阅会话或请求详情。

## 升级说明 / Upgrade notes

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- Windows 数字版本为 `2.1.1.0`；完整版本递增至 `2.1.1-beta.5`，高于公开的 `2.1.0` 与本地 `beta.1`–`beta.4`。
- 安装身份、安装目录与数据目录沿用既有设置；无新增数据库迁移、无新增依赖。
- 不修改已有账号、路由、用量留存或本地客户端配置；建议更新前正常退出应用并保留数据备份。

## 已知边界 / Known limits

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 本次为本地构建，不会出现在远端自动更新渠道。
- 过渡已在生产 CSS 与隔离 Chromium 上核对，原生 WebView2 窗口与 140% 字号观感需在本地更新后确认。
- 系统开启「减少动画」时所有过渡直接跳过，只保留状态变化。
