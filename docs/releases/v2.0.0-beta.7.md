# OmniProxy v2.0.0-beta.7（本地测试版）

本版修复存在 Google 订阅账号时无法开始 ChatGPT 登录的问题，保留 Beta.6 的 5h／周额度轮换、Desktop 大首事件兼容和安全诊断。仅在本机生成安装包，不发布 GitHub。

## 登录修复

- 修复 ChatGPT 登录前清理逻辑把其他提供商的 subscription_login 账号误当作 Codex 账号读取，进而在授权开始前返回 account_unavailable 的问题。
- 清理前明确核对提供商类型，Google／Antigravity 等账号的凭据不会由 Codex 模块读取、退出或删除；既有 ChatGPT 登录和待保留引用继续受保护。
- 补充前端稳定错误映射，区分账号读取、组件／目录初始化、官方组件请求／协议等失败，不再全部显示“检查网络和登录组件”。

## 日志修复

- 修复 Windows GUI 进程没有有效 stderr 时，控制台写入失败导致后续文件／界面日志一并丢失的问题。
- 登录开始前的失败也记录固定操作阶段和错误码，不输出原始错误、账号身份、授权 URL、用户码或凭据。

## 验证与使用

混合提供商的浏览器／设备码授权、既有登录保留、自身不可读引用保护、错误提示和日志出口故障均有回归验证。官方 Codex 组件已在独立目录完成初始化探测，没有发起真实网页登录或修改现有授权。

沿用现有覆盖安装和数据保留流程，无数据库迁移或新依赖。用户更新后可重新打开“登录 ChatGPT”并开始授权；真实官方网页上的账号选择及授权仍由用户完成。本轮不自动安装或重启生产。
