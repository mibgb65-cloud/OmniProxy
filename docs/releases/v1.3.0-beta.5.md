# v1.3.0-beta.5 - Consolidated Codex activation control / 集中 Codex 激活入口

This beta consolidates the Codex quota activation control in the OpenAI provider header so account cards remain compact while preserving the existing per-account activation checks.

本次 Beta 将 Codex 额度激活入口集中到 OpenAI 厂商标题栏，减少账号卡片中的重复操作，同时保留原有的逐账号检测与激活逻辑。

## Improvement / 改进

- Moved `检测并激活` from every Codex account card to a single action on the right side of the OpenAI provider summary.
  - 将每张 Codex 账号卡片里的「检测并激活」移动到 OpenAI 厂商摘要右侧，仅保留一个入口。
- The consolidated action processes the currently displayed enabled Codex accounts sequentially and summarizes the result.
  - 集中入口会串行处理当前显示且已启用的 Codex 账号，并汇总检测与激活结果。
- Kept the existing backend activation decision, minimal request, quota recheck, and request-history recording unchanged.
  - 后端的激活判定、最小请求、额度复查和请求历史记录逻辑均保持不变。
- Kept the action accessible and responsive with loading, disabled, tooltip, and narrow-window states.
  - 保留加载、禁用、提示和窄窗口布局状态，确保操作可达且不会挤压标题内容。

## Upgrade Guidance / 升级说明

- Use the single `检测并激活` action in the OpenAI summary to check all currently displayed Codex accounts.
  - 请在 OpenAI 摘要区使用统一的「检测并激活」入口检查当前显示的 Codex 账号。
- Existing accounts, quota data, and the automatic activation setting are preserved.
  - 现有账号、额度数据和自动激活设置均会保留。
- No account-pool or local-data migration is required.
  - 无需迁移账号池或本地数据。
