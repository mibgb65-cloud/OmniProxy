# v1.2.6-beta.2 - Codex login and shared history / Codex 登录与共享历史

This beta keeps official Codex and OmniProxy gateway conversations in the same Codex history while making browser login easier to control and inspect.

本次 beta 让官方 Codex 与 OmniProxy 网关继续使用同一份 Codex 对话记录，并改进浏览器登录流程的可控性和可见性。

## Features / 新特性

- **Codex login dialog**: Clicking `登录 Codex` now opens an in-app dialog with the OAuth status and authorization link. The link can be copied or opened explicitly; it is no longer opened automatically.
  - **Codex 登录弹窗**：点击 `登录 Codex` 后显示应用内弹窗，展示 OAuth 状态和授权链接。链接可复制或手动打开，不再默认自动启动浏览器。
- **CPA-compatible import**: Completed browser login is stored using the flat Codex JSON fields expected by CLIProxyAPI, including access, identity, refresh, and expiry metadata.
  - **CPA 兼容导入**：浏览器授权完成后，使用 CLIProxyAPI 兼容的 Codex 顶层 JSON 字段导入访问令牌、身份、刷新令牌和过期信息。

## Bug Fixes / 问题修复

- **Shared Codex conversation history**: Gateway model profiles now use Codex's built-in `openai` provider and `openai_base_url`, avoiding a separate custom provider history namespace.
  - **Codex 对话记录合并**：网关模型配置改用 Codex 内置的 `openai` provider 和 `openai_base_url`，避免自定义 provider 造成对话记录分区。

## Breaking Changes / 不兼容更新

- None / 无

## Refactor & Performance / 重构与优化

- **Accessible login feedback**: The login dialog includes explicit progress, success, and error states, copy feedback, responsive layout, dark-theme support, and reduced-motion handling.
  - **可访问登录反馈**：登录弹窗提供明确的进行中、成功和错误状态，以及复制反馈、响应式布局、深色主题和减少动画适配。
