# OmniProxy v2.0.1-beta.2

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 修复：重置卡面板不再恒显示「官方暂未返回重置卡信息」

订阅额度显示改走官方 HTTP 额度接口（`/backend-api/wham/usage`）之后，重置卡汇总没有任何代码
再读取，导致重置卡图标没有角标、面板里的「当前可用重置卡」恒为 `—`，只能用「使用下一张可用卡」
之外的方式走不通。本版：

- 界面额度读取在同一次查询里**并行**请求官方重置卡汇总接口
  （`/backend-api/wham/rate-limit-reset-credits`，同一 `Bearer` + `ChatGPT-Account-Id`），
  数量以官方 `availableCount` 为准，明细来自 `credits` 列表。
- `credits: null` 只表示「官方只给了数量」，此时面板仍可让官方选择下一张可用卡；
  空数组表示详情已查询但没有可用条目。官方未返回获得时间时该项显示 `—`，不伪造时间。
- 重置卡接口未授权、限流、超时或响应形状不符时，**只让重置卡信息保持未知**（继续显示
  「官方暂未返回重置卡信息」），不影响 5h／一周额度窗口，也不会被当成 0 张。
- 网关调度、自动激活与后台额度观察不额外请求该接口；兑换链路（官方 stdio + 幂等记录）未改。

## 界面：请求页不再撑破窗口

- 请求页固定在可视区域内：标题、搜索／筛选、分页栏各占一行，只有表格内容区内部滚动，
  不再需要滚动整页；表格纵向滚动时表头吸顶。
- 请求列表底部的横向滚动条由 WebView2 原生样式（整幅浅灰轨道 + 两端箭头）换成与产品其它
  滚动区一致的 4px 圆角半透明滑块，深浅主题都可辨认；滚动位置、拖动、列宽与分页行为不变。

## 其他

- 文档与任务记录归档；产品行为无其它变化。

## 升级说明

- 覆盖安装即可，无新增数据库迁移、无新增依赖。
- 数字版本仍是 `2.0.1.0`（同一 patch 的 beta 递增不改数字版本），安装身份、安装目录与数据目录
  沿用原设置；路由、别名、账号、客户端配置、用量、额度留存快照与重置操作记录保持不变。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 官方重置卡汇总接口的字段按 v1 与同类实现的实测形状宽松解析，本版**尚未在真实账号上刷新验收**；
  若某账号确实没有重置卡权益，面板会按官方返回显示 0 或未知，不会回退到旧数据。
- 请求页滚动条与内部滚动只在生产构建 + 无头浏览器复现核对过，原生窗口视觉仍需安装后确认。
