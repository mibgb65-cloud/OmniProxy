# OmniProxy v2.3.1-beta.24

## Bug Fixes / 问题修复

- Google / Antigravity plan badges now tell the two Ultra tiers apart. `g1-ultra-tier` reads **Ultra 20x** (solid rose) and `g1-ultra-lite-tier` reads **Ultra 5x** (rose outline); the 5x tier previously fell through to the raw backend id. Google returns the same `paidTier.name` (“Google AI Ultra”) for both, so only the tier id can distinguish them. / Antigravity 的套餐徽章现在能区分两个 Ultra 档位：`g1-ultra-tier` 显示 **Ultra 20x**（rose 实底），`g1-ultra-lite-tier` 显示 **Ultra 5x**（rose 描边）；5x 档此前没有对照项，会直接显示后端原始标识。官方对两档返回的 `paidTier.name` 都是「Google AI Ultra」，只能按档位 id 区分。

## Breaking Changes / 不兼容变更

None / 无。No database migration, no API change, no stored-data change; only the badge's display text and colour for the two Ultra tiers. / 无数据库迁移、无 API 变更、无存量数据变化；只改两个 Ultra 档位的徽章文案与配色。

## Local update / 本地更新

- Local Windows amd64 Beta installer, not a public release and not signed. Fully exit OmniProxy from the system tray, back up the data directory, then run the installer over the existing installation. / 本版本为本地 Windows amd64 Beta 生产安装包，未公开发布、未签名。请先从托盘完全退出 OmniProxy，备份数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.3.1-beta.24`; Windows numeric resources: `2.3.1.0`; NSIS installer base version: `2.3.1`. / 应用／前端版本为 `2.3.1-beta.24`，Windows 数字资源版本为 `2.3.1.0`，NSIS 安装器基础版本为 `2.3.1`。
- After upgrading, open the Google / Antigravity account page: the 5x account now shows `Ultra 5x` and the 20x account shows `Ultra 20x`. / 升级后打开 Google／Antigravity 账号页：5x 账号显示 `Ultra 5x`，20x 账号显示 `Ultra 20x`。

## Verification boundary / 验证边界

- `task verify` passed before packaging: format, lint (`go vet`／`staticcheck`／ESLint), `tsc --noEmit`, all Go packages, frontend tests and the Windows production build. / 打包前 `task verify` 通过：格式、lint（`go vet`／`staticcheck`／ESLint）、`tsc --noEmit`、Go 全包、前端测试与 Windows 生产构建。
- Covered by tests: both Ultra ids map to distinct names, the 5x badge uses an outline instead of the 20x fill, unknown ids stay verbatim, and missing plans still read “无套餐”. / 测试覆盖：两个 Ultra 标识映射为不同名称、5x 使用描边而非 20x 的实底、未知标识保留原文、缺失套餐仍显示「无套餐」。
- **Not verified visually in this version**: colours are asserted by unit tests against class names, not by a screenshot on a real account page. / **本版本未做界面截图核对**：配色由单元测试按类名校验，未在真实账号页截图确认。
- This release does not change OpenAI model sync. GPT-6.2 availability in the catalog depends on the installed Codex CLI being new enough (0.169.1 or later); the user upgraded it separately. / 本版本未改动 OpenAI 模型同步；目录里能否出现 GPT-6.2 取决于本机 Codex CLI 版本是否足够新（0.169.1 及以上），用户已自行升级。
