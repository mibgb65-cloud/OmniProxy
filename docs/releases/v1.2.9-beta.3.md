# v1.2.9-beta.3 - Codex live WebSocket compatibility / Codex Live WebSocket 兼容性

This beta fixes `404 Not Found` responses from `/codex/v1/live` when recent Codex clients connect through the OmniProxy gateway.

本次 beta 修复新版 Codex 客户端通过 OmniProxy 网关连接 `/codex/v1/live` 时返回 `404 Not Found` 的问题。

## Bug Fixes / 问题修复

- **Codex live requests now use WebSocket forwarding**: `/codex/v1/live` Upgrade requests enter the existing bidirectional WebSocket proxy instead of being forwarded as ordinary HTTP GET requests.
  - **Codex live 请求现在使用 WebSocket 转发**：`/codex/v1/live` 的 Upgrade 请求会进入现有双向 WebSocket 代理，不再被当作普通 HTTP GET 转发。
- **Account-pool authentication is preserved**: Live connections use the account selected by OmniProxy and forward the matching Bearer token and `ChatGPT-Account-Id` to the Codex upstream.
  - **保留账号池鉴权**：Live 连接使用 OmniProxy 调度选中的账号，并向 Codex 上游写入对应的 Bearer Token 与 `ChatGPT-Account-Id`。
- **Existing Responses WebSocket behavior is unchanged**: `/responses` WebSocket connections continue to use the same routing, retry, usage, and shutdown handling.
  - **现有 Responses WebSocket 行为不变**：`/responses` WebSocket 连接继续沿用原有路由、重试、用量记录和关闭处理。
- **Regression coverage**: Added an end-to-end test covering the live WebSocket handshake, upstream path rewrite, authentication headers, and bidirectional messages.
  - **回归测试覆盖**：新增端到端测试，覆盖 Live WebSocket 握手、上游路径改写、鉴权请求头和双向消息。

## Upgrade Guidance / 升级说明

- Restart OmniProxy after installing this beta, then restart Codex CLI, the IDE extension, or the desktop client.
  - 安装本 beta 后请重启 OmniProxy，并重新启动 Codex CLI、IDE 扩展或桌面客户端。
- No account-pool, client-configuration, or local-data migration is required.
  - 无需迁移账号池、客户端配置或本地数据。
