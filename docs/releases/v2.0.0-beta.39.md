# OmniProxy v2.0.0-beta.39

本地预发布版本（Windows amd64）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 修复

- **WebSocket 请求在列表里退回「Codex CLI / Desktop」**。Beta.38 给透明入口的 WebSocket 补上
  逐轮记账时，直接使用了入口前缀的归属值（`codex`），而协议入口的 WebSocket 也从来没做过细化；
  结果是这些请求无法再区分 CLI 与桌面端。
  - 现在两条 WebSocket 路径在创建请求时都用与 HTTP 入口相同的判定
    （客户端自报的 `originator`／`User-Agent`）：`codex-cli`／`codex-desktop`／`codex-vscode`。
  - 未知来源仍记作笼统的 `codex`，不猜测运行形态。
  - 帧级授权复核继续使用前缀／接入 Key 的原始值，不受显示归属影响。
- 历史记录不回溯改写：升级前写入的 `codex` 归属保持原样。

## 升级说明

- 覆盖安装即可，无新增数据库迁移。
- 已有的路由、别名、账号与客户端配置保持不变。

## 已知边界

- 安装器未签名，Windows SmartScreen 可能提示未知发布者。
- 只有客户端自己声明来源标识时才能细化；既不声明 `originator` 也不在 `User-Agent` 里带标记的
  客户端仍显示为「Codex CLI / Desktop」。
- 实机 WebSocket 会话的运行形态显示由用户在本机验收。
