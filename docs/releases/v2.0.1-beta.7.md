# OmniProxy v2.0.1-beta.7

本地预发布版本（Windows amd64，production 构建）。未签名、未公开推送，安装包仅供本机覆盖更新。

## 修复：账号页提供商切换区越界与遮挡

相对本地 `v2.0.1-beta.6`，本次新增以下修复：

- 提供商切换区横向滚动后，再切换账号详情时，动画图标不会再侵入左侧操作栏或标题栏。
- 账号详情的动画副本不再盖过底部切换区，避免账号文字与提供商图标重叠。
- 底部切换区使用不透明主题底色，不再透出下方的账号卡片内容。
- 保留现有 600ms 原位切换动画、横向滚动、键盘导航及减少动画偏好。
- 深浅主题、窄窗、侧栏收起、快速连点和长列表滚动已做隔离浏览器回归验证。

对应修复为 TASK-20261028-010，代码提交 `970990e0`。沿用 Beta.6 的网关端口配置与冲突自动避让功能。

## 升级说明

- 运行本次安装器覆盖更新；本次构建不会自动安装或停止当前运行中的应用。
- Windows 数字版本仍为 `2.0.1.0`；Beta 完整版本递增至 `2.0.1-beta.7`。
- 安装身份、安装目录与数据目录沿用既有设置；无新增数据库迁移、无新增依赖。
- 不修改已有账号、路由、用量留存或本地客户端配置。建议更新前正常退出应用并保留数据备份。
