# OmniProxy v2.0.0-beta.5

本版汇总原生 OpenAI 图片输入和 Codex 额度窗口自动激活两项修复，包含 Beta.4 的订阅流式转发兼容修复。

## 图片输入

- 修复原生 OpenAI 模型目录把已确认的图片输入能力降为仅文本的问题。只有官方上游明确声明图片能力的模型及其原生别名才发布图片能力，不扩大跨协议多模态范围。
- Responses HTTP／WebSocket 使用独立 16 MiB 请求上限，支持超过原先 2 MiB 限制的 Base64 图片请求；WebSocket 合并历史及路由改写后继续检查最终容量，其他协议上限不变。
- 已通过真实 `gpt-6.1-sol` HTTP／WebSocket、Codex CLI 0.163.0 与 Desktop 内核 0.163.0-alpha.10.2 共四次图片识别验收。Desktop 内核成功不等同于 Desktop 外壳 GUI 全流程验收，也不保证所有账号与模型权限。

**升级后需要重新应用 Codex 模型配置并重新加载客户端／新建会话。** 如果共享配置被外部修改，仍须通过 OmniProxy 界面重新读取、预览并确认应用；不会静默覆盖外部配置或登录。

## 自动激活 Codex 额度窗口

- 修复“剩余额度 100%、约 5 小时／5 小时 1 分钟后重置”的未开始窗口漏判。判断依据是独立额度查询中重置目标是否随时间滑动，不是界面倒计时字符串；首次观测不会被误报为已激活。
- 增加观测与确认计时的持久状态。只有符合安全条件、已登记允许发送的原账号窗口才会使用原有最小消息流程；固定目标、耗尽额度、陈旧／异常时间、并发／重启和结果未知仍保持保守处理，避免重复发送。
- 界面区分“窗口已开始计时”和发送结果；收到请求回执不直接等于窗口已激活。
- 升级自动执行数据库迁移 034，保留已有周期和尝试记录，不清空历史、不重置发送资格。请先备份数据；迁移后不建议直接降级使用旧程序写入同一数据库。

此功能默认关闭，需在 OpenAI 设置中开启。已完成时序回归、匿名行为重放、模拟传输闭环及迁移保留验证；发布前未对真实账号发送激活消息，实际自动激活效果仍需升级运行后核验。不会为验收而擅自消耗真实账号额度。

Windows amd64 测试版。沿用既有覆盖安装、应用内下载／校验／重启静默更新和卸载保留数据的流程。发布不会自动安装或重启本机软件、当前 Agent，也不会更改共享客户端配置。Beta 渠道可发现本版，稳定版 Latest 和旧 Beta 标签／资产保持不变。

请同时下载安装器及同名 `.sha256` 校验文件。安装包尚未代码签名。升级与历史数据兼容边界见 [升级说明](https://github.com/mibgb65-cloud/OmniProxy/blob/main/docs/product/UPGRADE.md)。
