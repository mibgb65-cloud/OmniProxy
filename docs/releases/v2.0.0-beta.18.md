# OmniProxy v2.0.0-beta.18

本版为汇总 main 当前功能的 Windows amd64 production 本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

## Codex 中转内存优化

- 修复每次中转准备令牌都重复解密官方 Codex 授权文件，导致 GiB 级临时分配及内存留存的问题。
- 增加 Windows DPAPI 保护的进程内缓存，最多 16 条、固定 5 分钟有效；每次仍核对完整官方密文和当前系统凭据，内容变化、过期、淘汰或退出登录后失效。
- 实际高成本解密串行执行，完成后归还大块临时工作区；不降低官方加密强度，不把 Token 明文写入文件、数据库、日志或 UI，也不绕过官方刷新和账号身份／版本检查。
- 相同官方工作因子的假数据专项中，缓存命中单次 Go 分配约 10.6 KiB，不再重复分配约 1 GiB。独立测试进程读取完成后的私有提交约 50 MiB，不代表完整桌面应用的内存保证。
- 首次读取、官方授权更新或缓存到期时，仍可能短暂需要约 1 GiB；本版减少重复计算和长期留存，不承诺完全消除算法必需峰值或官方外部进程的开销。

## 独立周额度估算与卡片精简

- 周美元参考估算使用完整的一周窗口，不再受旧 5h 周期或历史周裁剪基线影响；5h 与周窗口分别按自身边界计算。
- 美元估算卡片精简为“总额／剩余”两列，Token 区域保留输入／输出／缓存三列，移除指定的额度与本机留存提示。
- 估算仍基于本机保留的实际用量和基础参考价，不是官方美元余额；未知用量、价格和无效窗口不猜测，也不补造其他客户端消费。

## 继承功能与验证边界

- 包含 main 上此前已完成的功能，继承 Beta.17 的 Gemini 完整工具 JSON Schema 兼容修复及既有长会话、额度留存、路由和客户端接入能力。
- 不新增数据库迁移，不改变安装身份或已有凭据格式，不主动修改客户端登录、路由选择或账号启用状态。
- Google 上游的 `429 / RESOURCE_EXHAUSTED` 仍是独立调查项；本版不宣称解除限流或完成真实 Gemini Desktop 会话验收。后台调查文档或历史规划草稿不作为已完成功能承诺。
- 构建与专项验证使用隔离环境和假数据，不发送真实推理；本地覆盖更新后的完整应用内存走势和真实模型调用由用户验收。

## 安装与数据保留

更新前建议保留包含 SQLite WAL 的一致性数据备份。从托盘完全退出旧版后，运行本安装包覆盖更新，安装后在“设置与关于”确认版本为 2.0.0-beta.18。

本版沿用现有安装目录、账号、数据库、设置、请求历史与累计统计，不主动清空数据，不自动重启 Claude／Codex Desktop；不要同时启动新旧版本写入同一数据目录。

本地安装包未签名，Windows 可能提示未知发布者，机器级安装需要管理员确认。构建过程不自动安装、停止或替换生产应用，不上传公开发布；真实覆盖安装与数据保留由用户本地验收。
