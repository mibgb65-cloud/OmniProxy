# OmniProxy v2.2.3-beta.3

## Features / 新功能

- OpenAI pay-as-you-go API Key accounts can now be used as forwarding accounts. Add the key under Accounts → OpenAI, sync the account's `/v1/models` catalog in Routing, and Codex can consume that account through the local gateway.
  - OpenAI 按量 API Key 账号现在可以作为转发账号使用。在「账号 → OpenAI」添加 Key，在「路由」页同步该账号的 `/v1/models` 目录后，Codex 即可通过本地网关消耗该账号额度。
- Codex keeps its existing built-in `openai` identity, ChatGPT login, sessions and one-click configuration. The gateway selects the upstream per account: subscription accounts keep the ChatGPT Codex endpoint, while API Key accounts use `api.openai.com/v1` with `Authorization: Bearer` and no `ChatGPT-Account-ID`.
  - Codex 保持原有内置 `openai` 身份、ChatGPT 登录、会话与一键配置不变。网关按账号选择上游：订阅账号继续使用 ChatGPT Codex 端点；API Key 账号使用 `api.openai.com/v1`，仅发送 Bearer 认证，不发送 `ChatGPT-Account-ID`。
- Subscription and pay-as-you-go accounts remain separate billing pools. Same-pool failover never crosses authentication or billing methods, and fixed accounts keep priority.
  - 订阅账号与按量账号保持独立计费池；同池故障切换不会跨认证或计费方式，固定账号仍优先。
- OpenAI API Key models are discovered from the official model list; non-chat families such as embeddings, image, audio and transcription models are excluded. Unknown context or modality metadata stays unknown.
  - OpenAI API Key 模型通过官方模型列表发现；embedding、图片、音频、转写等非对话型号不写入目录。未公布的上下文或模态元数据保持未知。
- `/responses/compact` and Responses WebSocket transparently follow the selected API Key account; quota-exhausted responses (`insufficient_quota`) are classified as a controlled quota rejection.
  - `/responses/compact` 与 Responses WebSocket 按选中的 API Key 账号透明转发；额度耗尽响应（`insufficient_quota`）按受控额度拒绝分类。

  - 新增有界的 OpenAI 原生 Responses 适配器与模型发现客户端，不新增第三方依赖；订阅额度观察显式跳过 API Key 账号。

## Upgrade notes / 升级说明

- This is a local Windows amd64 Beta production installer for manual in-place updates, not a public release. Fully quit OmniProxy from the system tray and back up the current data directory before running the installer over the existing installation.
  - 本版本为供手动覆盖更新的本地 Windows amd64 Beta 生产安装包，未公开发布。更新前请从托盘完全退出 OmniProxy，并备份当前数据目录，再运行安装器覆盖现有安装。
- Application/frontend version: `2.2.3-beta.3`; Windows numeric resources: `2.2.3.0`; NSIS installer base version: `2.2.3`.
  - 应用／前端版本为 `2.2.3-beta.3`，Windows 数字资源版本为 `2.2.3.0`，NSIS 安装器基础版本为 `2.2.3`。
- Existing accounts, data-location settings and update preferences remain unchanged. This update adds no database migration.
  - 既有账号、数据位置与更新偏好保持不变，本次更新不增加数据库迁移。
- After updating, add the OpenAI API Key account and sync its models once, then reload Codex. If a subscription account also exposes the same model, temporarily disable it or pin the API Key account in a routing rule while testing.
  - 更新后添加 OpenAI API Key 账号并同步一次模型，再重新加载 Codex。若订阅账号也提供同名模型，测试时可暂时停用订阅账号，或在路由规则中固定到 API Key 账号。
- The official API still does not expose a remaining prepaid credit endpoint; the UI continues to show local usage only and does not claim an official balance.
  - 官方仍未提供查询剩余预付额度的接口；界面继续只显示本机用量，不冒充官方余额。
