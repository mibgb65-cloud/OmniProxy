# OmniProxy v2.4.1-beta.5

## Fixes / 修复

- **A remote proxy configured as HTTP no longer hangs every request.** A proxy port can accept TCP and speak only SOCKS5: it answers no HTTP `CONNECT` and never closes the connection, so a provider request configured as `http` waited until the caller's deadline (a minute or more) without any proxy error code. The outbound transport now confirms an explicitly selected scheme with one bounded handshake before the first use; if that scheme is not answered but the other one is, it switches to the working protocol, persists the result and stops re-probing. / 「远端代理填成 HTTP 后请求不再挂起。」代理端口可能只接受 TCP 且只会说 SOCKS5：它既不回应 HTTP `CONNECT`，也不关闭连接，于是配置成 `http` 的提供商请求一直等到调用方超时（一分钟以上），而且拿不到任何代理错误码。出站传输现在会在首次使用前用一次有界握手确认显式选择的协议；该协议不应答而另一种协议成立时，自动切到可用的协议、持久化识别结果，之后不再重复探测。
- The per-protocol handshake budget was raised from 2 to 4 seconds. Remote proxies with username/password authentication spend 1.9–2.6 seconds on the SOCKS5 greeting plus auth exchange, which the old budget reported as “protocol mismatch”. / 单协议握手预算由 2 秒提高到 4 秒：带用户名密码认证的远端代理在 SOCKS5 greeting 加认证交换上要花 1.9–2.6 秒，旧预算会把它判成「协议不匹配」。
- Changing the proxy scheme now clears the stored detection result, so a previous automatic detection can no longer override a new explicit choice. / 修改代理协议时会清除已保存的识别结果，历史识别不再压过新的显式选择。

## Notes / 说明

- The confirmation happens once per configuration version: after a successful switch the scheme is stored in `proxy_settings.detected_scheme`, and later requests reuse the in-memory or persisted result. Local mixed ports only pay one extra handshake round trip (milliseconds). / 确认只在每个配置版本发生一次：切换成功后协议写入 `proxy_settings.detected_scheme`，后续请求复用内存或持久化结果。本地 mixed 端口只多一次握手往返（毫秒级）。
- When neither protocol answers, the user's configuration is kept and the real request exposes the problem — the fix does not turn a transient stall into a hard error. / 两种协议都不应答时保留用户配置，由真实请求暴露问题：本修复不会把瞬时抖动升级成硬错误。
- The “Test” button now allows up to 10 seconds so both protocols get one full handshake. / 「测试」按钮的探测总预算提高到 10 秒，让两种协议各有一次完整握手。
- No database migration and no configuration rewrite: existing proxy settings keep working, and a saved `http` scheme is corrected automatically on the next request. / 无数据库迁移、不改写配置：既有代理设置继续可用，已保存的 `http` 会在下一次请求时自动纠正。
- Also included since beta.4: usage statistics merge reasoning-level variants of the same model (beta.4), and re-authorizing the same Google or ChatGPT account updates the existing account instead of adding a duplicate (beta.3). / 同时包含 beta.4 的内容：用量统计按模型家族合并推理档位变体；以及 beta.3 的内容：重新授权同一 Google／ChatGPT 账号会更新原账号，不再新增重复卡片。
