# OmniProxy v2.0.0-beta.27

本版为 Windows amd64 production 本地 Beta 安装包，供用户手动覆盖更新，未公开发布。

本版相对 Beta.26 只增加请求页的四项指标，网关转发、账号、路由、客户端配置与数据库结构均未改动。

## 请求页：缓存命中、成本、速度、首字

之前要在「请求」页判断一次请求划不划算，只能看输入／输出 Token 和总耗时，剩下的靠猜。本版把四个关键数字直接放进列表和详情：

- **缓存命中**：上游报告的前缀缓存命中量占输入 Token 的比例，例如 `40%`。悬停可以看到「缓存 41,000 / 输入 50,000」的原始数量。输入 Token 本来就包含缓存部分，不会重复计费。
- **成本**：按基础参考价估算的美元金额。缓存明细未知时显示区间（如 `$0.06–$0.15`），因为无法确定缓存折扣是否生效。
- **速度**：`≈75 tok/s`，即输出 Token ÷ 生成耗时。流式请求会扣掉首字等待，只统计模型真正出字的那段时间；因此它比「Token ÷ 总耗时」更接近主观感受。
- **首字耗时**：从请求开始到第一个内容字节的毫秒数，之前只在详情弹窗里有，现在列表也能直接对比。

四个表头都带一个圆形说明按钮，鼠标悬停或键盘聚焦即可看到每个指标的口径。

### 未知就是未知，不补零

这些数字全部来自上游实际报告的 usage。为了防止把「没采集到」显示成「是 0」：

- 上游没有返回缓存明细（含本版之前的历史记录），缓存命中显示 `—`；真实零命中显示 `0%`。
- 成本只在用量完整且该型号有已确认参考价时给值，否则 `—`；从未用模型名前缀去猜价格。
- 进行中的请求、没有输出 Token 的失败请求，速度显示 `—`。

## 关于「成本」的边界

成本是**按公开基础单价估算的参考值，不是账单**，也不代表订阅套餐的实际扣费。缓存命中折扣按已报告的缓存量计算；缓存未知时给出上下界，而不是编造一个单值。人民币计价的通道不会被擅自换算成美元。

## 兼容与已知边界

- 无新迁移。缓存量与首字时间用的是 Beta.26 之前就已保存的列（迁移 032／037），历史记录直接可读，只是当时没采集的字段显示 `—`。
- 本版不改客户端目录、Agent 配置与模型路由，升级后**不需要**重新应用客户端配置。
- 请求列表从此前的 8 列增加到 12 列，窄窗口下依赖横向滚动查看右侧列。
- 速度与成本依赖上游已报告的 usage；部分提供商在失败或截断时不返回 usage，这类请求只显示 `—`。
- 这四项只出现在请求明细里，不进入累计用量、仪表盘聚合或配额估算。
- Codex 在约 500k 用量时提前压缩、Google 上游 `429 / RESOURCE_EXHAUSTED` 两项仍是独立调查项，本版不宣称已修复。
- 构建与回归在本地执行，不以自动化测试替代真实上游调用、真实覆盖安装或客户端界面验收。

## 安装与数据保留

先从托盘完全退出旧版，再为整个数据目录保留一致性备份，随后运行本安装包覆盖原安装目录，无需先卸载旧版或删除账号数据。安装后在“设置与关于”核对版本为 2.0.0-beta.27。

本版沿用现有安装目录、账号、数据库、设置、请求历史与累计统计，不主动清空数据，不自动重启 Claude／Codex Desktop；不要同时启动新旧版本写入同一数据目录。

本地安装包未签名，Windows 可能提示未知发布者，机器级安装需要管理员确认。构建过程不自动安装、停止或替换生产应用，不上传公开发布；真实覆盖安装与数据保留由用户本地验收。

## 校验

- 安装器 `OmniProxy-Setup-v2.0.0-beta.27-windows-amd64.exe` 与同名 `.sha256` 位于 `release-assets/v2.0.0-beta.27/`。
- 完整质量门（格式 → lint → 类型 → Go 全部包 → 前端测试 → Windows production 构建）、Windows 版本资源与发布资产校验均通过。
