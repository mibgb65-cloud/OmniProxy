# v1.2.6-beta.3 - Gemini visual consistency / Gemini 视觉统一

This beta brings the desktop console closer to Gemini's current visual language and aligns pages that previously used different colors, spacing, and surface treatments.

本次 beta 进一步贴近 Gemini 当前的视觉语言，并统一此前在色彩、间距和容器层级上不一致的页面。

## Features / 新特性

- None / 无

## Bug Fixes / 问题修复

- **Page consistency**: Aligned the OpenRouter chat heading, Quickstart client previews, Help workflow cards, and first-run guide with the shared page hierarchy and container geometry.
  - **页面一致性**：统一 OpenRouter 对话页标题、一键配置客户端预览、使用说明流程卡片和首次使用引导的层级与容器形态。

## Breaking Changes / 不兼容更新

- None / 无

## Refactor & Performance / 重构与优化

- **Gemini design system**: Refreshed the shared light and dark theme tokens with Gemini blue, neutral layered surfaces, lower shadows, and matching Element Plus theme values.
  - **Gemini 设计系统**：更新浅色和深色主题令牌，采用 Gemini 蓝、中性分层表面、轻量阴影，并同步 Element Plus 主题值。
- **Typography**: Added Google Sans, Roboto, Noto Sans SC, and Microsoft YaHei UI fallbacks for a more consistent desktop reading experience.
  - **字体体系**：补充 Google Sans、Roboto、Noto Sans SC 和 Microsoft YaHei UI 回退，提升桌面端中英文显示一致性。
