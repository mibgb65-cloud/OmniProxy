# 配额与余额总览

配额页集中展示已添加账号的剩余资源，支持 ChatGPT／Codex 订阅额度、DeepSeek／Kimi API Key 余额、阶跃星辰普通余额与未知的 Step Plan 资源，以及 Gemini 项目声明与本机错误观察。页面默认只做监控和手动查询，账号启停及授权管理仍在账号详情中完成。用户在 OpenAI 账号设置切换自动激活开关后直接保存生效，后台可为未开始的额度窗口发送原账号最小消息并复查，额度变化通过独立事件刷新共享缓存；详见 `SUBSCRIPTION.md`。

## 页面

- 顶部显示支持监控的账号数、已确认额度耗尽／余额不足数、查询异常数及待确认数。没有已确认结果时耗尽数显示“—”；正在读取、缺失数据、需要登录和已过重置时间归为待确认。
- 按具体提供商配置分组，使用最多四列的响应式账号卡片。可搜索账号、邮箱、套餐、公开账号 ID，筛选提供商与资源状态；筛选不改变全局概况。
- 卡片首行显示账号名称与刷新按钮；下一行左侧显示 API Key 类型或订阅套餐，右侧显示资源状态并靠右对齐。
- Codex 展示官方返回的 5h／周窗口、剩余百分比和重置倒计时，复用账号详情窗口组件。按当前实际窗口展示，不换算请求次数或跨账号相加；窗口缺失、异常和过期明确显示。
- DeepSeek 展示 CNY／USD 各自的总余额、赠送／充值余额，保留官方十进制文本。充足状态只使用官方字段，不换汇或合并币种。
- 每个支持查询的账号有刷新入口；“刷新当前列表”只刷新当前筛选中具备查询条件的账号，汇报完成数量与失败数量。未授权及未支持账号没有刷新动作。
- 保留最后成功刷新时间。后台刷新及失败继续显示同一身份的已有快照和安全错误；首次未知不显示零值。达到官方重置时间后标记待刷新，不直接恢复为 100%。
- 账号详情链接进入对应提供商的账号详情页。停用账号仍可只读查询；资源状态不表示模型权限或保证请求成功。

## 查询与缓存

订阅额度及 DeepSeek／阶跃星辰／Kimi 余额复用账号／提供商元数据及现有 `SubscriptionQuota`、`AccountBalance` 绑定。Gemini 使用独立资源／项目绑定接口，不混用订阅身份。额度按账号身份与授权状态隔离，余额按账号及元数据版本隔离；配额页与账号详情共享查询键、60 秒缓存和 10 分钟保留时间。

订阅读取使用前端串行队列，余额最多两个并发，减少批量查询在后端互斥锁和超时上下文中的等待。离开页面取消未开始的请求；已开始的 RPC 等待后端结束后释放名额，避免取消后实际并发超限。查询不自动重试或轮询，30 秒本地计时器仅更新重置倒计时和过期显示。

## 当前边界

订阅额度及已接入余额尚未实现额度历史、低额度提醒、自定义自动刷新频率和自动调度；提醒阈值及刷新策略仍需另行定义。不自动使用重置卡，不读取或显示上游凭据。

## 阶跃星辰资源

普通账号按所选地区查询 `/v1/accounts`，显示账户类型、余额与累计充值／赠送，国内按人民币 CNY／¥ 展示，海外币种保持待确认；不根据负后付费金额猜耗尽状态。订阅账号不查询普通余额，不填零 Credit，不推算重置窗口，提供对应地区的官方平台入口。没有稳定主体 ID 时，不将多个 Key 的余额加总；详情与本页共享版本化缓存及有界查询队列。见 `STEPFUN.md`。

## Kimi 余额

普通 API Key 按已确认的国内／海外平台查询可用、代金券及现金余额，国内 CNY、海外 USD。保持官方金额精度和欠费现金负数，按可用余额大于零判断充足／不足，纳入概况及状态筛选；未确认平台的账号不发起官方请求。复用账号详情的 `AccountBalance` 与版本化缓存、余额并发队列，仪表盘主动检查同样可查询。不同 Key 可能共享平台账户余额，不做加总；Kimi Code 订阅额度尚未接入。见 `KIMI.md`。

## Gemini 项目资源

Google API Key 账号详情及配额页提供项目资源卡片。用户可以声明 6–30 位的 Cloud 项目 ID、解除绑定；此声明未通过 Cloud 身份验证。同项目多个 Key 合并为一个资源组，未绑定时明确项目范围未知，不推断独立额度池。

本机记录只保存经过校验的 401／403／402／429 分类、模型、Google 指标／上限、观察及建议重试时间，不保存上游正文。仅明确的每日指标识别为每日配额耗尽，按 `America/Los_Angeles` 零点计算下一日，包含夏令时；普通 429 不猜成每日耗尽。记录超过 24 小时或经过重试时间后标为过期，不宣称恢复额度。更换 Key 隔离旧绑定、目录和观察，在途请求的账号版本变化时也拒绝写入旧结果。

资源读取每 30 秒刷新本机快照，也有手动入口，不产生上游查询或推理。官方余额／剩余额度保持未知；本机 token 用量复用既有用量页。官方用量／限流和账单按钮仅打开固定 AI Studio 页面；没有自动充值或额度调度。Cloud OAuth／Service Usage／Monitoring、账单账号绑定、历史及完整 Agent 桥接保留为后续阶段。

规则依据：[官方限流说明](https://ai.google.dev/gemini-api/docs/rate-limits)、[官方计费说明](https://ai.google.dev/gemini-api/docs/billing)。
