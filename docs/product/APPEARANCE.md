# 外观与文字大小

窗口采用一体式通顶侧边栏：左侧边栏占满窗口高度，顶部品牌栏（44px，与右侧标题栏同高）内依次为主图标、`OmniProxy` 名称和收展按钮；标题栏只覆盖内容区，不再重复图标或名称。全窗口只有这一处品牌标识。侧栏收起后品牌栏整行即展开按钮，默认显示主图标，鼠标悬停或键盘聚焦时换成展开图标并带「展开」提示。窗口拖动区仍为标题栏空白部分，双击该区域最大化／还原。侧栏底部只保留“设置与关于”。

左侧导航的选中状态是一块独立的滑动背景块（药丸）：点击切换菜单项时，圆角背景不再就地消失和出现，而是以 450ms、`cubic-bezier(0.22, 1, 0.36, 1)` 的阻尼缓动纵向滑动到新选中的按钮，相邻切换与「仪表盘」→「日志」这类跨项点击同样平滑；背景块位于图标与文字之下且不拦截点击，未选中项悬停只提亮文字与图标。位置与高度取自选中项的真实布局，因此首次挂载、侧栏收展与全局字号变化后都会重新测量，不会出现从顶部滑下来的误触发动画；系统要求减少动画时直接到位。路由切换沿用各链接自身的选中判定，不需要维护额外的选中状态。

标题栏右侧在亮暗模式按钮左侧仅显示语言图标按钮，保留可访问名称；点击后弹出中文／English 单选菜单，当前语言显示勾选标记。选择即时生效并自动保存，菜单自动关闭；支持键盘操作、Escape／点击外部关闭和焦点恢复。语言入口不受侧栏展开／收起影响。

标题栏的亮暗模式按钮以点击位置为圆心向四周圆形扩散切换主题：新主题从点击处展开约 700ms（`cubic-bezier(0.4, 0, 0.2, 1)`）后铺满窗口，旧主题不做淡出。键盘激活时圆心取按钮中心；窗口尺寸变化时半径始终按「点击点到最远角」计算，圆形一定能覆盖整屏。运行时缺少 View Transitions API 或系统要求减少动画时，主题在同一帧内直接切换，界面与状态结果一致。

设置页面的“外观”提供全局文字大小滑块：80%–140%、每步 5%、默认 100%。拖动或使用键盘立即应用并自动保存，可点击“恢复默认”回到 100%。

- 导航、卡片、列表、弹窗、提示及金额说明／时间小字统一按比例调整。
- 设置仅存本机 UI 偏好，不涉及账号、凭据或服务端配置。
- 首帧加载前恢复已保存值，避免启动时字号闪动；异常范围、非数字、非法步进或被破坏的偏好回退默认，不能覆盖状态操作函数。
- 遵循系统减少动画偏好；余额刷新期间图标旋转，完成／失败后恢复，重复点击在查询时禁用。

实现复用 Zustand 持久化和 Radix Slider，根字号驱动 rem 布局与文字，同时将现有 9／10／11px 小字规则统一为对应 rem，无新增依赖。

主内容区按页面地址独立记忆滚动位置：首次访问从顶部开始，切换回来恢复该页之前的位置，前进／后退也遵循相同规则。不同提供商账号详情分别记录，同页查询／筛选不创建新记录。位置在当前窗口会话中保留，关闭／重新加载窗口后重置。异步内容加载期间等待高度满足后恢复；用户主动滚动或操作会取消等待。侧栏和卡片内滚动保持独立，网关页签切换仍回到顶部。
