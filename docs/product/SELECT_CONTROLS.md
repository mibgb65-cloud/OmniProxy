# 全局下拉选框

软件中 9 处可见下拉统一使用 `components/ui/SelectField`，包括请求结果、日志模块、路由状态／编辑器提供商／模型／账号、模型同步账号、Agent 模型及网关测试模型。

触发器和菜单沿用应用主题，提供圆角、阴影、背景模糊、悬停高亮、选中勾选与焦点边框。菜单通过 Portal 显示，避免被卡片和弹窗裁剪；自动避让窗口边缘，长列表可滚动，遵循全局字号和减少动画偏好。

键盘支持 Enter／Space 打开、方向键选择、输入文字定位、Enter 确认、Escape 关闭及恢复焦点。不可用项目保持禁用，已删除账号或未知模型保留诊断选项。

业务使用受控字符串值、选项列表和 onValueChange，支持空值；组件内部编码不会与实际模型／账号值冲突。表单通过 React Hook Form Controller 接入，保留值、校验、引用和级联重置。Radix 的隐藏表单控件只用于表单语义，不产生可见的系统菜单。选项初始化的无效空事件不会重置已选择模型。

不增加依赖，使用现有 radix-ui 与 Tailwind。前端测试操作可见菜单选项，jsdom 缺少的指针／滚动 API 仅在测试环境提供。
