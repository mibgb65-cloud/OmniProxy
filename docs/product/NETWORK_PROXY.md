# 提供商出站代理（Network Proxy）

## 目的

部分海外提供商的接口在本机网络下不可达。用户已经在运行 v2rayN / Clash / mihomo
这类代理客户端，希望 OmniProxy 只把「选定提供商」的出站请求转发到它的本地监听端口。

OmniProxy 只作为客户端连接**已经启动**的代理端口：不启动、不重启、不更新代理软件，
不读取订阅与节点，不解析 vmess/vless/trojan 链接，也不修改系统代理。

## 用户可见行为

- 提供商页右上角「网络代理」按钮打开设置窗口：
  - 代理服务器：启用开关、协议（自动识别 / HTTP / SOCKS5）、地址、端口、可选用户名与密码、
    不走代理的地址列表。
  - 「探测本机代理」：并行检查常见本地端口（10808、10809、7890、7891、7897、1080、2080、1087），
    命中后显示 `127.0.0.1:10808 · SOCKS5` 形式的一键填充。
  - 「测试」：探测该端点支持哪些协议并给出延迟；失败时区分「代理端口无响应」与
    「端口不是 HTTP/SOCKS 代理」。
  - 使用代理的提供商：每个提供商三态——跟随全局 / 直连 / 走代理，另有「全部走代理」与
    「全部直连」。
- 提供商卡片在走代理时显示「代理」徽标；把鼠标停在上面可看到实际协议。

## mixed 端口与协议识别

v2rayN 默认监听形如 `本地:[mixed:10808]`，同一个端口同时接受 HTTP CONNECT 与 SOCKS5。
Go 的 `http.Transport` 必须二选一，所以：

- `scheme=auto` 表示「由探测决定」。探测只做握手，不产生真实出网流量：
  SOCKS5 greeting（`05 01 00`，必要时补用户名密码子协商）与 HTTP `CONNECT` 状态行。
- 两种协议都通（mixed）时使用 SOCKS5：纯 TCP 隧道对 `ws://` 与 `wss://` 都不依赖代理侧
  的 HTTP 解析。
- 识别结果写入 `proxy_settings.detected_scheme`；端点（主机、端口、用户名）变化后清除。
- 运行期纠偏：连接建立但协议不成立时自动切换另一种协议重试一次（同一端点 60 秒内最多一次），
  成功后回写识别结果。因此用户把 mixed 改成纯 SOCKS 也不需要重新配置。

## 解析顺序

单个请求是否走代理，按以下顺序判定：

1. `no_proxy` 命中或目标是 loopback／`localhost`，且该提供商不是显式「走代理」→ 直连。
2. 提供商 `proxy_mode = direct` → 直连。
3. `proxy_mode = proxy` → 走代理；全局未配置端点时报 `proxy_not_configured`，不静默直连。
4. `proxy_mode = inherit` → 跟随全局「启用代理」。
5. 都不适用 → 进程环境变量 `HTTP(S)_PROXY`（既有行为）→ 直连。

提供商身份优先取请求上下文；没有上下文的调用（额度、余额、授权续期）按目标主机名匹配，
内置提供商使用目录里的默认端点参与匹配。

## 覆盖范围

走同一套策略的出站路径：网关转发（全部提供商适配器）、连通性测试、Codex 透明转发
（HTTP 与 WebSocket）、Codex 额度读取与令牌续期，以及经由适配器实现的余额／额度查询。

应用自身更新与 Agent 安装下载**不走**提供商代理：代理挂掉或限速不应连带更新失败。

## 失败语义

| 情况 | 错误码 | 是否影响账号 |
| --- | --- | --- |
| 代理端口无响应（预连失败，30 秒缓存） | `proxy_unavailable` | 不影响：不换号、不写冷却 |
| 端口通了但两种协议都不成立 | `proxy_protocol_mismatch` | 不影响 |
| 提供商显式走代理但未配置端点 | `proxy_not_configured` | 不影响 |

## 数据与安全

- `proxy_settings` 只保存 scheme／主机／端口／用户名／`no_proxy`／识别结果；
  密码只写 `credential_ref` 指向的 DPAPI 凭据文件，界面只显示是否已保存。
- 日志、错误与 UI 一律使用脱敏端点（`http://127.0.0.1:10809`），不出现用户名密码。

## 不在范围

- 不做 `tun2socks`／系统级代理接管。
- 不支持多个代理出口分组（需要分流时由代理客户端自身配置规则）。
- 不探测非 loopback 网段，也不自动启动代理软件。
