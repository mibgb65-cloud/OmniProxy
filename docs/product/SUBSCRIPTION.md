# ChatGPT 订阅账号

Google AI / Antigravity 使用独立订阅通道与浏览器授权，详见
[Google 订阅说明](GOOGLE_SUBSCRIPTION.md)；不共用本文的 Codex 额度、重置卡或系统登录。

OpenAI 账号支持 API Key 与 ChatGPT / Codex 两种认证方式。订阅授权已用于模型目录同步与 Responses 转发，跨协议支持文本和工具；具体权限仍由官方每次请求决定，见 `LOCAL_AGENTS.md`。

## 使用

登录弹窗使用整块可选的浏览器／设备码授权卡片，并提供各自说明与键盘焦点反馈。顶部显示品牌和用途，底部固定主要操作，内容过高时独立滚动；新增账号可选填名称，重新登录不显示名称输入。等待状态集中显示官方页面入口和设备码，完成／错误使用独立状态面板；关闭保留后台授权，取消才停止。深浅主题及最小窗口沿用同一布局，界面不再显示已过时的“订阅转发待接入”提示。

1. 确认本机官方 `codex --version` 可用。目前已验证版本为 codex-cli 0.155.1。
2. 在“账号 → OpenAI”点击“登录 ChatGPT”。名称选填，留空使用官方账号身份，身份为空时使用 ChatGPT Codex。
3. 选择浏览器授权或设备码授权，点击“开始授权”。应用打开官方页面；设备码模式在窗口显示一次性代码。设备码可用性由官方服务和账号策略决定，无法使用时可改用浏览器。
4. 在官方页面完成登录。应用通过状态事件读取结果，以登录邮箱为账号标题，并显示套餐标签；邮箱尚未返回时使用账号名称。正常状态不额外显示“已授权”，异常授权状态仍可见，不接收用户密码。
5. 账号详情通过图标按钮刷新状态、重新登录或退出，鼠标悬停和键盘聚焦显示统一风格提示。退出保留账号记录，删除会清理该账号的本地授权。
6. 套餐后显示官方 account_id 的首 8 位和末 6 位，完整值可通过鼠标悬停或键盘聚焦查看；旧账号点击“刷新状态”补全。账号启停使用电源图标按钮，绿色表示已启用，灰色表示已停用，悬浮提示说明下一步操作。
7. 账号详情自动读取真实订阅额度：Plus／Team 普通套餐显示 5h 与一周窗口，其他套餐显示一周窗口。蓝／绿进度条显示剩余百分比，不推算固定请求次数。状态刷新后自动重新读取；查询失败可点击额度区域的刷新图标重试。
8. 额度窗口显示重置倒计时，悬浮或键盘聚焦可查看本地时区的完整重置时间。已过期快照提示“待刷新”，不擅自把进度条恢复为 100%；缺失窗口或时间明确提示。全额且无官方重置目标时显示本地“未开始计时”，悬浮提示说明时间尚未返回。
9. 订阅卡片底部并排显示创建／更新时间，统一为本地时区 YYYY-MM-DD HH:mm；列表沿用相同格式。OpenAI 账号详情顶部的设置图标在入口旁展开局部设置面板，自动避让窗口边缘、内部滚动，不遮暗或模糊整页；关闭按钮、再次点击入口、Escape 或点击外部可收起。提供「Codex WebSocket」开关，默认开启、所有 OpenAI 账号共用。只控制当前 OmniProxy 网关的 WebSocket 接入，开关自动保存并即时生效，普通 HTTP/SSE 仍可用；不修改 Codex 认证或会话。读取失败提供重试，保存失败保留原值，任一开关保存期间暂时禁用两个设置开关，关闭或重开面板不会取消已经提交的保存。详见 `LOCAL_AGENTS.md`。
10. 每个订阅账号提供“重置卡”图标，有可用数量时显示角标。点击在按钮下方展开局部面板，靠近窗口边缘时自动避让，不遮暗或模糊整页；卡片列表在面板内滚动。可查看官方可用总数、卡片名称／说明、状态、获得时间和有效期。信息未返回不当作零数量，详情不完整时可让官方选择下一张可用卡。关闭按钮、再次点击入口、Escape 或点击面板外可收起面板；使用过程中禁止关闭。
11. 点击“使用这张卡”或“使用下一张可用卡”后，必须点击“确认使用”才会兑换。结果不确定时显示“核对本次使用”，关闭／重开面板或重启后可恢复同一请求；使用结果和额度刷新结果独立显示。

重置卡明细和账号设置面板统一使用细圆角滚动条，轨道始终保留占位，默认及滚动时隐藏，仅悬停轨道或拖动时淡入、移开后淡出，内容宽度不随显隐变化。保留滚轮、键盘、轨道点击和滑块拖动，减少动态效果模式下取消透明度过渡。

## 自动激活额度窗口

OpenAI 账号设置提供「自动激活 Codex 额度窗口」，默认关闭。切换开关直接持久保存并生效，无需二次确认或保存按钮；保存期间显示进度，失败保留原状态并允许重试。开启成功后立即检测，应用运行期间每 5 分钟串行检查，已有额度读取也会唤醒限频检测。只处理启用的 OpenAI 提供商及已授权、身份完整的启用订阅账号，不要求网关运行。

按现有页面定义识别未开始：有效的 5h／周窗口、剩余 100% 且没有重置时间。缺失窗口、异常时间、已知耗尽和已开始的窗口不触发。使用原账号官方目录中的默认模型发送固定短消息，禁用工具、使用已公布的低推理档位，会消耗少量订阅额度；发送前再检查额度和身份，完成后复查官方重置目标。一次消息可以激活两种窗口。

迁移 017 保存默认关闭设置和每账号／窗口的身份及周期登记。发送前登记，同周期在并发、重启、超时或结果不确定时均不重发，只复查；观察到新周期后才可再次激活。尚未确认时明确显示待复查，不宣称已激活。关闭保存停止后续自动请求，已经发送的请求无法撤回；退出取消并有界等待。设置不会修改原客户端配置或会话，不自动使用重置卡。见 [ADR-009](../decisions/ADR-009-codex-quota-auto-activation.md)。

## 行为边界

- 授权等待最多 10 分钟，初始化及单次操作有 30 秒超时。关闭登录窗口或切换页面会保留后台授权，重新打开同一操作可恢复；显式取消、应用退出或超时才停止回调。后台授权完成后账号列表通过事件刷新。
- 应用重启后原授权链接失效，需要重新开始。重试使用新的浏览器页面，旧页面的重新加载无法恢复已经结束的回调服务。
- 一次只允许一个授权会话。正在重新授权的账号不能同时刷新、退出或删除。
- 重新登录需保持原身份。改用其他身份请新增账号；取消不会破坏原授权。
- 刷新由官方组件处理令牌刷新。凭证缺失显示需要重新登录，无法确认状态时显示待确认；套餐字段不代表实际可调用模型或剩余额度。
- 官方授权完成后使用强制刷新读取身份。新增账号的身份读取暂时失败时，保存已成功的系统授权与账号引用，标记状态待确认并显示警告，用户可刷新恢复，不因元数据读取失败注销有效授权。重新登录已有账号仍须确认原身份后才能替换。
- 订阅账号没有密钥预览、密钥复制或 API Key 替换入口；修改名称不改变授权。
- 套餐标签按官方返回的套餐标识配色，支持 Free、Go、Plus、Team、Business、Pro、Pro Lite 等不同背景。未识别的标识保留原文并使用中性配色；不根据套餐大类推断未返回的价格或额度档位。
- 官方账号 ID 通过本机 account/rateLimits/read 返回的 accountId 获取，不读取令牌或使用本地记录 ID 代替。附加读取最多等待 5 秒；暂未返回时保留授权和已有 ID，并明确提示刷新，不将身份信息写入日志。
- 额度通过独立 SubscriptionQuota 查询读取同一官方协议，优先使用 codex 用量桶并按窗口分钟数识别 300／10080。缺失持续时间不根据 primary／secondary 位置猜测；官方未返回窗口时不展示假数值。
- 查询读取使用 10 秒超时（接口总操作上下文 30 秒），与已有账号操作串行以限制官方子进程数量。前端按账号身份及授权状态隔离缓存，快照 60 秒后过期、暂离界面保留 10 分钟，不后台轮询或自动重试。元数据更新时间变化触发同一身份内的后台查询，保留上一次数值／时间／布局，失败也保留原快照；退出或切换身份不展示其他身份的额度。
- 配额页与账号详情共用查询选项、缓存和前端串行队列；排队时离开页面会取消未开始的请求，已开始的查询等待后端结束后释放名额。全局页面能力见 `QUOTA.md`。
- 首次没有快照时使用安静的固定布局占位，不显示查询中的可见文案或推算额度。结果返回后数值／时间淡入、进度条宽度过渡，遵循减少动画偏好；多个组件共享刷新时不取消并重启同一查询。
- 官方身份字段存在时验证快照与保存账号一致；额度读取失败不改变授权状态，返回稳定错误码，禁止记录身份、凭据或原始响应。额度百分比与计时不代表实际模型调用权限。
- 重置卡数量使用 availableCount，不用详情数组长度推算；credits:null 表示仅数量，空数组表示详情已查询但未返回可用条目，列表可能被官方截断。未知类型／状态、已使用和已过期的指定卡片不可使用。
- 重置只由用户手动确认触发，无自动重试或自动使用。官方返回 reset／alreadyRedeemed／nothingToReset／noCredit 后更新记录并重新读取；超时保留同一幂等键，不能换键当作一次新使用。待核对操作不允许被新请求覆盖。
- 迁移 006 保存重置操作的公开身份归属、卡片 ID、UUID 和有限状态，支持跨重启核对及完成回执恢复，不存凭据或原始响应。详见 [ADR-004](../decisions/ADR-004-reset-credit-idempotency.md)。
- 清理失败会返回错误或警告。临时授权保留清理标记，下次登录前重试；已替换的旧授权保留定位信息，退出、删除或下次成功重新授权时重试。

## 存储与安全

- 本机官方 app-server 使用固定参数、独立 CODEX_HOME 与强制 keyring，不将令牌写入 SQLite 或明文 auth.json。
- CODEX_HOME：操作系统缓存目录中的 `OmniProxy-CodexAuth/<运行环境>/<随机 ID>`。开发与生产隔离，应用数据目录迁移不改变其 keyring 定位。
- SQLite 通过迁移 004 新增 `auth_method`、`auth_email`、`auth_plan`、`auth_state`。旧账号默认为 API Key。
- 迁移 005 新增 `auth_account_id`，仅保存公开身份标识，长度与格式经过校验；与本地 `id`、隔离配置 ID 和凭据引用分离。
- `credential_ref` 指向原有 DPAPI 存储，密文只含隔离配置定位；授权令牌由官方组件管理。删除与失败清理仅操作经过格式和根目录校验的隔离目录。
- 授权 URL 限定到官方 HTTPS 域名，浏览器打开接口只接受进行中的随机会话 ID，不接受任意 URL。
- 不读取或修改用户原有 Codex 配置和登录。日志不记录授权 URL、用户码、账号身份或令牌；前端只显示稳定错误码对应的文案。
- 授权阶段诊断仅记录状态与稳定错误码，通过中央脱敏 logger 输出；用于区分等待、超时、协议、账号读取和保存失败，不记录授权内容。
- 授权子进程过滤启动器继承的来源、登录客户端和签发方覆盖变量，使用 OmniProxy 初始化的客户端身份；用户配置的 HTTPS 代理和自定义 CA 保留。避免从 Codex 桌面启动开发环境时混用桌面应用的授权来源。
- 旧版 `auth.openai.com/oauth/authorize` 浏览器入口采用参考项目已可登录的流程来源 `codex_vscode`，映射仅作用于此端点的 originator。client_id、scope、state、PKCE 与 redirect_uri 保留官方组件原值；app-server 初始化和请求归属仍标识 OmniProxy，设备码及其他授权端点不改变。

协议来源：[官方认证说明](https://learn.chatgpt.com/docs/auth)、[官方 app-server 文档](https://learn.chatgpt.com/docs/app-server)。具体实现决策见 [ADR-003](../decisions/ADR-003-official-codex-subscription-auth.md)。
