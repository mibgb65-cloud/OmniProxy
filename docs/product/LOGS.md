# 实时运行日志

日志页用于查看当前应用进程的运行诊断记录，支持中英文与亮暗主题。

## 页面能力

- 默认展示 INFO、WARN、ERROR，可按级别多选、模块和关键词组合筛选；关键词最多 256 字符，覆盖信息与诊断字段。
- 时间显示到毫秒，级别同时使用文字和颜色区分。展开信息可以查看完整时间和已脱敏结构化字段，支持复制单条 JSON 记录。
- 只有日志列表滚动，页面工具栏保持可见；停留在底部时自动跟随，向上翻阅时保持阅读位置，显示新增记录数量与回到最新入口。
- 暂停冻结当前显示，后台继续记录；继续时按游标补齐。高频日志可能覆盖缓存中的旧记录，页面会提示缓存边界。
- 清空显示只更新页面游标，不清理后端缓存或磁盘日志；后续新增记录继续显示。文件清理由设置页管理。
- 导出当前筛选结果为 JSONL，使用原生保存对话框。正文由后端缓存获取，前端只提交记录 ID；已过期记录的数量会在结果中显示，全部过期时要求重新加载。
- 打开日志目录只使用当前运行环境的配置，不接受前端传入的路径。

## 数据与生命周期

沿用中央 slog／Redactor／轮转文件。现有 UIBuffer 的 Add／Lines 接口保留，内部扩展为结构化记录，默认和最大容量为 5000 条。代理结束日志包含 request_id、已报告输入／输出 Token 和用量状态，可从展开行跳到请求详情；请求页也可按同一 ID 筛选日志。详见 `ACTIVITY.md`。

记录包含递增 ID、UTC 时间、标准日志级别、模块、信息和诊断字段。信息与单个字段限制约 2 KiB，字段数量和总量有界，读取得到独立副本。

Wails 通过 `logs:updated` 发出最新序号通知，最多每 150ms 合并发送一次；通知不携带正文，也不阻塞日志写入。页面先订阅事件，再通过 LogsRead 分批读取，每批最多 200 条并固定本次读取上界，处理去重、缓存覆盖与游标复位。

页面离开时解除订阅；应用退出时停止事件转发。UI 模块不修改实际采集级别；生产默认 INFO，开发默认 DEBUG，页面底部显示实际记录级别。

## 安全与边界

脱敏在进入日志出口和缓存前执行，包括嵌套 Group、error、map／数组和延迟属性；无法安全序列化的值遮掩，递归深度有界。

密钥、账号名称、提示词和回复相关结构化字段会遮掩，UI 仅接收诊断字段白名单。调用方仍必须遵守不把用户内容或凭证拼进日志消息的规则。

JSONL 导出先写临时文件再替换目标文件，失败时保留原文件；目标必须是用户通过对话框选择的绝对 JSONL 路径。对话框取消不显示导出成功，底层错误或路径不会原样显示在页面。

首版只展示当前运行缓存，不检索历史日志文件，不采集用户对话内容。Wails 自身独立控制台输出不在应用中央日志缓存内。
