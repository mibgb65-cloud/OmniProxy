# API Key 账号余额查询

DeepSeek 和阶跃星辰普通按量 API Key 账号支持官方余额查询。阶跃支持账号级国内／海外，账户类型与累计金额单独建模，国内已确认人民币 CNY、海外币种待确认，不套用 DeepSeek 的剩余分项及充足标志；Step Plan 剩余 Credit 未接入。阶跃详细边界见 `STEPFUN.md`，下文为 DeepSeek 协议与展示规则。

## 使用

- 打开“账号 → DeepSeek”，卡片和列表自动查询总余额、赠送余额、充值余额、币种及官方余额是否充足。
- CNY／USD 分开展示，不换汇、不合并；金额保留官方十进制文本，不使用浮点计算。
- 刷新图标仅查询余额。同一账号版本的后台刷新保留旧结果，失败继续保留旧结果并显示错误；首次失败不显示为零余额。
- 余额刷新期间图标旋转并禁用重复点击，完成或失败恢复；减少动画偏好不播放旋转。API Key 卡片的启停状态标签与密钥复制区域同一行、靠右显示。
- 更换 API Key 或元数据版本变化重新查询，避免复用旧凭据的余额；前端缓存 60 秒，暂离页面保留 10 分钟，无后台轮询和自动重试。
- 配额页复用相同缓存与读取能力，余额查询最多两个并发，离开页面移除未开始的排队查询；具体概况、筛选和批量刷新见 `QUOTA.md`。
- 账号或提供商停用仍可做只读余额查询，不改变转发资格。余额是否充足不表示模型权限或保证转发成功。

## 协议与安全

- GET `https://api.deepseek.com/user/balance`，Bearer 认证，仅由后端发起，不发送模型请求。
- `is_available` 表示官方余额充足状态；`balance_infos` 含 currency、total_balance、granted_balance、topped_up_balance。
- 总余额包含赠送及充值余额；赠送余额为未过期赠送部分。直接显示官方字段，不从金额推算可用状态。
- 接口固定官方 HTTPS 地址，禁止重定向，不使用用户配置的自定义 Base URL。系统 HTTP 代理／网络设置仍由现有标准传输处理。
- 应用层核对账号为 DeepSeek API Key，通过 account.UseAPIKey 受控回调读取；结束后清除解密字节，请求头移除 Authorization。前端只接收余额 DTO，不接收 Key 或凭据引用。
- 查询超时 10 秒，响应上限 64KiB；校验字段存在、类型、币种、重复币种及十进制长度／格式。空明细明确显示未返回，不虚构金额。
- 401、403、429、服务错误、网络超时、无效响应及凭据问题使用稳定错误码和本地文案，不记录凭据或原始响应。

来源：[DeepSeek 官方余额接口](https://api-docs.deepseek.com/api/get-user-balance/)。
