# 网关页面

## 小米 MiMo（2026-10-14）

普通 API Key 已接入，复用现有账号、路由、客户端目录与请求／用量统计。支持文本、思考和函数工具调用的原生 Chat Completions、Responses 与 Anthropic Messages JSON／SSE；Messages 使用独立 `/anthropic/v1/messages`。账号添加后提供未验证预设，路由页可同步真实模型目录。接入检查包含 MiMo 元数据；具体模型和兼容边界见 [MIMO.md](MIMO.md)。

网关页集中管理本地代理运行、客户端接口和「本地 Agent 接入」。网关默认停止，由用户手动启动。
「设置与关于 → 通用设置 → 桌面行为」可开启「启动软件时自动启动网关」，下次启动
OmniProxy 时生效，关闭后恢复手动启动。此偏好独立于 Windows 开机自启动，不立即改变
当前网关状态。自动启动遇到端口占用等错误时保留桌面应用运行，并记录错误，用户可处理后手动重试。

侧栏软件名称下方、仪表盘导航上方显示网关运行状态、代理端口和已添加账号总数（包含停用账号），提供电源按钮启动／停止网关。侧栏收起后保留按钮与状态点，悬停或键盘聚焦可查看概况。启停操作中会显示进度并同步禁用侧栏和网关页按钮；操作结果、错误及后端状态事件通过共享缓存同步。停止网关会取消在途请求。

## 页面结构

公共顶栏显示运行状态、实际地址摘要、启停与刷新入口，和选项卡导航一起在内容滚动时保持可见。页面分为四个选项卡：

- **运行概览**：默认显示已记录请求总量、成功率、平均首字／完整耗时、当前未结束请求与已报告 Token；提供成功／失败趋势、最近请求、累计上游分布和只读接入信息。
- **客户端接入**：本地 Agent 品牌图标卡片；点击后进入对应客户端配置页，进行一键配置、预览／应用、独立接入 Key 复制、启停和恢复。
  卡片单独展示软件安装状态，详情页支持检测和安装；Codex CLI 与桌面应用分开处理。
- **手动接入**：通用 Base URL、Codex／Claude 端点与配置摘要、复制及官方说明。
- **测试诊断**：DeepSeek／River／Atria／Gemini／MiMo API Key 元数据接入检查，以及请求记录／运行日志入口。

选项卡使用 `/gateway?tab=overview|clients|manual|diagnostics` 定位，缺省或非法值回到运行概览，支持刷新及前进／后退。方向键移动页签焦点，Enter／Space 激活。面板首次访问才加载，访问后保留到离开网关页面；往返切换保留手动配置模式、进行中的操作与结果，隐藏面板不接收键盘焦点。切换后内容回到顶部。刷新同步更新网关、资源元数据及已加载的客户端配置，不调用模型。

运行参数只读；资源概况和接入检查覆盖 DeepSeek／River／Atria／Gemini／MiMo／阶跃星辰／Kimi API Key，ChatGPT / Codex 使用已有订阅账号接入。资源数量仅表示配置，不表示密钥有效或目录已同步。手动配置摘要含占位符，不包含完整密钥；独立 Key 继续通过桌面端复制。

## 请求统计与首字耗时

请求指标、趋势和最近记录共用本地今日／近 7 天／近 30 天边界。统计从 Trace 受理推理请求开始，不包含鉴权／并发拒绝前未受理的请求、模型列表或后台资源查询。成功率为成功／（成功＋失败），平均总耗时也按成功＋失败的完整请求计算；取消单列。当前进行中统计全部未结束记录，不限当前时段。

首字耗时从网关受理到首次成功写出有效流式内容：HTTP 在完整 SSE 事件写出并刷新后记录，Responses WebSocket 在完整消息写出后记录。包含文字、拒绝文本、思考和工具输出，排除心跳、空 delta、创建元数据、单独用量和不支持的事件。使用单调时钟，每次请求只记录首次值；不会把响应头／上游首字节冒充用户可见的内容。缓冲的跨协议转换仍按下游实际写出时刻测量。

旧记录、非流式和没有有效内容的请求保持未知，显示「—」；测得的 0 毫秒是有效值。平均首字只计算成功且实际测得的流式请求，并展示样本数。失败／取消后已测得的首字仍保留在明细，不混入成功均值。

迁移 032 为明细增加可空首字字段，为独立 15 分钟桶增加总和／样本数。结束事务同时记账，幂等完成、保留上限和账号删除不会减少累计；不保存提示词或生成内容，日志只追加可选毫秒数字。请求详情也可查看首字和总耗时。详见 [ADR-014](../decisions/ADR-014-first-token-latency.md)。

上游分布从独立提供商／模型累计分组，明确标为累计，保持删除资源及淘汰明细后的历史，不随时段切换；不把最近 8 条记录当作全量分布。最近表显示所选时段最后 8 条保留记录，支持本地模型／提供商与状态筛选，链接进入完整请求记录和指定请求详情。

网关和仪表盘复用统计缓存、范围生成和本地 `activity:updated` 事件。隐藏网关面板不继续读取统计；背景记账刷新不会启动手动刷新按钮动画。读取失败展示错误，未知值不伪装为零，页面不会调用模型或主动检查官方额度。

River 原生转发 Chat／Responses JSON 与 SSE；Messages 文本／工具通过 Chat 转换，完整上游结果返回后才生成下游 SSE。添加 API Key 后提供三款官方预设，可同步实际目录；详细能力与限制见 [RIVER.md](RIVER.md)。

Atria 使用独立原生适配器，将 Chat Completions／Responses／Messages 转发到官方相应端点，保留 JSON、SSE 和工具调用正文。只接受文本内容与整数 1–65536 的输出上限；使用既有受控凭证、错误分类、Retry-After、取消及请求／用量统计。模型预设为 `Atria-Dawn-Preview`，不表示 Key 已验证，不新增隐式重试、自动调度、余额查询或上游 WebSocket。

Gemini 使用 Google 官方 OpenAI 兼容 Chat 端点，受控 Key 仅放在上游认证头；文本 Chat JSON／SSE 原样转发，保留工具签名扩展。流式请求合并 `stream_options.include_usage=true`，复用本机请求及 token 统计；显式输出上限按实际选中账号的官方模型限制校验。模型需先在路由页同步。不进行隐式重试／切换 Key，也不支持 Gemini Responses／Messages、WebSocket 或原生 Gemini REST 路由；限流与支付观察见 `QUOTA.md`。

## 当前能力

- 真实运行状态、启停，停止会取消在途请求。
- Codex CLI／Desktop、Claude Code CLI、Claude Desktop Code 的配置入口；默认模型／路由选择、受控预览、应用、加密备份和恢复。
- 客户端独立接入 Key，支持复制及启停。复制在桌面端完成，完整 Key 不通过 Wails 绑定返回。
- Codex 保留 model_provider、官方认证文件与会话目录。内置 openai 使用专用本地接入路径，不重定义内置提供商表。
- Claude Desktop 添加独立 3P 条目，保留官方当前配置。首次使用需在桌面配置选择器选择该条目；不会自动切换官方工作空间。
- Chat Completions、Responses、Messages 和 Codex Responses WebSocket。
- OpenAI 账号设置提供全局 Codex WebSocket 开关，默认开启且持久保存；每次握手及连接内创建响应检查当前开关。关闭时拒绝 WebSocket，HTTP/SSE 保持可用，修改无需重启网关。
- ChatGPT / Codex 与 DeepSeek 模型目录在路由页按账号同步，网关模型选择同步更新。

实际协议及配置范围见 [本地 Agent 接入](LOCAL_AGENTS.md)，会话保护设计见 [ADR 005](../decisions/ADR-005-preserve-agent-session-identity.md)。

## 运行边界

只绑定 IPv4 loopback，检查请求 Host，禁止跨来源浏览器请求、任意 URL 转发和上游重定向。每次请求均校验本地接入 Key，并重新检查路由、账号和提供商启用状态。

Chat Completions 请求体上限 2 MiB、消息最多 512；Messages 请求体上限 16 MiB、消息最多 512。Responses 与 `/responses/compact` 使用独立 16 MiB 请求上限，不套用消息数量限制，因为历史还包含推理、工具调用／结果及压缩项。所有协议仍拒绝重复 JSON 字段、非法 UTF-8 和超过 32 层的嵌套；请求和 WebSocket 连接并发上限各 16。请求期限 120 秒，普通响应上限 8 MiB，SSE 总量 32 MiB，Responses 单行 SSE 上限 2 MiB。

WebSocket 空闲读超时 60 秒，连接内缓存上下文，合并后的完整请求仍受 16 MiB 限制；禁止跨连接引用未知 response ID，但允许客户端在重连后显式回放完整历史，不删减、不隐式重试生成。协议解析失败保留安全错误码，并只记录协议、传输、状态和固定错误码，不记录请求正文。

流读取失败返回 `upstream_stream_failed`，单行超限返回 `response_too_large`，客户端写入／刷新失败返回 `client_write_failed`；这些错误不会被误标为凭据不可用。取消及超时仍按既有分类处理。HTTP 已提交 SSE 响应头后保留实际状态码，通过请求失败状态与错误码记录中断；WebSocket 使用错误事件表达失败。开始生成后的中断不触发账号切换或自动重放。

ChatGPT Responses 原生流式转发；跨协议支持文本和工具关联，收齐结果后返回 JSON 或 SSE。DeepSeek 跨协议关闭思考，多模态及不支持的托管工具显式报错。已支持最多三次的同服务商、同认证／计费／地区账号故障切换，固定账号和成功响应后不重放；完整健康／负载调度仍待实现。开关、触发条件、Google 配额边界和尝试统计见 [账号故障切换](FAILOVER.md)。

原上游凭据保留在受保护存储中；客户端原认证头一律丢弃。错误只返回稳定代码，日志不记录请求内容、账号身份、完整地址或凭据，统一 Redactor 也屏蔽本地接入 Key。

## 验证

先在账号页添加上游账号，ChatGPT／DeepSeek／Gemini 在路由页同步模型，Atria 与 MiMo 自动提供官方预设，MiMo 也可按账号同步实际目录，再启动网关并配置客户端。通过客户端发起实际请求，并在请求记录和运行日志中查看结果；真实请求会消耗账号额度。网关页面只检查已保存的配置，不提供请求验证功能。

手动客户端可使用卡片上的「复制接入 Key」，无需使用上游 API Key。开发环境默认地址 http://127.0.0.1:3001/v1，正式环境默认端口 3000，以实际页面为准。Codex 一键配置会生成含独立 Key 的专用本地地址，请保持 model_provider 原值。
