# 仪表盘运行总览

仪表盘作为运行总览首页，原应用信息和绑定测试面板已移除。版本、存储和运行配置继续由关于及设置页面提供，网关启停使用侧栏。

## 页面

- 默认今日，可切换近 7 天／30 天；指标、趋势和最近请求使用同一时段。
- 四项指标：请求数、已报告输入／输出和合计 Token、成功率、平均完整请求耗时。进行中与取消单列；成功率为成功／（成功＋失败），耗时也仅计算成功＋失败的完整请求，包括流式响应。
- 今日按本地小时展示，7／30 天按本地日期展示。趋势可切换请求结果分类与输入／输出 Token，支持悬浮／键盘焦点查看精确值，图表在窄屏内部滚动。
- 待处理问题关注已启用账号及提供商中的授权异常、已确认资源耗尽和已启用异常路由；未检查资源单独提示。账号、路由和配额链接进入对应管理页面。
- 最近最多 8 条已保留请求，显示时间、模型、提供商、结果及耗时，点击进入已有请求详情。资源概况、客户端接入采用紧凑卡片。
- 客户端状态表示配置读取结果，不代表进程在线；未配置、冲突及接入停用分别标示。

## 统计与历史

迁移 010 追加独立 UTC 15 分钟桶，按请求开始时间归属。Begin、累计用量差值、结束状态和崩溃恢复与原记账事务一致更新；重复事件不重复累计。清理请求明细、删除账号／提供商均不减少聚合。

前端按本地日历生成 UTC 秒边界，后端校验 2–33 个递增、15 分钟对齐的边界及最大时间范围，读取同一事务快照。15 分钟粒度支持现代整点、半小时和 45 分钟时区，跨夏令时按实际本地日长处理。

迁移只回填现存请求；若全局计数大于明细数，则保守标记迁移前时段可能缺失，不推算已经删除的结果、耗时或 Token。页面显示历史覆盖提示；没有样本的成功率和耗时显示“—”，零请求但存在历史缺口时不把零值当作完整统计。完整用量报告数量单独显示，未收到任何报告的 Token 保持未知。

## 刷新

本地记账变更通过有界合并的 `activity:updated` 信号通知首页重新读取，事件不携带账号或正文；窗口隐藏时只标记失效，返回后刷新。时钟只用于本地日期跨越，不周期调用模型或官方配额。

首页资源模块默认仅订阅配额页／账号详情的共享缓存。“刷新概况”读取本地统计和配置；用户点击“检查资源”后才调用已有官方接口，沿用订阅串行／余额两个并发及身份／凭据隔离规则，显示失败数量与最后成功查询时间。

没有收费估算、自动使用重置卡、低额度阈值、自动故障切换或请求正文保存。详见 ADR-007。
