# TASK-20261017-010: Agent 卡片按可用宽度自适应列数

## Status

In Progress

## Created

2026-10-17（Asia/Singapore）

## Request

用户反馈大屏下本地 Agent 卡片每行仍只有两张，宽度浪费，希望增加大屏的信息密度。

## Goal

保留统一分组卡片，按内容区实际宽度自动排出一至多列，兼顾大屏密度、小窗口及侧栏收展。

## Analysis

目前 local-agents.tsx 固定使用 sm:grid-cols-2。应改为可用宽度驱动的网格，参考项目现有
账号网格做法，设置合理最小卡宽；不按屏幕型号写死列数，也不修改卡片内配置与导航。
采用 auto-fit／minmax，最小卡宽为 22rem，窄于该宽度时收缩到容器 100%。列数随内容区
变化，余宽在当前列之间分配，末行沿用已有列宽；rem 随用户字号缩放。

## Implementation Plan

1. 选择兼顾产品标题、平台名称和状态的最小卡宽，使用自动填充网格。
2. 原生窗口核对小／中／大屏、多列边界及侧栏收展，检查换行、溢出和进入／返回行为。
3. 执行仓库质量门，更新说明、审查差异、提交并归档。

## Implementation Result

- 去掉固定两列，局部 CSS 使用 `repeat(auto-fit, minmax(min(100%, 22rem), 1fr))`；
  列数按实际可用宽度计算，侧栏和字号变化自然参与，窄容器可收缩，末行沿用列宽。
- 保留统一分组卡片、状态与共享详情导航；仅修改网格样式，无新依赖或后端变更。
