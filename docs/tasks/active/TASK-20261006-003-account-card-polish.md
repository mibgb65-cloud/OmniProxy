# TASK-20261006-003: 账号卡片固定高度与删除图标

## Status

In Progress

## Created

2026-10-06 21:04

## Request

1. 账号页面不再显示 OpenAI 的“订阅登录待接入；目前可添加 API Key 账号。”
2. 每个提供商卡片使用固定高度，不再随账号数量变化。
3. 删除按钮文字改为图标。

## Goal

账号总览卡片高度一致，多账号列表在卡片内滚动；删除操作以图标呈现，仍可识别目标账号并确认删除。

## Analysis

- 总览 `AccountProviderCard` 采用内容自适应高度，账号列表仅限制最大 240px；空卡片和多账号卡片高度不同。
- OpenAI 接入提示只由总览卡片渲染。
- 总览与提供商详情页分别渲染文字删除按钮，可复用现有 Lucide 图标和 Button 的 `icon-sm` 尺寸。
- 卡片固定为 320px，内部使用纵向弹性布局，账号列表占据余下空间并继续使用已有 ScrollRegion。
- 本次只调整前端呈现，不修改账号删除确认、凭证存储、后端能力或订阅登录流程。

## Implementation Plan

1. 移除总览 OpenAI 接入提示；提供商卡片固定 320px，高度不受账号数量或启用状态影响。
2. 总览和详情页的删除按钮改为垃圾桶图标，保留账号名称可访问标签、悬浮提示、禁用状态及原有删除确认。
3. 更新现有账号页面测试，在实际开发窗口检查空卡片和多账号卡片高度、内部滚动及图标布局。
4. 运行 `task verify BIN_DIR=bin/verify-account-card-polish`，更新状态看板与任务记录，审查并提交本任务文件。

## Risks

固定高度不能裁掉标题或操作按钮；列表必须正确收缩并滚动。真实窗口验证只读取和滚动现有账号，不执行删除。

## Implementation Result

- 移除 OpenAI 总览接入提示及对应未使用的中英文文案。
- 提供商卡片固定为 320px，标题与停用提示不收缩；空状态居中，多账号列表使用剩余空间并在内部滚动。
- 总览和详情页删除按钮使用 Lucide `Trash2` 图标及 32px 图标按钮；保留包含账号名的可访问名称、删除悬浮提示、原有禁用状态和确认流程。
- 更新既有页面测试，验证提示不再出现、卡片高度约束、图标按钮仍能执行删除及详情页可访问名称。
- 修改文件：账号总览卡片、详情卡片、对应页面测试、中英文文案、状态看板及本记录。无后端、依赖或凭证存储变更。
