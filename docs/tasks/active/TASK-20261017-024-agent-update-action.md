## Goal

## Analysis

- 更新仅针对 Claude Desktop，使用现有固定 `msstore` 包 ID 和 WinGet 后台进度渠道，保留 Windows 安装完整性校验；不接受前端提供下载地址、版本或命令。
- [WinGet 官方升级契约](https://learn.microsoft.com/en-us/windows/package-manager/winget/upgrade)支持精确 ID／源升级。使用 `upgrade` 而非沿用既有 `install --no-upgrade`，不传 force、卸载旧版、关闭应用、跳过安全校验或重启参数。
- 点击更新后复核官方目标和真实安装版本，再启动与安装互斥的后台任务。仅真实版本达到检查目标才成功；商店未提供该版本时返回明确提示，不将进程结束当作升级成功。
- 复用安装快照、轮询、退出取消与进度；增加操作类型／目标版本以区分更新与安装，防止重新检测把仍安装着的旧版本误报成更新成功。
- 验证使用替身，不实际更新用户本机 Claude；原生窗口只检查按钮切换和布局。

## Implementation Plan

1. 核对可用官方更新渠道，确认固定目标、安装完整性和实际版本核对方式。
2. 对接更新动作与简洁状态，复用现有互斥和反馈，并保留固定按钮尺寸。
3. 使用替身覆盖升级、失败和重复点击，完成原生只读／布局验证、质量门、文档与提交归档。
