# TASK-20261028-012: 发布 v2.1.0 正式版

## Status

In Progress

## Created

2026-10-28（Asia/Singapore）

## Request

用户在比较 v2.0.0 至当前变更并收到版本建议后确认：「按2.1.0发布吧」。

## Goal

将当前 main 的版本统一为 2.1.0，整理相对 v2.0.0 的中英文发布说明，通过本地质量门与构建校验，使用仓库既有 GitHub Actions 流程构建、自签并公开发布 v2.1.0 正式版。

## Scope

- 阅读发布、构建、测试规范，核对远端标签、Release 与工作流状态。
- 同步应用、前端包、Windows 资源与安装器版本。
- 编写正式版发布说明并更新受影响的当前状态和升级文档。
- 本地验证、提交、推送 main 与新版本标签，跟踪 Actions 发布结果。
- 校验公开 Release、资产与正式更新渠道，记录真实结果和提交哈希。

## Out of Scope

- 不加入新业务功能、不改技术栈或依赖、不做无关重构。
- 不覆盖已有公开 Release、不移动旧标签、不改写历史。
- 不操作真实账号或安装数据，不自动安装或修改客户端配置。
- 不把自动测试当作真实覆盖安装、端口联调或官方账号验收。
- 不读取、导出或记录签名私钥、令牌和密码。

## Existing Behavior

当前源码为 2.0.1-beta.7；最近本地构建记录显示质量门和安装包校验通过，但该包未签名、未公开发布。最近本地正式标签为 v2.0.0。

## Expected Behavior

版本源统一为 2.1.0（Windows 数字资源 2.1.0.0），GitHub 托管工作流产生项目自签的 Windows amd64 安装器与 SHA256，Release 为非草稿、非预发布，正式更新渠道可发现该版本。

## Analysis

- 仓库采用 SemVer；用户已明确选择 2.1.0，覆盖从 v2.0.0 至当前的端口管理、新模型、账号交互及修复。
- 版本源共五处：Go 常量、前端 package.json、build/config.yml、Windows info.json、NSIS wails_tools.nsh；发布脚本校验完整版本并生成数字资源。
- 远端默认分支为 main，当前公开 stable Latest 是 v2.0.0，未发现远端 v2.1.0 标签；原工作区干净。
- 现有 release.yml 按新标签构建、运行完整质量门、生成未签名 Artifact，再由独立作业自签、验证证书 pin／篡改拒绝和 SHA256，最后发布并设置 stable Latest。
- GitHub CLI 可以访问目标仓库，签名所需的两个 Secret 名称已配置；不读取 Secret 内容，也不在本地签名。
- 相对 v2.0.0 无新增数据库迁移和依赖；保留安装身份与数据路径。修改网关端口会重启监听器并取消在途请求，需在发布说明中提示。
- 真实覆盖安装、原生 UI、真实客户端端口联调及官方重置卡接口仍未由本轮验收，不宣称这些场景已通过。

## Implementation Plan

1. 核对项目约束、版本映射、工作流及远端 main / 标签 / Release。
2. 更新版本源、中英文发布说明、CURRENT 和升级信息。
3. 运行本地发布脚本，验证质量门、安装包资源、摘要和差异。
4. 提交发布变更并推送 main；确认提交后创建、推送 v2.1.0 标签。
5. 跟踪 Actions，核对公开资产、签名验证结果和 stable latest。
6. 回填实际结果、验证、风险和提交哈希，归档任务并提交记录。
