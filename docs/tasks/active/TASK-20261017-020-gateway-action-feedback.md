# TASK-20261017-020: 网关动作反馈解耦与柔和过渡

## Status

In Progress

## Created

2026-10-17（Asia/Singapore）

## Request

启动网关时右侧刷新接入检查也闪动；希望启停中的动画持续稍长、过渡更柔和，主按钮和侧栏电源按钮一致优化。

## Analysis

刷新按钮把所有查询的 isFetching 合并为自身加载状态，网关状态事件触发后台读取也会切换刷新文案／旋转／禁用态。主按钮和侧栏共享真实 mutation，但快速成功会在很短时间内反复切换状态。

## Implementation Plan

1. 刷新加载反馈只由用户主动刷新驱动，保留首次读取的禁用和错误处理，后台状态同步不触发刷新动画。
2. 成功动作提供约 650ms 的最短反馈，真实启停请求与结果缓存立即生效，慢操作不叠加完整等待，失败即时反馈；共享互斥覆盖反馈窗口。
3. 主按钮与侧栏使用固定尺寸的缓慢旋转图标、柔和颜色过渡，保留减少动态效果支持；验证快／慢／失败、多个入口、刷新解耦与原生状态，再运行质量门。

## Implementation Result

- 刷新按钮改由手动刷新 mutation 驱动，不再把后台 runtime／账号／提供商读取合并为自身忙碌状态；首次读取仍禁用，但使用普通文案而不显示手动刷新动画。
- 启停成功先立即写入真实结果缓存，再只补足不足 650ms 的视觉反馈。慢请求不叠加一轮延迟；失败直接进入原错误处理，不等待成功动画。共享 mutation 继续覆盖主按钮／侧栏互斥，增加同步检查避免跨入口重复提交。
- 成功的手动刷新也补足同一短反馈，避免用户主动点击时一闪即逝；所有真实请求立即执行。
- 两个启停入口共用固定尺寸的图标层，静态图标和加载圆环以 220ms 淡入淡出，圆环按 1.4s 慢速旋转；按钮使用 220ms 颜色／透明度过渡和较轻的禁用变暗，保留尺寸预留，减少动态效果下关闭动画。
- 后端、接口、网关启动速度与全局 Button 均未修改。
