# TASK-20261017-014: 一键配置支持选择模型

## Status

In Progress

## Created

2026-10-17（Asia/Singapore）

## Request

用户希望一键配置时可以选择模型，不手动选择则默认配置全部模型。

## Goal

保留默认全部模型的一键接入体验，允许用户只配置所选模型，确保预览与实际写入一致。

## Analysis

- 当前预览和应用共用 prepare，所有客户端均发布完整目录，RefreshCatalog 会再次写回全部模型。
- Input 增加可选 modelIds：缺省／null 表示动态全部；显式空列表拒绝，非空列表校验 ID、重复与边界。原 Model 字段继续表示默认模型。
- 目录版本绑定完整源目录，允许用户在同一源快照内调整子集／默认模型；应用仍核对文件和源目录版本。
- 迁移 031 在 agent_backups 增加可空 model_ids，与应用文件版本同事务保存，刷新按保存的子集过滤，恢复随备份记录清除。Codex 子集使用本地目录避免远程完整目录覆盖选择。
- 前端默认全选，增加全选／清空、逐项复选及所选模型中的默认模型；清空禁止应用。

## Implementation Plan

1. 核对客户端配置、目录生成／刷新和现有测试，确定兼容的选择语义。
2. 在现有弹窗增加模型选择，后端校验并应用所选目录，保留未选择时的全部模型行为。
3. 补充关键路径与边界测试，运行完整质量门，同步产品文档与任务看板。
4. 审查 diff，只提交本任务文件，归档实际结果。

## Implementation Result

- 弹窗默认勾选完整适用目录，提供按名称／ID 搜索、逐项选择、全选、清空和已选数量；未选模型仍可见并可重新勾选。清空后立即提示且禁用应用。
- 默认模型下拉仅列出已选模型，取消原默认后回退到所选范围内首项；Harness 保留只读建议模型及客户端内选择的原有语义。
- modelIds 缺省／null 继续表示动态全部，不影响旧调用者；显式选择在预览和应用时验证空值、重复、长度、数量与有效性，默认模型须属于选择。目录版本绑定完整源快照，源目录／文件变化仍阻止过期应用。
- 迁移 031 将选择保存到 agent_backups.model_ids，与受管版本同事务更新。目录刷新、重启和失败回滚保留选择，恢复原配置随备份清除；重新全选应用恢复动态全部目录。
- Codex 部分选择强制使用本地目录并关闭远程发现，避免重新发布全部；Claude CLI 默认失效后回退到所选且可用的模型。九种客户端复用现有写入、加密备份与外部修改保护。
- 修正备份 INSERT 的隐式列数依赖，改用显式列名，兼容扩展后的表结构；未新增依赖，未改变网关路由或模型调用权限。
- 项目开发版由既有 Wails watcher 重建，原生弹窗展示最新功能；未点击应用修改用户真实客户端配置，也未发送推理请求。
