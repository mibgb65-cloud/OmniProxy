## Request

记录每个服务商的每个模型使用的输入／输出 Token，并展示在用量页。

## Analysis

现有按模型统计合并同名模型；每日桶只有提供商名称快照，不能在资源删除后通过账号表可靠回查配置 ID。新增独立 provider_id＋model 累计表，与已有用量差值事务同步更新，保留删除后的数据。旧桶优先使用保存的请求快照识别唯一提供商，其次唯一名称映射；歧义归入历史归属，不推测拆分或减少旧累计。

## Implementation Plan

1. 添加迁移与提供商／模型累计，回填可识别历史。
2. 暴露可兼容的查询字段，用量页增加按提供商分组的模型表。
3. 验证同名模型隔离、差值幂等、删除／淘汰、旧数据迁移，执行 task verify 并恢复开发窗口。

## Implementation Result

- 迁移 009 增加无删除外键的提供商／模型累计表，与现有差值事务同步，跨账号合并且按配置 ID 隔离同名模型。
- 新增可兼容 providerModels 查询字段，保留原模型汇总；用量页增加按提供商分组的模型表，显示输入／输出／合计与请求数。
- 迁移回填旧桶，资源删除且请求仍在时保留原 ID，多 ID 混合或无法确定归属时保留历史分组。
