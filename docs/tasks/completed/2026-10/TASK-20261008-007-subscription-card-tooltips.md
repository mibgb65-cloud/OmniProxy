## Status

Completed

## Created

## Request

订阅账号卡片主标题显示登录邮箱；套餐标签使用不同背景色；隐藏正常状态的“已授权”；刷新、重新登录和退出改为图标按钮；全局悬浮提示统一美化，移除浏览器原生提示框。

## Goal

减少重复身份信息，提高订阅套餐与账号操作的辨识度，提供支持鼠标和键盘的主题一致提示。

## Scope

- 订阅账号的卡片、列表和摘要显示邮箱，缺失时保留账号名称。
- 按后端实际套餐标识设置标签配色，保留异常授权状态提示。
- 订阅操作图标化，复用现有登录、刷新和退出逻辑。
- 统一替换现有原生 title 提示，覆盖窗口控件、导航、账号、提供商、设置及运行信息。

## Out of Scope

- 更改授权流程、凭据存储、账号数据或订阅请求转发。
- 根据套餐大类猜测付费价格、额度或未返回的细分档位。

# Analysis

## Existing Behavior

卡片以账号自定义名称为标题，正文重复展示身份与类型；套餐使用同一种灰色背景；正常授权状态常驻显示；订阅操作是文字按钮，部分界面使用原生 title 提示。

## Related Modules

frontend/src/features/accounts、components/ui、components/common、features/providers、features/settings、features/about、app/routes。

## Dependencies

复用已有 Radix Tooltip、Lucide、Tailwind 与主题变量，不新增依赖。

## Risks

须避免工具提示干扰对话框触发、窗口拖动、长文本截断及键盘访问；深浅主题均需清晰可读。邮箱只能取自账号数据，不写入示例、日志或硬编码。

# Implementation Plan

1. 增加共享悬浮提示组件和订阅显示辅助逻辑。
2. 调整卡片、套餐标签、图标操作和现有 title 提示。
3. 验证邮箱回退、异常状态、操作行为与悬浮提示交互，检查响应式和深浅主题。
4. 运行 task verify，更新任务记录与当前状态，审查本任务差异。
