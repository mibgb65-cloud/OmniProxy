# TASK-20261009-009: 全局下拉选框统一样式

## Status

Completed

## Created

2026-10-09

## Request

用户反馈软件所有原生下拉菜单样式粗糙，要求统一优化触发器和展开菜单。

## Analysis

共 9 处 select：请求结果、日志模块、路由状态／编辑器三字段、账号模型同步、Agent 默认模型和网关测试模型。日志文件夹受忽略规则影响，额外执行不忽略文件的全局检索确认。仅 CSS 无法可靠统一系统弹层。现有 radix-ui 具备 Select，沿用应用主题和 Portal；空字符串选项用无冲突编码保留，RHF 改为受控字段，保留原级联重置与禁用／异常选项。

## Implementation Plan

1. 新建共享 SelectField，统一圆角、阴影、焦点／选中／禁用、滚动与定位，支持键盘和减少动画。
2. 替换全部可见原生 select，迁移表单和交互验证。
3. 验证空值、禁用、级联、弹窗内操作、主题／大字号／边缘布局，运行 task verify，更新文档和开发窗口。

## Implementation Result

- 共享 Radix SelectField 统一触发器和菜单，主题、圆角、背景模糊、阴影、悬停／选中勾选、键盘／焦点与减少动画，长列表滚动并避让窗口边缘。
- 替换全部 9 处可见原生下拉；RHF Controller 保留原提供商切换时清空模型／账号、禁用及已删除／未知选项。
- 空值通过全值编码保留，忽略 Radix 隐藏表单控件初始化的无效空事件，避免加载选项时清空默认模型；没有新增依赖。

## Verification

- 组件与集成测试初步通过：选择／清空／特殊值、禁用、Escape 焦点返回、配置预览、路由保存／修复／筛选、网关启停及日志模块筛选。
- 真实浏览器检查 24 种亮暗主题、80／100／140 字号、宽度960／360、上下边缘菜单；圆角、位置、长列表、选择和键盘焦点均通过，无页面错误。
- 完整 task verify 通过：格式、Go 静态／测试、ESLint、TypeScript、46 个前端文件共 226 项测试、Windows 构建。保留已有构建包体提示。
- 不忽略文件的全局搜索确认没有遗留可见原生 select／option，前端测试已迁移为操作实际菜单；路由字段文件 201 行，三个表单字段及级联逻辑保持同一个内聚组件，未为了 1 行差异添加额外层级。
- 原生 Wails 确认请求页下拉已是自定义 ComboBox；浏览器验证真实组件的全部菜单操作。UI 自动化后重新启动窗口以清除测试打开的菜单，开发窗口、Vite 9245、Control 3891 和代理 3001 已恢复。产品说明见 SELECT_CONTROLS.md；共享文件含前序实现，保留未提交状态。
