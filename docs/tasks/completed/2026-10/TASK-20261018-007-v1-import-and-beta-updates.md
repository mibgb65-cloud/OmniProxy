# TASK-20261018-007: 旧版数据迁移与 Beta 更新

## Status

Completed

## Created

2026-10-18（Asia/Singapore）

## Request

用户要求处理 Wails v3 大版本升级前的「数据迁移」和「Beta 更新」两个问题。

## Goal

新版提供用户主动触发、可预览、可重试的旧版数据导入，保留源数据与现有新版账号；更新检查正确识别预发布版本和渠道，支持 Beta 后续升级至新 Beta／正式版。

## Scope

- 基于旧仓库实际格式设计有界读取、凭据转换、幂等导入与回滚；迁移范围和不支持内容在预览及文档中明确说明。
- 修复版本比较，增加稳定／Beta 更新渠道与必要设置、真实仓库配置。
- 沿用用户已确认的 v2 Beta 版本规划，同步完整应用版本和 Windows 数字资源，避免旧版 v1 被误认为新版应用的更新。
- 扩展现有设置界面和 Wails 绑定，补充回归测试、产品／架构文档及必要 ADR。
- 执行定向验证和完整 task verify，归档记录并提交。

## Out of Scope

不读取或迁移用户真实凭据、不修改旧仓库和旧数据、不自动发布远端 Release、不合并旧仓库历史。

## Analysis

旧版 tokens.json 是包含 DPAPI 包装 tokenValue 的数组，Windows 使用固定 v1 entropy；新版 API Key 为独立 DPAPI 文件，Codex 订阅由官方组件的隔离登录持有，不直接接纳旧令牌。迁移支持可明确映射的 API Key 账号、名称、启停及计费／区域，订阅提示重新登录，历史／路由／全局设置保留在源目录且在界面明确说明。

采用单账号事务和确定性迁移 ID，保留已有新版账号；失败项目可重试，成功项目不重复导入。预览和导入之间校验源文件快照，预览／错误不返回凭据。默认目录按运行环境隔离并识别旧 bootstrap，自定义源目录由用户选择。

更新沿用按需检查和发布页手动安装，补齐 SemVer 预发布比较、稳定／Beta 渠道持久化、默认正式仓库、列表分页及输入／响应边界；未实现或承诺自动下载安装。工作区有五份既有未跟踪任务记录，保持不变且不纳入本任务。

## Implementation Plan

1. 检查旧存储格式、新版账户／事务／设置边界以及现有更新契约。
2. 明确迁移与更新方案，实施服务、绑定、界面和回归测试。
3. 验证失败／重试／重复导入与版本排序、渠道筛选和安全边界。
4. 执行完整质量门及界面检查，更新文档、审查差异、提交并归档。

## Implementation Result

- 新增只读旧数据解析、v1 Windows DPAPI entropy 兼容和应用层迁移服务。预览及确认均限制文件类型／大小／数量，确认复核源快照；支持兼容官方入口的 API Key、名称、启停及明确计费／地区，订阅、MiniMax 旧计费身份和不支持的提供商／地址逐项提示手动处理。
- 复用账号创建校验、独立凭据文件和单账号数据库事务；确定性旧身份与同服务商 Key 去重，失败账号可重试，事务失败清理新凭据。没有改写旧文件、已有新版账号或真实客户端配置。
- 新增数据存储里的预览／确认入口，明确迁移范围、跳过和失败原因；修改目录清除旧预览，完成后可以重新预览剩余项目。只在点击时读取源，不自动访问真实旧账号。
- 修复完整 SemVer 预发布比较、Beta 列表有界分页和候选过滤，拒绝重定向、无效仓库／标签／超大响应；发布页 URL 根据可信仓库和标签构造。默认仓库为原正式仓库，渠道持久保存并使用已有设置锁；默认跟随版本，用户明确选择优先。
- 更新页提供正式／Beta 选择，切换后清除旧结果；继续采用按需检查和发布页手动安装，没有实现自动下载安装。
- 应用／前端版本为 `2.0.0-beta.1`，Windows 构建／NSIS 为 `2.0.0`，PE 固定文件／产品版本为 `2.0.0.0`，产品字符串保留 Beta 后缀。同步 Windows 公司名与资源语言，使用系统 API 验证实际字段。
- 新增 ADR-016、UPGRADE 产品说明，同步 PRD、架构、Git 版本规则和 CURRENT；没有新增依赖或数据库迁移。当前 main 的普通开发监听器已自动构建最新代码，既有生产实例保持运行。
