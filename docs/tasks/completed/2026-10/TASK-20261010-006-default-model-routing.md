## Request

用户要求优化路由页面：读取默认模型，并依照读取到的模型做初步映射，减少手动配置；用户可以设置某个模型优先使用的服务商。

## Goal

基于已有模型目录提供可直接使用的默认映射，并让每个模型的服务商偏好真实影响网关路由、预览和客户端目录。

## Analysis

现有后端已经对同步模型和内置 DeepSeek 模型做同名直通，但路由页仅展示手工规则，因此可用模型仍呈现为“没有映射”。默认账号按创建时间选择，缺少按模型设置服务商偏好。

采用派生的默认映射视图，而非读取时批量写入规则：保留手工规则语义，目录变化即时反映且不会覆盖用户配置。新增独立模型服务商偏好表；顺序为启用精确规则 → 默认映射中优先服务商 → 其他支持同名模型的可用服务商。偏好只影响未命中的默认映射，不是固定目标；停用／删除／账号失效时可回落，并显示当前实际选择。不进行请求失败重试，不猜测跨模型名称的等价关系。

默认视图与网关、预览、客户端目录共享配置解析；仅展示已有适配器支持的候选提供商，保留暂时失效的偏好供用户修复／恢复自动选择。新增迁移 012 和薄 Wails 绑定；不新增依赖，不改变核心技术栈和模块边界。

用户明确选择“先覆盖现有已接入服务商”，本次保持 DeepSeek 和 ChatGPT/Codex 范围，不扩展自定义 OpenAI 兼容适配器。

3. 调整路由页面，保留用户可控规则与错误反馈，更新中英文文案。
