# TASK-20261009-010: 侧栏网关状态与启停控制

## Status

Completed

## Created

## Request

在左侧的仪表盘上面、软件名字下面增加一个区域，显示网关运行状态、端口、账号数量，并提供可以启动或关闭网关的按钮。

## Goal

在任何页面都能从侧栏查看网关概况并执行启停，保持现有侧栏展开／收起及中英文行为。

## Analysis

侧栏位于 `frontend/src/components/common/app-sidebar.tsx`；网关已有 `useGatewayRuntime` 和真实 Wails 启停服务，账号已有共享查询。优先复用现有数据与缓存，避免新增接口或重复维护运行状态。工作区含大量前序未提交变更，保留它们且不混合提交。

端口来自网关运行快照（停止时仍保留配置端口），复用已有端口边界校验；账号数量表示全部已添加账号，包含停用账号，不表示可路由账号数。侧栏和网关页各自挂载 Hook，需要按共享 mutation key 统计操作中状态，防止两个入口同时提交启停。

## Implementation Plan

1. 确认端口／账号数量语义以及已有运行态、错误提示与缓存同步行为。
2. 增加紧凑侧栏状态组件，支持展开概况、收起提示、真实启停和操作中禁用。
3. 添加关键交互验证，运行 `task verify`，同步网关文档、状态看板和任务结果。

## Implementation Result

- 软件名称下方、仪表盘导航上方新增紧凑网关卡片，展示实际运行状态、代理端口和已添加账号总数。
- 电源按钮调用现有真实网关接口；启动／停止时显示进度并禁用控件，失败展示固定安全文案并允许重试。
- 侧栏收起后保留居中电源按钮和状态点，悬停或聚焦可查看运行态、端口、账号总数及停止影响；禁用状态通过外层可聚焦提示触发器保持概况可读。
- 复用账号查询、状态事件和端口边界校验；共享 mutation key 同步侧栏及网关页的操作进度与最新错误，另一入口成功重试会清理过期错误。
- 支持中英文、亮暗主题、全局字号及减少动画；没有新增依赖或后端 API。

主要变更：`app-sidebar.tsx`、`sidebar-gateway-status.tsx`、`use-sidebar-gateway-status.ts`、`use-gateway-runtime.ts`、`gateway-status-card.tsx`、网关中英文词典、侧栏及网关状态测试。

组件测试为 203 行，覆盖同一组件的查询、启停、缓存、错误与提示行为；维持同一套测试上下文，避免仅为 3 行差异拆出额外测试模块。
