# TASK-20261007-003: 编辑账号名称与 API Key

## Status

Completed

## Created

## Request

操作列需要增加编辑按钮，可以编辑名字和 API Key。

## Goal

卡片和列表提供编辑入口，名称预填，密钥留空则保留；提交后更新元数据和密钥预览，并安全替换受保护凭证。

## Analysis

- 当前账号只有创建、启停、删除和密钥预览／复制，缺少更新服务与弹窗。
- 不回填原密钥。只输入新 Key 时替换原凭证，名称清空时沿用前最多 8 个字符的自动命名规则。
- 先写入新凭证，再通过条件更新切换引用；数据库失败或并发冲突时清理新凭证并保留原引用。提交成功后清理旧凭证，清理失败通过结果警告通知 UI，不把已成功的更新误报为完全失败。
- 详情卡片和列表共用操作组件；总览账号行也增加相同入口，弹窗和查询刷新共用。

## Implementation Plan

1. 新增有边界校验和并发保护的更新服务、结果类型与 Wails 绑定。
2. 增加编辑图标和统一弹窗，支持只改名称、只换 Key、同时更新、取消与失败重试。
3. 更新元数据和脱敏查询缓存，验证原 Key 保留、凭证替换回滚、旧凭证清理警告及真实 DPAPI 存储。
4. 完成前端交互和真实窗口检查，运行独立产物目录的完整质量门禁。
5. 更新文档和任务记录，审查并提交本任务文件，保留其他任务的改动。

## Risks

数据库与凭证文件不共享事务；更新失败不能删除原凭证。完整 Key 不回填、回显或进入日志／持久化 UI 状态。共享工作区另有网关任务，提交时只包含本任务改动。

## Implementation Result

- 详情列表、详情卡片及总览账号行增加编辑图标，共用统一的编辑弹窗和操作组件。
- 名称预填并选中，原密钥只显示脱敏信息，API Key 输入默认为空；空 Key 保留原凭证，清空名称沿用自动命名。
- 新增 UpdateInput／UpdateResult 与 UpdateAccount Wails 绑定，校验 ID、名称和 Key 长度／控制字符，结果不返回完整密钥。
- 替换时先保护新 Key，再用事务及原引用／更新时间条件切换引用。失败清理新凭证；并发冲突不覆盖其他修改、不删除其他操作已提交的凭证。
- 提交成功后清理旧凭证，清理失败通过明确的成功警告报告；只改名称不会读取或替换旧密钥。
- 保存刷新元数据和脱敏预览，提交结束 reset mutation 并移除其输入；弹窗支持取消、焦点恢复、保存中锁定、失败重试和中英文说明。
- 重新生成前端绑定，更新 PRD、架构说明和状态看板。没有新增依赖或数据库迁移。
