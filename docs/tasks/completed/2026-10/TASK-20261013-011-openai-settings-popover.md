## Goal

设置从入口旁展开紧凑面板，自动激活开关点击后直接持久保存并生效，读取／保存失败明确反馈。

## Scope

设置面板定位与交互、自动激活开关即时保存、相关回归测试、中英文说明和当前产品文档。

## Analysis

现有 OpenAI 设置使用全屏 Dialog，自动激活组件维护本地草稿并要求独立保存；WebSocket 已使用开关即时保存。沿用已完成的重置卡 Popover 模式与原有设置接口，移除草稿即可保持后端检测／去重规则。两个开关共享整份设置缓存，需在任一保存期间禁止重复／并行提交，避免响应乱序覆盖界面状态；非模态面板重开也应识别未完成保存。

## Implementation Plan

1. 改为入口下方非模态 Popover，使用边缘避让、内部滚动及可访问关闭操作。
2. 自动激活开关直接调用既有保存接口，失败保留旧值；两个开关共享保存锁。
3. 调整中英文说明、回归测试和产品／决策文档。
4. 运行相关测试及 `task verify`，隔离原生测试即时保存，开发窗口验收局部布局，审查提交并归档。

## Implementation Result

- OpenAI 账号设置改为入口下方非模态 Popover，移除整页遮罩／模糊，420px 宽、最多 560px 高，按可用空间避让，说明与状态在面板内滚动。
- 将开关移至各设置卡片的标题行，说明使用全宽，保留关闭按钮、入口切换、Escape、外部点击和焦点恢复。

- 两个设置开关使用同一 mutation key，任一保存期间暂时禁用两个开关；关闭后重开也识别在途保存。成功返回前取消旧设置读取，防止延迟响应覆盖新状态。
- 更新中英文说明，保持默认关闭、后台原账号请求及持久去重规则，无后端接口或依赖变更。
