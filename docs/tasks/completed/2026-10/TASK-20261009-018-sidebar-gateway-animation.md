# TASK-20261009-018: 稳定侧栏网关卡片收展动画

## Status

Completed

## Created

## Request

左侧操作列表展开和收起时，网关状态卡片异常跳动，需要优化动画展示效果。

## Goal

网关卡片、按钮和下方导航连续过渡，详情不被挤压换行；保留网关启停、提示及可访问性。

## Analysis

现有侧栏宽度使用 250ms 过渡，但卡片按 collapsed 同步切换 flex 布局、内边距和详情挂载，造成高度与按钮位置瞬间变化。展开期间详情宽度跟随窄侧栏挤压，进一步引起换行和高度跳变。

采用固定展开内容宽度、裁切容器与 CSS 网格高度过渡，电源按钮保留同一 DOM 并连续移动。相比定时卸载或动画库，这种方式无需引入依赖和额外状态，允许动画中途反向。支持系统减少动态效果偏好。

## Scope

- 侧栏及网关卡片布局、过渡样式。
- 关键交互回归和浏览器逐帧几何验证。
- 任务记录、当前状态看板。

## Implementation Plan

1. 保留现有展开／收起最终布局，统一过渡时间并稳定详情宽度。
2. 验证启停按钮身份、焦点及收起详情可访问性；检查连续切换、字号、主题、语言和减少动画。
3. 运行 task verify，核对项目原生窗口，记录结果及限制。

## Implementation Result

- 网关标题与详情始终保持展开宽度排版，侧栏缩窄时只裁切并淡出，消除文字换行导致的高度跳动。
- 固定保留收起时按钮／状态点的高度，只对额外详情使用 CSS 网格高度过渡；避免直接使用最小高度截断动画。
- 侧栏宽度、卡片额外高度、电源按钮位置与卡片背景共用 250ms 缓入缓出参数；支持动画中途反向，无定时器及新增依赖。
- 电源按钮保持同一 DOM，收展不丢失焦点；状态播报及错误描述独立于视觉裁切，收起后提示与启停操作仍可使用。
- 系统减少动态效果模式下直接切换最终布局。

主要文件：`app-sidebar.tsx`、`app-sidebar.css`、`sidebar-gateway-status.tsx`、`sidebar-gateway-status.css`、`sidebar-gateway-status.test.tsx`。
