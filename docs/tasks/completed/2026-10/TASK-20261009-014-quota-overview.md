## Request

用户认可配额页首版规划并要求实施：跨账号查看 Codex 订阅额度和 DeepSeek 余额，顶部概况、按提供商分组、搜索／筛选、单个／批量刷新、账号详情跳转和可靠刷新反馈。

## Goal

将配额占位页接入已有真实查询，在一个页面查看剩余资源与异常账号；百分比按账号／窗口分别展示，余额按币种保留官方精度。

## Scope

首版只读监控与手动刷新。不新增历史、提醒、自动调度、自动使用重置卡或自动刷新频率。

## Analysis

现有 SubscriptionQuota／AccountBalance 绑定返回公开快照及 fetchedAt，账号卡片已有按身份／凭据版本隔离的 TanStack Query 缓存。订阅服务通过全局 operations 锁串行读取，RPC 上下文有超时；大量同时发起查询会在后端等待。将共享查询选项抽出，订阅读取用前端串行队列，余额读取限制两个并发；排队期间取消不发起 RPC，已发起请求等待结束后释放并发名额。

页面采用顶部概况与按提供商分组的响应式账号卡片，复用额度窗口、重置时间和套餐组件。汇总统计能力已支持账号、已确认耗尽／余额不足、查询异常、待确认；未授权／不支持／缺失数据分别显示，已过官方重置时间的快照归为待刷新，不自动推算恢复。每次批量刷新只处理当前筛选列表中的可查询账号，失败保留上次快照并逐行显示安全错误。工作区包含前序大量未提交实现，保留并不混合提交。

## Implementation Plan

1. 复用账号／提供商元数据及额度／余额查询，限制查询并发并共享缓存。
2. 实现全局概况、分组账号列表、筛选及刷新，清楚呈现未授权／未支持／过期／失败。
3. 关键逻辑与交互验证、浏览器布局验证、task verify，并同步文档和任务记录。

## Implementation Result

- 替换配额占位页，展示支持监控账号数、已确认耗尽／余额不足数、查询异常和待确认概况；未知结果不当作零耗尽。
- 按提供商配置分组，响应式卡片最多四列。支持账号／邮箱／套餐／公开账号 ID 搜索、提供商和资源状态筛选，筛选不改变全局概况。
- 展示 Codex 官方额度窗口及重置倒计时；DeepSeek CNY／USD 分开展示官方总余额、赠送／充值余额，保留十进制精度。未授权、未接入、缺失、过期和失败分别显示。
- 支持单个刷新和当前筛选列表的批量刷新，跳过未授权／不支持账号，显示读取进度与批量失败数量；详情链接进入所属提供商的账号详情页。
- 配额页和账号详情共用查询选项、缓存、身份／凭据隔离规则，以及前端订阅串行／余额两个并发的查询队列。未开始请求可取消，已开始 RPC 等待结束后释放名额。失败保留快照，元数据更新触发同身份后台读取，更换凭据不沿用旧余额。
- 查询不自动重试或轮询，不改网关转发资格，不使用重置卡。支持中英文、亮暗主题、全局字号、键盘、减少动画，无新依赖或后端 API。

主要文件：`frontend/src/features/quota/`、共享查询 Hook、额度行组件、`frontend/src/lib/query-queue.ts`、配额路由和词典。
