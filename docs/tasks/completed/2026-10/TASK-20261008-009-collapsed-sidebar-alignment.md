# TASK-20261008-009: 收起侧栏图标与选中背景居中

## Status

Completed

## Created

2026-10-08

## Request

收起状态的左侧导航选中背景位置不正确，图标没有在背景中居中，需要优化。

## Goal

导航图标、选中背景与侧栏中心对齐，顶部品牌和底部操作视觉一致，展开／收起动画不产生图标横向跳动。

# Analysis

导航使用 ScrollRegion，其轨道始终占用右侧 12 像素，即使无需滚动也保留空间。图标使用固定左侧内边距，选中背景跟随被压缩的内容宽度，造成背景中心与图标偏离。底部不使用该轨道，因此导航和底部按钮宽度也不一致。

## Scope

- 侧栏滚动轨道改为覆盖右侧留白，导航恢复完整宽度。
- 保留主内容及账号列表原有轨道和窗口缩放边缘避让。
- 调整收起态提示位置，保持滚动、键盘访问及现有文字动画。

# Implementation Plan

1. 用真实浏览器测量当前侧栏、选中项、图标和底部按钮的位置，确认偏移来源。
2. 增加局部滚动覆盖模式，仅用于侧栏，验证居中与过渡稳定性。
3. 检查深浅主题、短窗口滚动、悬浮与键盘提示，运行质量检查并更新记录。

# Progress

- 已定位到侧栏轨道常驻预留宽度与固定图标位置不一致。
- Chrome 实测：侧栏宽 64px，图标中心 32px，选中背景中心 25.5px，相差 6.5px；背景左侧留白 8px、右侧 21px，确认是常驻轨道挤压。

# Implementation Result

- 新增 ScrollRegion 的局部 CSS 覆盖模式，侧栏轨道改为右侧 8px 留白内的绝对定位，不再压缩导航宽度；主内容和账号列表仍使用原有预留轨道。
- 导航按钮裁切自身隐藏标签，避免长标签在收起时扩大导航的横向滚动范围；固定图标位置、36px 行高和文字动画保留。
- 收起导航的自定义提示置于右侧，避免覆盖相邻图标。
