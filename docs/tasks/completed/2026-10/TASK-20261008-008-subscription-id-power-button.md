## Request

在订阅套餐后显示授权返回的 account_id，使用首尾缩略形式；将账号滑动开关改为参考图中的电源启停图标按钮，启用和停用样式明确区分。

## Goal

识别同一订阅身份，统一账号启停操作与编辑、删除图标的尺寸和视觉风格。

## Scope

- 确认官方 account_id 的可用来源，补充账号元数据读取、存储与返回。
- 订阅套餐后显示缩略账号 ID，并提供完整值的自定义悬浮提示。
- 账号总览、详情卡片和列表复用电源启停按钮；保持现有启停服务逻辑。

## Out of Scope

- 更改授权协议、登录会话生命周期、推理转发或其他设置开关。
- 用本地记录 ID、随机配置 ID 或邮箱伪造官方 account_id。

# Analysis

现有身份元数据仅包含邮箱、套餐和状态，必须先确认官方字段如何安全读取。账号启停目前复用提供商滑动开关，可替换账号组件而保留提供商现有行为。

本机官方 CLI 生成的 GetAccountRateLimitsResponse schema 含 accountId（可为空）；通过 account/rateLimits/read 获取，不读取或解析授权令牌。辅助元数据读取设置独立短超时，失败只提示 ID 待获取，保留已确认身份和授权。旧账号可通过刷新补全。

## Risks

account_id 是身份信息，禁止记录到日志；仅读取本应用已管理的隔离授权。兼容已有数据库和身份尚未刷新账号，保留缺失状态，不因附加字段未返回破坏有效登录。

# Implementation Plan

1. 检查官方协议及本地适配器，选择最小、安全的 ID 读取方式。
2. 增加可兼容的元数据字段、迁移和绑定；完整维护创建、刷新、重登、退出路径。
3. 实现缩略 ID 与电源按钮，验证启停、异常状态和深浅主题。
4. 运行质量检查，恢复开发环境并更新文档与记录。
