## Request

用户要求先规划再完成：统计累计代理输入／输出 Token；删除账号不得删除历史统计；每次代理有记录并与请求和日志关联；日志缓存最多 5000 条；请求默认保存 10000 条并可在设置修改；ChatGPT Team 需同时按邮箱和 account_id 区分成员。

## Scope

- 所有现有 HTTP／SSE／WebSocket 代理路径统一请求 ID、生命周期记录和官方 usage 采集。
- 独立持久化累计统计与有数量上限的请求明细，账号删除和明细淘汰不影响累计。
- 用量页、请求页、日志关联与设置页请求保留条数。
- 订阅身份以邮箱和 account_id 共同识别，并校验实际授权身份一致。

## Analysis

用量／请求页当前占位；日志默认 512、最大 4096，前后端均需调整为 5000。代理已有 HTTP JSON／SSE、WebSocket 和跨协议转换，必须在原上游读流处采集 usage，避免转换器将缺失 usage 转成 0 后误统计。HTTP 流目前只识别 [DONE]，原生 Responses 的 completed 需识别为正常终止。

累计与按日／模型／成员汇总独立保存；明细保留 10000（设置范围 100–1000000）。不对账号／提供商使用删除外键，记录身份快照。Begin 先落库；每次官方用量快照事务更新明细及汇总差值，重复事件幂等；结束只更新结果。缺失或截断用量保留未知／部分状态。DB 写入失败阻断转发或中断响应并报告。

订阅身份使用规范化邮箱和 account_id 组合键，实际授权读取还核对邮箱；同 Team 工作区不同邮箱的成员分别汇总，删除后重加同身份可合并历史。
