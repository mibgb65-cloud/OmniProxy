## Implementation Result

- 沿用 UIBuffer，兼容 Add／Lines，新增有界结构化 Entry、递增序号、固定上界分批读取、独立副本、缓存覆盖与旧游标复位；默认 512 条，最大 4096 条。
- 中央脱敏扩展到嵌套 Group、error／map／数组、敏感分组与 CamelCase／token 字段，处理循环和深度边界；UI 使用诊断字段白名单，文本与字段有界。
- Wails 新增 LogsRead／LogsHead／LogsExport／LogsOpenDirectory 与类型化 logs:updated 事件；150ms 合并通知，写入不阻塞，退出时解除后台订阅。
- 导出只接受记录 ID，以原生对话框选择 JSONL 目标；先快照已脱敏正文再原子写入，过期条目有明确反馈，取消不显示成功。目录打开只使用当前环境配置。
- 日志页提供级别／模块／关键词筛选、毫秒时间、详情、复制、暂停补齐、清空显示、自动跟随／新增提示和导出；工具栏固定，列表独立滚动，亮暗主题与中英文本完整。
- ScrollRegion 兼容扩展外部 viewportRef／onScroll，保留既有滚动条交互；为日志源码添加 .gitignore 例外，使 Git 和 Tailwind 正确识别该目录。
