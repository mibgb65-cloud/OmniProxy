## Request

接入 DeepSeek API Key 账号余额查询，先核对官方协议和现有实现，再完成查询与界面展示。

## Scope

- 官方 GET /user/balance，展示总余额、赠送余额、充值余额、币种和是否充足。
- 账号卡片与列表使用真实数据，支持手动刷新及失败重试；其他提供商保持原占位。
- API Key 仅在后端凭据回调中使用；金额保留十进制字符串，不换汇、不使用浮点累加。

# Analysis

DeepSeek 官方接口返回 is_available 和 balance_infos。现有 account.UseAPIKey 可在回调结束清除解密字节；提供商已有 DeepSeek 适配器，可扩展只读余额方法。查询固定官方 HTTPS 地址并禁止重定向，不向自定义地址发送查询凭据。应用层核对账号属于 DeepSeek 且为 API Key，再返回安全 DTO。

查询缓存按账号元数据版本隔离，以便更换 Key 后不复用旧余额；同版本手动后台刷新保留上次结果，失败不改为零。

4. 做适配器／凭据边界／交互测试和实际只读验证，运行 task verify，恢复开发环境并更新文档。
