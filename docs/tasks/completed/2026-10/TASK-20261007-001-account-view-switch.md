## Request

每个账号的具体显示做一个可以切换的，一个是卡片展示，一个是列表展示，列表参考用户提供的截图，并设计合理的布局。

补充确认：一并实现真实 Key 脱敏与复制，暂不加批量勾选。

## Goal

提供商账号详情页能切换卡片／列表并记住偏好，两个视图展示同一份真实账号信息，共用启停和删除流程。

## Analysis

- 当前详情页按单列卡片展示名称、API Key 认证方式、启用状态、余额待接入、创建及更新时间；尚无 Key 脱敏和复制接口。
- 在详情页标题右侧、添加账号按钮旁提供视图切换；卡片使用响应式网格，列表使用清晰的表头、紧凑行和独立横向滚动。
- 两个视图复用格式化与操作组件，避免启停和删除行为分叉；偏好使用已有 Zustand 持久化状态，并验证存储值。
- 默认保留卡片。用户已确认：一并实现真实 Key 脱敏与复制，暂不增加批量勾选。

## Implementation Plan

1. 添加可验证、可持久化的卡片／列表显示偏好与可访问切换按钮。
2. 优化卡片网格，实现账号列表，复用时间显示、启停与删除，处理空状态和窗口宽度。
3. 后端读取凭证生成脱敏文本；复制由 Wails 端直接写系统剪贴板，完整 Key 不返回前端。缺乏真实数据的余额继续显示待接入。
4. 验证切换、偏好恢复、双视图操作与真实窗口布局，运行完整质量门禁。
5. 同步文档、状态看板和任务记录，审查并提交本任务文件。

## Risks

密钥列不能依赖账号名称伪造片段；复制真实 Key 必须走受控凭证读取，不将完整 Key 放入查询缓存或持久化 UI 状态。表格在较窄窗口应内部滚动，避免裁掉操作列。视图切换不能触发数据写入。

## Implementation Result

- 厂商账号详情页标题右侧加入卡片／列表单选切换，默认卡片并记住选择；存储恢复校验展示值，异常值不会覆盖 setter。
- 卡片采用响应式两列／三列网格，列表展示账号／序号、API Key 脱敏、状态、余额、创建／更新时间和操作。
- 表格内部横向滚动，账号标识与操作列固定在左右两侧；卡片与列表共用真实数据、时间格式化、状态徽标、启停、删除及密钥预览组件。
- 新增受控密钥读取与两个 Wails 方法。预览从真实凭证产生，超过 16 个 Unicode 字符时显示前后各 4 个字符，其余遮掩；短密钥全部遮掩，考虑自动名称可能已显示前 8 个字符的情况。
- 复制由桌面层直接写入系统剪贴板，新的复制接口不返回密钥内容；读取与使用结束清理拥有的密钥字节，前端仅缓存脱敏预览，删除后移除对应预览缓存。
- 加入读取重试、复制中／成功／失败反馈和中英文文案，余额继续如实显示待接入；按用户确认范围，没有批量勾选或批量操作。
- 已重新生成 Wails 绑定；没有新增依赖或数据库字段。

## Technical Notes

纯展示偏好保存在已有 Zustand 状态，账号及预览查询继续由 TanStack Query 管理。密钥读取放在应用服务，系统剪贴板操作只放在 Wails 适配层；剪贴板写入序列化，避免初始化和写入竞争。详情页测试约 230 行，共用现有查询／路由构造覆盖两个视图及同一页面的删除与复制契约，保留此组织以避免重复测试构造；新增手写组件和服务文件均低于 200 行。
