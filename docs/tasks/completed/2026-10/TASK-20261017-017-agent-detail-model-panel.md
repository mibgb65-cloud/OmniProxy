## Request

用户希望详情页右侧新增空间展示当前接入的模型；点击配置按钮后，右侧切换为设置接入 Agent 模型的页面。

## Goal

详情页形成管理与模型两栏；右侧可在已接入模型展示和模型配置之间切换，沿用默认全选、版本保护、备份恢复和目录刷新行为。

## Analysis

- 详情页当前安装与接入卡片全宽堆叠；AgentClientSettings 自持配置弹窗状态。
- 增加只读 ConfiguredModels 契约，从受管且版本匹配的实际菜单／目录提取公开 ID、名称和默认模型；不将可用源目录当作已接入目录，不返回原配置或凭据。
- 前端将现有配置表单迁移为内联编辑器，移除旧弹窗包装，保留同一保存逻辑和原版本保护测试；保存／取消返回列表。
- 宽屏左右两栏，窄容器上下排列；模型列表独立滚动，操作可见。保存、重新读取、恢复后更新右侧查询，切换客户端隔离状态。

## Implementation Plan

1. 核对已有客户端配置与模型目录，明确已接入和可配置模型的区别。
2. 增加安全的已接入模型读取契约，重用现有模型选择和保存逻辑，将详情页配置迁入右侧。
3. 覆盖展示、编辑／取消／保存、刷新／恢复和客户端切换，验证宽窄窗口及键盘操作，运行完整质量门。
4. 同步文档、审查 diff，仅提交本任务文件，记录提交并归档。

## Implementation Result

- 详情页改为容器宽度驱动的两栏：左侧软件安装和接入管理，右侧已接入模型。窄容器上下排列，沿用原页面导航与页签状态。
- 右侧展示实际受管目录的模型名称、ID、默认模型标记、数量，支持搜索、刷新和 Key 停用提示。未接管时显示空状态，读取失败／外部修改不使用可用目录冒充已接入状态。
- 新增只读 AgentConfiguredModels 绑定，校验客户端白名单、文件版本与目录哈希，从九种客户端实际模型菜单／JSONC／YAML／Codex 目录投影公开信息；Desktop 稳定别名按当前目录解析，原始配置和凭据不返回前端。
- 点击一键配置直接将右侧切换为内联编辑器并自动预览，沿用默认全选、搜索、勾选、默认模型、空选择拦截、源快照和加密备份保护；移除旧弹窗包装并保留原行为测试。
- 重新读取、取消、应用放到编辑器顶部，正文和模型列表独立滚动；保存后回到已接入列表并显示通知，取消不写入，恢复原配置同步清空展示。编辑时禁用左侧配置操作，客户端切换隔离编辑状态。
- 配置元数据暂不可用时仍独立展示软件安装区，保持安装／检测与配置服务的原边界。无新增依赖、数据库迁移或核心协议变更。
