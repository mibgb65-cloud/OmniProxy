## Request

额度查询期间保留原始显示，查询完成后通过动画更新信息，不再闪现空进度条、时间待确认和查询中提示。

# Analysis

现有额度 queryKey 包含账号 updatedAt，状态刷新改变版本时会建立空的新查询，导致已有额度被占位内容覆盖。改为按账号身份和授权状态隔离的稳定键，元数据版本变化触发同一查询的后台刷新，保留最后成功数据和失败时的原内容。首次无数据使用安静、固定布局的占位；数值／计时淡入，进度条宽度平滑过渡，并尊重减少动画偏好。

# Implementation Plan

1. 创建稳定且隔离身份的额度查询键，调整重置卡成功后的缓存写入。
2. 保留后台刷新内容，稳定首次加载布局，增加数值／时间和进度条更新动画。
3. 验证元数据刷新、失败保留、账号切换及退出隔离、真实布局和减少动画，更新记录。

# Progress
